# 提示詞片段的寫法

腳本負責把片段組合成完整的提示詞：順序、不重複、每一鏡用字一致。片段本身寫得好不好，腳本管不了。這一份說每一種片段怎麼寫。

各工具官方對提示詞的要求不一樣，見 `tool-capabilities.md` 的「各工具官方的提示詞寫法」。

## 一、六條通則

1. **寫看得見的東西。** 生成工具畫的是畫面，不是概念。「氣質清冷」「眼神堅毅」「很有故事感」沒有對應的畫面，每次生成都會不一樣。改寫成造成那個印象的具體特徵：「眼尾微微下垂，薄唇，很少笑」。
2. **具體勝過形容。** 寫顏色、材質、形狀、數量、位置。「漂亮的裙子」改成「霧藍色及膝棉質連身裙」。
3. **寫要什麼，不寫不要什麼。** 否定句常常把那樣東西叫出來。「沒有人的街道」改成「空蕩的街道」；「不要多餘的手指」改成把兩隻手的位置寫清楚。
4. **一個片段只管一件事。** 外貌裡不寫表情，場景裡不寫人，風格裡不寫光線。片段會被組合到不同的圖裡（角色設定圖沒有場景，場景定稿圖沒有人），越界的內容會跑到不該出現的地方。
5. **夠用就停。** 每多一個細節，就多一個生成工具可能做錯、或顧此失彼的地方。一個角色三到五個辨識特徵，一個場景三四樣固定物件。
6. **同一樣東西永遠用同一個詞。** 這一鏡寫「毛衣」、下一鏡寫「針織衫」，生成工具會當成兩件衣服。角色、道具由腳本代入，不會寫錯；你手寫的 `bg`、`motion`、`end` 要自己守住。

## 二、腳本怎麼組合

寫片段之前先知道它會被放在哪裡，才不會重複或互相矛盾。

- **首幀圖像**：每個角色（`look`、服裝、`state`、`marks`、`pos`、`gaze`、`hands`、`face`）→ `props` → 背景（`bg`，沒有就用機位的，再沒有才是場景的 `space`）→ 光線（`light`，沒有就用機位或場景的光線與時間）→ 怎麼拍（景別與取景範圍、鏡頭類型、角度、`frame`）→ `style_lock`。
- **尾幀**：一句圖像編輯指令，內容是 `end`。
- **影片（圖生影片）**：`motion` → 運鏡 → `video_suffix` → 台詞與語氣、`sound`、`audio_suffix`（後三樣原生音訊方案才有）。不含外貌與場景。
- **影片（文字生影片）**：角色與走位 → `props` → `motion` → 背景 → 光線 → 景別與運鏡 → `style_lock` → `video_suffix` → 聲音。

主體在前、鏡頭與風格在後。Google 的官方指南列的要素是主體、動作、場景、鏡頭角度、運鏡、鏡頭效果、視覺風格、聲音，並說明不必每一項都寫，也沒有規定順序（2026-11-25 查證）。

## 三、設定檔的片段

### `look`：固定外貌

順序：年齡與性別 → 臉型 → 髮型與髮色 → 眼睛 → 體型。妖怪、動物、器物、巨獸這類非人角色的順序不同，見 `creatures-and-effects.md`。

| 不好 | 好 | 差在哪裡 |
|---|---|---|
| 清秀的少女，氣質溫柔 | 十七八歲的女性，圓臉，栗色及胸長捲髮，圓而大的深棕色眼睛，身形嬌小 | 「清秀」「溫柔」畫不出固定的樣子 |
| 帥氣的年輕總裁，眼神冷峻 | 三十歲左右的男性，臉型瘦長，黑色短髮往後梳，單眼皮，眉毛濃而直，肩膀寬 | 身分和性格不是外貌 |
| 年輕女子，長頭髮 | 二十歲出頭的女性，鵝蛋臉，黑色及腰直髮，中分 | 年齡要有範圍，髮型要有長度、直捲、分線 |

- **髮型最能鎖住辨識度**，寫到長度（及肩、及腰）、直或捲、瀏海、顏色、怎麼綁。
- 年齡寫「二十歲出頭」這樣的範圍，不要只寫「年輕」。
- 表情、姿勢、服裝各有自己的欄位，不要寫進來。
- 不要用真人或既有作品角色的名字代替描述。不同工具對同一個名字的反應不一樣，有些會直接擋下；寫特徵才穩，也沒有肖像與著作權的問題。

### `tag`：短稱

最顯眼的兩個特徵加上性別年齡：「黑髮及肩的年輕女子」「短髮戴眼鏡的高個男子」。

- 角色之間的短稱要一眼分得出來，最好用不同種類的特徵（一個靠髮型、一個靠眼鏡、一個靠體型）。
- 不要放會隨造型改變的東西。服裝會換，短稱寫了「穿紅衣的」，換裝之後就錯了。
- `motion` 和 `end` 裡每次都用一模一樣的字串，腳本會檢查。

### `outfit`、`outfit_top`、`state`：造型

每件衣物寫「顏色＋材質＋款式」，必要時加長度或合身度；由上到下，最多三四件。

| 不好 | 好 |
|---|---|
| 休閒的打扮 | 米白色粗針織高領毛衣，深灰色及踝百褶長裙，棕色短靴 |
| 古裝 | 月白色交領長袍，袖口寬大，腰間繫深青色布帶 |

- `outfit_top` 只寫腰部以上看得到的，盡量和 `outfit` 的前半段一字不差。
- `state` 寫看得見的狀態，不寫原因和嚴重程度：「左袖上臂處被血浸成深色」，而不是「受了重傷」。
- 會讓人記住的固定特徵（痣、疤、不離身的飾品）放 `marks`，不放服裝。

### `space`：場景的固定結構

第一句交代這是什麼地方（類型、大小、新舊），接著是三四樣不會動的東西，以及它們彼此的位置。

| 不好 | 好 |
|---|---|
| 溫馨的房間，窗在左邊，桌上有一碗麵 | 老舊公寓的小客廳，一張木頭方桌緊靠窗邊，玄關的門在窗戶對面的牆上，一張布沙發靠著與窗戶垂直的牆 |

「溫馨」是感覺；「窗在左邊」是畫面座標，換個機位就錯；「一碗麵」是會變的東西。

### `light`、`time`：光線

一段光線描述要回答三件事：**光從哪裡來**（光源）、**往哪個方向照**、**是什麼樣的光**（顏色、軟硬、亮暗對比）。

「暖橘色的夕陽從窗戶斜照進來，室內其餘地方偏暗」三樣都有。「光線很美」「氛圍感燈光」一樣都沒有。

先用白話把光源和方向寫出來，需要更精確時再加一個術語：

| 類別 | 用詞 | 英文 | 效果 |
|---|---|---|---|
| 方向 | 順光 | front lighting | 平、清楚、陰影少 |
| | 側光 | side lighting | 立體，有戲劇性 |
| | 逆光 | backlighting | 輪廓發亮；背景很亮時變成剪影 |
| | 輪廓光 | rim light | 人物邊緣一圈亮邊，把人從暗背景裡分出來 |
| | 頂光 | top lighting | 眼窩有陰影，壓抑 |
| | 底光 | underlighting | 詭異、不自然 |
| 軟硬 | 硬光 | hard light | 影子邊緣清楚：正午的太陽、沒有罩子的燈泡 |
| | 柔光 | soft diffused light | 影子邊緣模糊：陰天、紗簾後的窗光 |
| 明暗 | 高調 | high-key lighting | 整體明亮、陰影少：輕鬆、日常 |
| | 低調 | low-key lighting | 大片暗部、只有局部亮：懸疑、沉重 |
| 色溫 | 暖光 | warm light | 燭火、鎢絲燈、夕陽 |
| | 冷光 | cool light | 月光、陰天、螢幕、日光燈 |
| 特殊 | 體積光 | volumetric lighting | 看得見的光束（穿過灰塵、霧、樹葉） |
| | 剪影 | silhouette | 人物全黑，只有輪廓 |
| | 場景內光源 | practical light | 畫面裡看得到的燈：檯燈、螢幕、燭火 |
| 時段 | 黃金時刻 | golden hour | 日出後、日落前，低角度的暖光 |
| | 藍調時刻 | blue hour | 日落後天還沒全黑，均勻的藍色調 |

backlighting、side lighting、rim light、high-key、low-key、volumetric lighting、golden hour 都出現在 Google 或可靈的官方提示詞指南裡（2026-11-25 查證），其餘是通用的攝影用語。

- 光源必須是這一鏡畫面裡合理存在的。特寫看不到屋頂的破洞，就不要寫「從屋頂破洞照下來」，用那一鏡的 `light` 改寫成「一束冷白的光從上方斜照在臉上」。
- `time` 只寫時段與天氣，飽和度與顆粒歸 `style_lock`。

### `style_lock`：風格鎖定句

結構：媒材或畫風 → 線條 → 上色方式 → 色彩 → 質感。

| 題材 | 可以這樣寫 |
|---|---|
| 現代都市、校園日常 | 日系賽璐珞動畫風，線條柔和，平塗上色加一層陰影，低飽和暖色調，輕微膠片顆粒 |
| 古裝、仙俠 | 國風水墨淡彩，墨線勾勒，設色清淡，大量留白，宣紙質感 |
| 懸疑、驚悚 | 寫實厚塗插畫風，線條隱沒在色塊裡，冷色調，明暗對比強，暗部濃重 |
| 甜寵、輕喜劇 | 韓系條漫風，線條乾淨纖細，漸層上色，明亮的粉彩色調 |
| 奇幻冒險 | 立體動畫電影風格，造型圓潤，材質細膩，色彩飽和 |
| 寫實短劇感 | 電影感寫實攝影風格，自然膚質，色彩偏低飽和，輕微膠片顆粒 |

- 不寫背景、人物、天氣、光線方向。它會被加到每一張圖上，包含純色背景的角色設定圖。
- 用特徵描述風格，不要只丟作品名、畫師名或工作室名。理由和 `look` 不寫名人一樣。
- 定了就不要改。一改，所有資產圖和首幀都要重出。
- 工具支援風格參考圖時，鎖定句照寫，參考圖是加強，不是取代。

### `props[].desc`：道具

十五字以內的名詞短語：材質、顏色、形狀、新舊。「一把磨得發亮的舊銅鑰匙」。狀態（拆了沒、亮不亮）寫在鏡頭裡。

它會被代入句子中間（「右手握著{P01}」），所以寫成一個不含逗號的短語。`a square pale-blue biscuit tin, paint worn at the corners` 代進去之後句子會斷掉；寫成 `a square pale-blue biscuit tin with worn corners`。

## 四、分鏡檔的片段

### `pos`、`gaze`、`hands`、`face`：走位

| 欄位 | 要寫到 | 例 |
|---|---|---|
| `pos` | 在畫面哪裡（左右、上下、前中後景）＋身體朝向＋姿勢 | 坐在畫面右側中景的桌前，上半身朝向畫面左側 |
| `gaze` | 看誰或看什麼＋方向 | 抬頭看向畫面左上方的前景男子 |
| `hands` | 兩隻手各自的位置、動作、拿著什麼；看不到也要說 | 右手握著門把，左手自然下垂 |
| `face` | 具體的肌肉變化，一個主表情加一個不完美的細節 | 眉頭微皺，嘴唇抿成一線，視線有點飄 |

| 不好 | 好 |
|---|---|
| 站在旁邊，很生氣 | 站在畫面左側中景，身體朝向畫面右側，雙臂交叉抱在胸前；眉頭緊鎖，下顎繃緊 |
| 拿著杯子 | 右手握著白色馬克杯的把手，杯子舉在胸前；左手扶著杯底 |

兩個人都完整入鏡時，髮色和服裝顏色容易互相串。能避就避：讓其中一人用 `partial`（背影、前景虛焦）；避不掉時，每個人的 `pos` 都以畫面位置開頭（「畫面左側的…」），並確認兩人的描述在顏色上差得夠遠。

### `bg`、`frame`、`end`

- **`bg`**：這一鏡的取景範圍裡實際看得到的背景，並說明清楚還是虛化：「背景是虛化的窗框與窗外的暮色」。同一個機位的鏡頭把它登記在 `setups`，不要每鏡重寫。
- **`frame`**：主體放在哪、前景有什麼、景深、留白，原則見 `shot-craft.md` 第七節。需要時加鏡頭與景深的用詞：

  | 用詞 | 英文 | 效果 | 常用在 |
  |---|---|---|---|
  | 廣角鏡頭 | wide-angle lens | 空間被拉開，近大遠小，環境收得多 | 建立鏡頭、狹小的室內 |
  | 長焦鏡頭 | telephoto lens | 前後景被壓在一起，背景虛化 | 近景與特寫、從遠處看人 |
  | 淺景深 | shallow depth of field | 只有主體清楚，背景虛化 | 人物近景、插入鏡頭 |
  | 深焦 | deep depth of field | 前後都清楚 | 建立鏡頭、前後景都有戲 |
  | 前景虛焦 | out-of-focus foreground | 前景模糊，襯出後面的主體 | 過肩鏡頭、隔著東西看 |

  這些是攝影用語，效果因工具與畫風而異。先用在最需要的鏡頭上，看了結果再決定要不要多用。
- **`end`**：只寫和首幀不一樣的地方，用短稱指人。有運鏡時寫運鏡之後看到的畫面（「畫面比首幀略為推近，女子的臉佔畫面一半」）。

### `motion`：怎麼動

四步驟的寫法在 `fields.md`。另外注意：

- **動詞選力道中等的**：走、轉、抬、放、推、握。撲、衝、甩、踹這類動作拆成剪接。
- **一鏡最多兩三拍**：一個主動作，加一兩個微動作。用「先…接著…」把順序講清楚。
- **寫動作本身，不寫情緒的名字**：

  | 不好 | 好 |
  |---|---|
  | 她很驚訝 | 黑髮及肩的年輕女子眼睛微微睜大，吸了一口氣，肩膀跟著抬起 |
  | 風吹過，頭髮飄動，他轉身離開，門關上 | 拆成兩鏡：一鏡是風吹動頭髮、他抬手按住；一鏡是門在他身後關上 |
  | 兩人激烈爭吵 | 短髮戴眼鏡的高個男子上身前傾，右手食指點了一下桌面；黑髮及肩的年輕女子身體往後靠，其餘保持靜止 |

- 可靈與 Seedance 的官方指南支援在一段提示詞裡用時間碼或鏡頭編號排好幾個動作（「0–3 秒：…」「鏡頭一：…」）。這個 skill 是一鏡一個動作、各自生成，腳本不會產生這種寫法；使用者想把相鄰幾鏡合成一段生成時，再照該工具的指南手動合併。

### `line.tone`、`sound`：聲音

- **`tone`**：音量、語速、情緒，挑兩樣寫。「低沉、遲疑」「壓低聲音，說得很快」。英文寫成接在 says 後面的短語：`in a low, hesitant voice`、`whispering quickly`。
- **`sound`**：環境音加一兩個具體的音效，寫出聲音的來源：「遠處的車聲，門軸的吱呀聲」。「緊張的氛圍音」沒有來源，生成工具只能自己編。
- 不想要工具自己加字幕或配樂，寫在 `audio_suffix`（「不要字幕，不要背景音樂」）。這是少數官方認可有效的否定寫法。

## 五、英文片段

- **寫名詞短語，不寫完整句子。** 開頭不大寫，結尾不加句號，腳本會處理。
  - `look`：`a woman in her early twenties, oval face, shoulder-length straight black hair with blunt bangs, dark brown almond eyes, slim build`
  - `outfit`：`an off-white chunky-knit turtleneck sweater, a dark grey ankle-length pleated skirt`（順序是顏色、材質、款式、物件）
- **`tag` 用 the 開頭的名詞短語**：`the young woman with shoulder-length black hair`。`motion` 和 `end` 裡每次都用完全相同的字串。
- **`pos`、`gaze`、`hands` 用現在分詞**：`sitting at the table in the right midground, upper body turned toward frame left`、`looking up at the man in the left foreground`。
- **`motion` 用現在式的子句**：`the young woman with shoulder-length black hair lowers her head and looks at the envelope; the curtain sways once in the breeze`。
- **畫面位置的說法**：frame left、frame right、the upper third of the frame、foreground、midground、background。
- **不要逐字直譯。**「神情平靜，略帶疲憊」是 `calm expression with a trace of tiredness`，不是 `expression calm, slightly tired feeling`。寫完自己唸一遍，不像英文就重寫。
- 給人看的欄位（`action`、`risk`、`continuity`、`desc`）仍然用使用者的語言。

## 六、提示詞太長的時候

超過工具上限時，照這個順序縮，前面的做完還不夠才往下：

1. `bg` 寫短，或改用機位的 `bg`，不要讓整段 `space` 進到近景裡。
2. 填 `outfit_top`，中景以內就不會帶到下半身的服裝。
3. 背影、前景虛焦的角色設 `partial: true`，腳本只寫短稱和服裝。
4. `frame` 刪掉修飾性的詞，只留位置。
5. `pos`、`gaze`、`hands` 各留一句最關鍵的。

`look` 與 `style_lock` 最後才動，而且要動就是改 `bible.json`、全片一起改。只在某一鏡把外貌寫短，那一鏡的角色就會走樣。
