# 提示詞片段的寫法

腳本負責把片段組合成完整的提示詞：順序、不重複、每一鏡用字一致。片段本身寫得好不好，腳本管不了。這一份說每一種片段怎麼寫。

各工具官方對提示詞的要求不一樣，見 `tool-capabilities.md` 的「各工具官方的提示詞寫法」。

目錄：一、六條通則｜二、腳本怎麼組合｜三、設定檔的片段（外貌與頭身比、短稱、造型、場景、光線與布光、色彩、風格鎖定句、道具、資產圖細節）｜四、分鏡檔的片段（走位與朝向、情緒對照表、背景與構圖、動作、聲線與聲音）｜五、英文片段｜六、提示詞太長的時候｜七、參考圖模式｜八、真人寫實

工具未定時，片段照故事需要寫完整，不為任何一個工具預先縮短或避開什麼；工具定了才照第六節縮、照 `anti-ai-rules.md` 第二部分換拍法。

## 一、六條通則

1. **寫看得見的東西。** 生成工具畫的是畫面，不是概念。「氣質清冷」「眼神堅毅」「很有故事感」沒有對應的畫面，每次生成都會不一樣。改寫成造成那個印象的具體特徵：「眼尾微微下垂，薄唇，很少笑」。
2. **具體勝過形容。** 寫顏色、材質、形狀、數量、位置。「漂亮的裙子」改成「霧藍色及膝棉質連身裙」。
3. **寫要什麼，不寫不要什麼。** 否定句常常把那樣東西叫出來。「沒有人的街道」改成「空蕩的街道」；「不要多餘的手指」改成把兩隻手的位置寫清楚。
4. **一個片段只管一件事。** 外貌裡不寫表情，場景裡不寫人，風格裡不寫光線。片段會被組合到不同的圖裡（角色設定圖沒有場景，場景定稿圖沒有人），越界的內容會跑到不該出現的地方。
5. **每樣東西寫在對的地方。** 鏡頭的片段寫「這一鏡要對」的東西：辨識一個角色所需的特徵、這一鏡看得到的陳設。一個角色挑最能認出他的幾個特徵寫進 `look` 與 `marks`，比把所有細節都塞進每一鏡穩，生成工具不會顧此失彼。做工、材質與磨損這些近看才看得到的，寫在只進資產圖的 `detail`，資產圖越細，鏡頭能照著畫的越多，見第三節。這一條是組織，不是字數限制；字數上限是工具定了之後的事，見第六節。
6. **同一樣東西永遠用同一個詞。** 這一鏡寫「毛衣」、下一鏡寫「針織衫」，生成工具會當成兩件衣服。角色、道具由腳本代入，不會寫錯；你手寫的 `bg`、`motion`、`end` 要自己守住。

## 二、腳本怎麼組合

寫片段之前先知道它會被放在哪裡，才不會重複或互相矛盾。

- **首幀圖像**：每個角色（`look`、服裝、`state`、`marks`、`pos`、`gaze`、`hands`、`face`）→ `props` → 背景（`bg`，沒有就用機位的，再沒有才是場景的 `space`）→ 光線（`light`，沒有就用機位或場景的光線與時間）與色彩（`palette`）→ 怎麼拍（景別與取景範圍、鏡頭類型、角度、`frame`）→ `style_lock`。參考圖模式下角色只剩「圖1中的＋短稱」與走位，見第七節。
- **尾幀**：一句圖像編輯指令，內容是 `end`。
- **影片（圖生影片）**：`motion` → 運鏡 → `video_suffix` → 台詞與語氣、`sound`、`audio_suffix`（後三樣原生音訊方案才有）。不含外貌與場景。
- **影片（文字生影片）**：角色與走位 → `props` → `motion` → 背景 → 光線與色彩 → 景別與運鏡 → `style_lock` → `video_suffix` → 聲音。

主體在前、鏡頭與風格在後。Google 的官方指南列的要素是主體、動作、場景、鏡頭角度、運鏡、鏡頭效果、視覺風格、聲音，並說明不必每一項都寫，也沒有規定順序（2026-11-25 查證）。

## 三、設定檔的片段

### `look`：固定外貌

順序：年齡與性別 → 臉型 → 髮型與髮色 → 眼睛 → 體型。妖怪、動物、器物、巨獸這類非人角色的順序不同，見 `creatures-and-effects.md`。

| 不好 | 好 | 差在哪裡 |
|---|---|---|
| 清秀的少女，氣質溫柔 | 十七八歲的女性，圓臉，栗色及胸長捲髮，圓而大的深棕色眼睛，身形嬌小 | 「清秀」「溫柔」畫不出固定的樣子 |
| 帥氣的年輕總裁，眼神冷峻 | 三十歲左右的男性，臉型瘦長，黑色短髮往後梳，單眼皮，眉毛濃而直，肩膀寬 | 身分和性格不是外貌 |
| 年輕女子，長頭髮 | 二十歲出頭的女性，鵝蛋臉，黑色及腰直髮，中分 | 年齡要有範圍，髮型要有長度、直捲、分線 |

- **髮型最能鎖住辨識度**，寫到長度（及肩、及腰）、直或捲、瀏海、顏色、怎麼綁。
- 年齡寫「二十歲出頭」這樣的範圍，不要只寫「年輕」。
- 表情、姿勢、服裝各有自己的欄位，不要寫進來。
- **頭身比**（頭的高度佔身高幾分之一）寫在插畫與動畫裡每個人類角色的 `look`：寫實畫風是七到八頭身（`about seven heads tall`），日系動畫常見六到七頭身，Q 版是二到三頭身（`chibi proportions, about three heads tall`）。真人寫實不用寫，真人本來就是那個比例，寫體型（「肩寬，身形結實」）就好。`style_lock` 只寫「寫實比例」「Q 版比例」這類不帶數字的說法：它會加到道具圖和沒有人的背景圖，「約七頭身」出現在那裡沒有意義，還可能叫出人來。腳本看到 `style_lock` 寫了頭身比會警告。
- **身高**寫在角色的 `stature`，只寫絕對身高：「身高約一百八十公分」。腳本會把它放進角色設定圖，以及兩人以上同框、看得到身體的鏡頭（中景以外），同框時每個人的身高並排出現，高矮自然看得出來；單人鏡頭不寫，免得佔字數。不要寫「比某某高一個頭」：設定圖和沒有那個人的鏡頭也會寫到他，工具可能多畫一個人，腳本會警告。同框的人沒寫身高時腳本會提示。
- 不要用真人或既有作品角色的名字代替描述。不同工具對同一個名字的反應不一樣，有些會直接擋下；寫特徵才穩，也沒有肖像與著作權的問題。

### `tag`：短稱

最顯眼的兩個特徵加上性別年齡：「黑髮及肩的年輕女子」「短髮戴眼鏡的高個男子」。

- 角色之間的短稱要一眼分得出來，最好用不同種類的特徵（一個靠髮型、一個靠眼鏡、一個靠體型）。
- 不要放會隨造型改變的東西。服裝會換，短稱寫了「穿紅衣的」，換裝之後就錯了。
- `motion` 和 `end` 裡每次都用一模一樣的字串，腳本會檢查。
- 長得一樣的幾個人（兩個手下、一群路人）：要各自有動作，就登記成不同角色、短稱靠一個看得見的差別分開（「左臉有疤的黑衣人」「矮壯的黑衣人」）；只是一起出現，就登記成一個角色，短稱寫成複數（「兩個蒙面黑衣人」、`two masked men in black`），並填 `group`（人數），設定圖才會畫成一群人。用單數的短稱寫「站在他兩側」，工具只會畫一個人。兩個角色短稱相同、或同一個角色在一鏡出現兩次，腳本會警告。

### `outfit`、`outfit_top`、`state`：造型

每件衣物寫「顏色＋材質＋款式」，必要時加長度或合身度；由上到下，最多三四件。

| 不好 | 好 |
|---|---|
| 休閒的打扮 | 米白色粗針織高領毛衣，深灰色及踝百褶長裙，棕色短靴 |
| 古裝 | 月白色交領長袍，袖口寬大，腰間繫深青色布帶 |

- `outfit_top` 只寫腰部以上看得到的，盡量和 `outfit` 的前半段一字不差。
- `state` 寫看得見的狀態，不寫原因和嚴重程度：「左袖上臂處被血浸成深色」，而不是「受了重傷」。
- 會讓人記住的固定特徵（痣、疤、不離身的飾品）放 `marks`，不放服裝。

### `space`：場景的固定結構

第一句交代這是什麼地方（類型、時代與地域、大小、新舊），接著是三四樣不會動的東西，以及它們彼此的位置。

**時代與地域是場景細節最大的來源。**「一間茶館」可以是任何年代、任何城市；「民國初年江南小鎮的茶館」「九〇年代香港唐樓的客廳」「近未來東京的便利商店」一寫出來，牆面材質、家具式樣、燈具、招牌和雜物都跟著定了。原文沒寫就從故事推斷，列入待確認；異世界或架空的地方，寫它參考哪個時代與地域（「參考宋代汴京的木構街市」）。

| 不好 | 好 |
|---|---|
| 溫馨的房間，窗在左邊，桌上有一碗麵 | 老舊公寓的小客廳，一張木頭方桌緊靠窗邊，玄關的門在窗戶對面的牆上，一張布沙發靠著與窗戶垂直的牆 |

「溫馨」是感覺；「窗在左邊」是畫面座標，換個機位就錯；「一碗麵」是會變的東西。

### `light`、`time`：光線

一段光線描述要回答三件事：**光從哪裡來**（光源）、**往哪個方向照**、**是什麼樣的光**（顏色、軟硬、亮暗對比）。

「暖橘色的夕陽從窗戶斜照進來，室內其餘地方偏暗」三樣都有。「光線很美」「氛圍感燈光」一樣都沒有。

先用白話把光源和方向寫出來，需要更精確時再加一個術語：

| 類別 | 用詞 | 英文 | 效果 |
|---|---|---|---|
| 方向 | 順光 | front lighting | 平、清楚、陰影少 |
| | 側光 | side lighting | 立體，有戲劇性 |
| | 逆光 | backlighting | 輪廓發亮；背景很亮時變成剪影 |
| | 輪廓光 | rim light | 人物邊緣一圈亮邊，把人從暗背景裡分出來 |
| | 頂光 | top lighting | 眼窩有陰影，壓抑 |
| | 底光 | underlighting | 詭異、不自然 |
| 軟硬 | 硬光 | hard light | 影子邊緣清楚：正午的太陽、沒有罩子的燈泡 |
| | 柔光 | soft diffused light | 影子邊緣模糊：陰天、紗簾後的窗光 |
| 明暗 | 高調 | high-key lighting | 整體明亮、陰影少：輕鬆、日常 |
| | 低調 | low-key lighting | 大片暗部、只有局部亮：懸疑、沉重 |
| 色溫 | 暖光 | warm light | 燭火、鎢絲燈、夕陽 |
| | 冷光 | cool light | 月光、陰天、螢幕、日光燈 |
| 特殊 | 體積光 | volumetric lighting | 看得見的光束（穿過灰塵、霧、樹葉） |
| | 剪影 | silhouette | 人物全黑，只有輪廓 |
| | 場景內光源 | practical light | 畫面裡看得到的燈：檯燈、螢幕、燭火 |
| 時段 | 黃金時刻 | golden hour | 日出後、日落前，低角度的暖光 |
| | 藍調時刻 | blue hour | 日落後天還沒全黑，均勻的藍色調 |

backlighting、side lighting、rim light、high-key、low-key、volumetric lighting、golden hour 都出現在 Google 或可靈的官方提示詞指南裡（2026-11-25 查證），其餘是通用的攝影用語。

**布光**：上表是一道光的性質；臉上的光通常不只一道。攝影的說法是：

| 用詞 | 英文 | 意思與效果 |
|---|---|---|
| 主光 | key light | 照亮主體的主要光源，決定影子落在哪一邊 |
| 輔光 | fill light | 從另一側補亮暗部，比主光弱；沒有輔光，暗部就是全黑 |
| 三點布光 | three-point lighting | 主光、輔光加背後的輪廓光，清楚、立體、中性 |
| 光比 | lighting ratio | 主光和輔光的亮度差。光比小：臉亮而平；光比大：半張臉在暗處，戲劇性強 |
| 林布蘭光 | Rembrandt lighting | 主光從側上方照，暗的那半邊臉頰上留一塊倒三角形的亮區：沉穩、有故事 |
| 分割光 | split lighting | 光只從正側面來，臉一半亮一半暗：矛盾、雙面、危險 |
| 蝴蝶光 | butterfly lighting | 主光在正前上方，鼻子下有小小的蝴蝶形影子：美、柔和，常用在女性特寫 |

- 這些是通用的攝影術語，各工具認不認得沒有逐一查證；寫了名稱，最好再補一句看得見的結果。「光比 4:1」這種數字工具更不會懂，要寫成「臉的右半邊在陰影裡，只有眼睛一點反光」。
- 布光的術語只用在近景以內：遠景看不到臉上的光。用了也要讓光源合理：林布蘭光要有一個側上方的光源（窗、檯燈），不能憑空出現。
- 一場戲沿用同一種布光，臉上的光才不會一鏡一個樣；換布光就是在告訴觀眾情緒變了（從三點布光的日常，變成分割光的對峙）。

- 光源必須是這一鏡畫面裡合理存在的。特寫看不到屋頂的破洞，就不要寫「從屋頂破洞照下來」，用那一鏡的 `light` 改寫成「一束冷白的光從上方斜照在臉上」。
- `time` 只寫時段與天氣，飽和度與顆粒歸 `style_lock`。

### `palette`：場景的色彩

`light` 寫的是光，`palette` 寫的是整個畫面的顏色分布：哪幾個顏色為主、暗部偏什麼色、有沒有一個跳出來的點綴色。只寫光線沒說到的，十個字左右。

| 場景 | `light` | `palette` |
|---|---|---|
| 傍晚的老公寓 | 暖橘色的光從窗戶斜照進來，室內其餘地方偏暗 | 暗部偏灰藍 |
| 雨夜的夜市 | 頭頂的燈泡，紅藍霓虹倒映在濕地面上 | 紅藍霓虹的點綴色，壓在深藍灰的陰影上 |
| 陰天的當鋪 | 灰白的天光從店門的玻璃照進來，光線平而柔 | 灰白與褪色的木色為主，整體偏冷 |
| 回憶 | 褪色的暖黃光，對比偏低 | 整體偏黃、偏淡，像褪色的照片 |

| 用詞 | 英文 | 效果 |
|---|---|---|
| 暖色調、冷色調 | warm palette、cool palette | 整體偏橘黃，或偏藍青 |
| 冷暖對比 | warm and cool contrast | 亮部暖、暗部冷（或反過來），有層次 |
| 單色調 | monochromatic palette | 只用一個色相的深淺，壓抑、統一 |
| 互補色 | complementary colors | 兩個對比的顏色互相襯托（橘與青），醒目 |
| 點綴色 | accent color | 大面積的中性色裡只有一處鮮豔，視線被引過去 |
| 褪色 | faded colors | 飽和度與對比都低，常用在回憶 |

- 冷暖寫在這裡，不寫在 `style_lock`。風格鎖定句會加到每一張圖，寫了「暖色調」，夜戲的提示詞就會同時出現「暖色調」和「冷白的月光」。腳本看到風格鎖定句寫了冷暖或主色會警告。
- 不要重複 `light` 已經寫的顏色。光是暖橘色，`palette` 再寫「暖橘為主」只是多佔字數。
- `palette` 會接在這個場景每一鏡的光線後面，所以要和場景裡所有的光都相容。某幾鏡的光顏色不同（暖色的燈籠、紅色的警燈、螢幕的冷光），那幾鏡用鏡頭的 `palette` 覆寫，不然同一句提示詞裡會出現「暖琥珀色的燈籠光」和「暗紅是唯一的點綴色」這種互相打架的寫法。寫完把有覆寫 `light` 的鏡頭挑出來，逐一看光和色彩有沒有矛盾。腳本看到暖光（燭火、燈籠、夕陽）配上寫明「以冷色為主」的 `palette` 會提示；最省事的是 `palette` 只寫暗部偏什麼色、點綴色是什麼，不寫誰為主。
- 同一個地點換了時段另開場景編號時，`palette` 跟著重寫。把整季的 `palette` 排在一起看，色彩的起伏（回憶褪色、最冷的高潮夜戲、結局回暖）要和故事的起伏對得上，這就是色彩腳本。

### `style_lock`：風格鎖定句

結構：媒材或畫風 → 線條 → 上色方式 → 飽和度與對比 → 質感。

| 題材 | 可以這樣寫 |
|---|---|
| 現代都市、校園日常 | 日系賽璐珞動畫風，線條柔和，平塗上色加一層陰影，低飽和，輕微膠片顆粒 |
| 古裝、仙俠 | 國風水墨淡彩，墨線勾勒，設色清淡，大量留白，宣紙質感 |
| 懸疑、驚悚 | 寫實厚塗插畫風，線條隱沒在色塊裡，明暗對比強，暗部濃重 |
| 甜寵、輕喜劇 | 韓系條漫風，線條乾淨纖細，漸層上色，高明度、低飽和的粉彩色系 |
| 奇幻冒險 | 立體動畫電影風格，造型圓潤，材質細膩，色彩飽和 |
| 真人短劇 | 寫實攝影，數位電影機質感，清晰銳利，中等飽和，輕微顆粒 |
| 真人電影感 | 電影感寫實攝影，35mm 膠片質感，低飽和，輕微顆粒，柔和的高光滾降 |
| 真人懷舊 | 寫實攝影，16mm 膠片質感，顆粒明顯，色彩褪淡，對比柔和 |

- 不寫背景、人物、天氣、光線方向，也不寫冷暖與主色（那歸各場景的 `palette`）。真人寫實也不寫「自然膚質」「毛孔」：它會加到道具圖和空景，寫到皮膚就可能多出一個人；膚質寫在角色的 `detail`，腳本看到會警告。它會被加到每一張圖上，包含純色背景的角色設定圖、夜戲和回憶。懸疑片想要整體偏冷，就讓每個場景的 `palette` 都偏冷，個別場景（溫暖的回憶）才有辦法例外。
- 用特徵描述風格，不要只丟作品名、畫師名或工作室名。理由和 `look` 不寫名人一樣。
- 比例可以寫，但只寫「寫實比例」「Q 版比例」這類說法，不寫「約七頭身」：這一句會加到道具圖和空景背景圖。具體的頭身比寫在人類角色的 `look`。
- 上色方式寫「平塗」「線條乾淨」時，工具會連材質與細節一起簡化，整批圖看起來單薄。要細節就寫「層次分明的上色」「材質刻畫細緻」「線條粗細有變化」這類說法，具體的細節寫在各資產的 `detail`。
- 定了就不要改。一改，所有資產圖和首幀都要重出。
- 工具支援風格參考圖時，鎖定句照寫，參考圖是加強，不是取代。

### `props[].desc`：道具

十五字（英文十個詞）以內的名詞短語：材質、顏色、形狀、新舊，挑兩三個最能辨認的。「一把磨得發亮的舊銅鑰匙」。狀態（拆了沒、亮不亮）寫在鏡頭裡。太長或有逗號腳本會提醒。

它會被代入句子中間（「右手握著{P01}」），所以寫成一個不含逗號的短語。`a square pale-blue biscuit tin, paint worn at the corners` 代進去之後句子會斷掉。

英文還要避開 with 片語：特徵放在名詞前面當形容詞，寫成 `a battered square pale-blue biscuit tin`、`a plain-guarded steel sword`。with 片語在描述的尾端，代進句子後，後面接的位置或動作會黏到 with 後面的名詞上：`a sword with a round guard` 代進「holding {P01} by the hilt」，讀起來是護手在劍柄旁；`a lantern with oiled-paper panels and a top handle` 代進「{P02} glowing」，glowing 黏到 handle 上。腳本看到英文道具描述有 with 會提示。寫完把幾個用到它的片段代進去唸一遍。

其餘的特徵（大小、扣環、提把、磨損的位置）寫在道具的 `detail`，它只進道具圖，沒有長度與逗號的限制。

### `detail`：只進資產圖的細節

資產圖是每一鏡的參考，畫得越細，鏡頭能照著畫的東西越多；鏡頭的片段卻要精簡，每多一個細節就多一個做錯的地方。兩者分開寫：鏡頭用的片段照常精簡，近看才看得到的東西寫在 `detail`，腳本只把它接進資產圖。沒有 `detail`，資產圖就只有鏡頭用的那幾個字，畫出來會很單薄。

| 寫在哪裡 | 進哪一張圖 | 寫什麼 |
|---|---|---|
| 角色的 `detail` | 設定圖、頭像、表情組圖 | 皮膚、髮絲、手的質感 |
| 造型的 `detail` | 這個造型的設定圖 | 布料、縫線、鈕扣、磨損與皺褶的位置、鞋 |
| 場景的 `detail` | 場景定稿圖 | 牆面、地面、木料的紋理與磨損，固定的陳設 |
| 機位的 `detail` | 這個機位的背景圖 | 從這個位置看得到的陳設與材質 |
| 道具的 `detail` | 道具圖（狀態圖由它改出來） | 大小、各部位的材質與做工、磨損的位置 |
| 特效的 `detail` | 特效參考圖（每個狀態都接上） | 粒子的大小與疏密、邊緣銳利或柔散、內部的紋理與層次 |

- 寫做工、材質、磨損，不寫新的辨識特徵。設定圖上有、鏡頭的文字沒寫的配件（手錶、胸針），文字生成的首幀不會有，兩邊對不起來；會讓人記住的特徵放 `look` 或 `marks`。
- 照「整體 → 部位 → 表面」的順序：先大小與輪廓，再各部位的材質與做工，最後是磨損、污漬與質感。
- 場景與機位的 `detail` 不寫人，也不寫會移動、會變狀態的東西，理由和 `space` 一樣。寫到人腳本會警告。
- 這一集用到的資產沒寫 `detail`，腳本會提示一行，列出是哪幾個。

## 四、分鏡檔的片段

### `pos`、`gaze`、`hands`、`face`：走位

| 欄位 | 要寫到 | 例 |
|---|---|---|
| `facing` | 朝向，用用詞表的詞：正面、半側朝左、半側朝右、側面朝左、側面朝右、背面。左右指臉朝畫面哪一邊 | 半側朝左 |
| `pos` | 在畫面哪裡（左右、上下、前中後景）＋姿勢。填了 `facing` 就不用再寫朝向 | 坐在畫面右側中景的桌前，上半身前傾 |
| `gaze` | 看誰或看什麼＋方向 | 抬頭看向畫面左上方的前景男子 |
| `hands` | 兩隻手各自的位置、動作、拿著什麼；看不到也要說 | 右手握著門把，左手自然下垂 |
| `face` | 具體的肌肉變化，一個主表情加一個不完美的細節 | 眉頭微皺，嘴唇抿成一線，視線有點飄 |

| 不好 | 好 |
|---|---|
| 站在旁邊，很生氣 | 站在畫面左側中景，身體朝向畫面右側，雙臂交叉抱在胸前；眉頭緊鎖，下顎繃緊 |
| 拿著杯子 | 右手握著白色馬克杯的把手，杯子舉在胸前；左手扶著杯底 |

**朝向用 `facing` 填，不寫在 `pos` 的自由文字裡。** 用詞固定，正反打的兩個人才看得出方向是不是相對（甲半側朝右、乙半側朝左）；同一個機位裡同一個人上一鏡朝左、下一鏡朝右，腳本會提示，多半是越軸。背對鏡頭的人除了 `facing` 填「背面」，還要設 `partial: true`，否則提示詞會寫一整段看不到的臉。

**情緒要寫成看得見的表現。** `face` 只寫「難過」，工具會給一張標準的難過臉；寫出眉、眼、嘴與呼吸，才有表演。只寫一個情緒詞時腳本會提示。下面是常見情緒的寫法，一次挑兩三個部位，不要全部堆上去：

| 情緒 | 眉與眼 | 嘴與下巴 | 身體與呼吸 | 英文 |
|---|---|---|---|---|
| 驚訝 | 眉毛上揚，眼睛睜大 | 嘴微微張開 | 身體往後一縮，屏住呼吸 | brows raised, eyes wide, lips parted, a sharp intake of breath |
| 壓抑的怒氣 | 眉頭壓低，眼神直盯不移 | 下顎繃緊，嘴唇抿成一線 | 鼻翼微張，手指慢慢收緊 | brows drawn low, jaw clenched, lips pressed thin, fingers slowly tightening |
| 強忍淚水 | 眼眶泛紅，視線往上或往旁邊移開 | 嘴角往下壓，下巴輕輕發抖 | 用力吞嚥，呼吸變淺 | eyes red-rimmed and glistening, gaze sliding away, chin trembling, swallowing hard |
| 心虛 | 視線游移，不敢對上 | 抿嘴，或擠出一個太快的笑 | 摸後頸、整理袖口，肩膀微縮 | eyes darting away, a quick strained smile, rubbing the back of the neck |
| 冷笑 | 眼睛沒有笑意，微微瞇起 | 一邊嘴角上揚 | 下巴略抬，身體不動 | one corner of the mouth lifted, eyes cold and slightly narrowed, chin raised |
| 恐懼 | 眉頭往上往中間擠，眼白露得多 | 嘴唇發白、微張 | 往後退半步，雙臂收向身體，呼吸急促 | brows pulled up and together, whites of the eyes showing, shallow rapid breathing |
| 釋然 | 眉頭鬆開，眼睛半閉 | 長長吐一口氣，嘴角放鬆 | 肩膀垂下來 | brows relaxing, eyes half closing, a long slow exhale, shoulders dropping |
| 尷尬 | 視線落向地面或旁邊 | 嘴角僵著，笑得不自然 | 耳朵或臉頰泛紅，手不知道放哪裡 | a stiff awkward smile, flushed cheeks, eyes on the floor, hands fidgeting |
| 失望 | 眼神暗下來，視線垂下 | 嘴角往下，輕輕嘆氣 | 肩膀垮下，手垂下來 | eyes dimming and dropping, corners of the mouth falling, a quiet sigh, shoulders sagging |
| 決心 | 眉頭微壓，眼神定住 | 嘴唇閉緊，下巴收 | 深吸一口氣，站直 | steady narrowed gaze, lips firmly closed, a deep breath, straightening up |
| 疲憊 | 眼皮半垂，眼下發暗 | 嘴唇乾，微微張著 | 動作慢，肩膀下沉，靠著東西 | heavy-lidded eyes with dark circles, slow movements, slumped shoulders |
| 懷疑 | 一邊眉毛挑起，眼睛微瞇 | 嘴角一邊往內收 | 頭微側，身體往後靠 | one brow raised, eyes narrowed, head tilted slightly, leaning back |
| 羞怯 | 視線往下，偶爾抬眼又移開 | 抿著嘴笑 | 頭微低，手指絞在一起 | glancing up then quickly away, a small closed-mouth smile, fingers intertwined |
| 悲傷 | 眉頭內側上揚，眼神空 | 嘴角往下 | 呼吸沉，動作停住 | inner brows raised, eyes unfocused, corners of the mouth turned down, motionless |

- 「不完美的細節」比完整的標準表情更像真人：嘴上在笑、眼睛沒笑；強忍時下巴的那一下抖動。一個主表情配一個細節就夠。
- 情緒強的時刻，身體比臉更好拍、也更穩：背影的肩膀在抖、手把杯子握得指節發白。特寫的臉是生成工具最容易做僵的地方。
- 上表是寫法的起點，不是標準答案。角色的個性會改變表現：同樣是生氣，有人會笑，有人會安靜下來。

兩個人都完整入鏡時，髮色和服裝顏色容易互相串。能避就避：讓其中一人用 `partial`（背影、前景虛焦）；避不掉時，每個人的 `pos` 都以畫面位置開頭（「畫面左側的…」），並確認兩人的描述在顏色上差得夠遠。

### `bg`、`frame`、`end`

- **`bg`**：這一鏡的取景範圍裡實際看得到的背景，並說明清楚還是虛化：「背景是虛化的窗框與窗外的暮色」。同一個機位的鏡頭把它登記在 `setups`，不要每鏡重寫。
- **`frame`**：主體放在哪、前景有什麼、景深、留白，原則見 `shot-craft.md` 第七節。焦段（廣角、長焦、35mm）有自己的欄位 `lens`，見 `fields.md`。景深的用詞：

  | 用詞 | 英文 | 效果 | 常用在 |
  |---|---|---|---|
  | 淺景深 | shallow depth of field | 只有主體清楚，背景虛化 | 人物近景、插入鏡頭 |
  | 深焦 | deep depth of field | 前後都清楚 | 建立鏡頭、前後景都有戲 |
  | 前景虛焦 | out-of-focus foreground | 前景模糊，襯出後面的主體 | 過肩鏡頭、隔著東西看 |
  | 散景 | bokeh | 背景的光點化成柔和的圓斑 | 夜景、霓虹、燈串前的人物 |

  這些是攝影用語，效果因工具與畫風而異；真人寫實和 3D 動畫最認得，平塗的 2D 畫風用了也不一定有效果。
- **`end`**：只寫和首幀不一樣的地方，用短稱指人。有運鏡時寫運鏡之後看到的畫面（「畫面比首幀略為推近，女子的臉佔畫面一半」）。

### `motion`：怎麼動

四步驟的寫法在 `fields.md`。另外注意：

- **動詞照戲的力道選**：安靜的戲用走、轉、抬、放、推、握；衝突的戲照實寫撲、衝、甩、踹，再寫出力道落在哪裡（「門板撞上牆，震下一陣灰」）。選定的工具做不好快速的動作時（`tool_limits.fast_motion` 是 `false`），才把這類動作拆成預備、結果與反應，見 `anti-ai-rules.md` 第二部分。
- **一個主動作，順序講清楚**：一個主動作，加一兩個微動作。連續的幾拍用「先…接著…」寫出順序，觀眾和工具都知道先發生什麼。
- **寫動作本身，不寫情緒的名字**：

  | 不好 | 好 |
  |---|---|
  | 她很驚訝 | 黑髮及肩的年輕女子眼睛微微睜大，吸了一口氣，肩膀跟著抬起 |
  | 風吹過，頭髮飄動，他轉身離開，門關上 | 拆成兩鏡：一鏡是風吹動頭髮、他抬手按住；一鏡是門在他身後關上 |
  | 兩人激烈爭吵 | 短髮戴眼鏡的高個男子上身前傾，右手食指點了一下桌面；黑髮及肩的年輕女子身體往後靠，其餘保持靜止 |

- 可靈與 Seedance 的官方指南支援在一段提示詞裡用時間碼或鏡頭編號排好幾個動作（「0–3 秒：…」「鏡頭一：…」）。這個 skill 是一鏡一個動作、各自生成，腳本不會產生這種寫法；使用者想把相鄰幾鏡合成一段生成時，再照該工具的指南手動合併。

### `voice`、`line.tone`、`sound`：聲音

- **`voice`**（角色的聲線）：這個人的聲音本身，整季不變。性別年齡、音色、語速：「二十多歲的女聲，音色偏低，說話輕而慢」「蒼老的男聲，沙啞」。英文寫成名詞短語 `a low, gravelly male voice`，腳本會寫成 `says in Mandarin Chinese, in a low, gravelly male voice`。原生音訊時它進每一句台詞；不寫，同一個角色每一鏡的聲音都會不一樣。
- **`tone`**（這一句的語氣）：音量、語速、情緒，挑兩樣寫。「低沉、遲疑」「壓低聲音，說得很快」。音色已經在 `voice`，這裡只寫這一句怎麼說；英文寫成說法 `hesitantly, almost a whisper`、`quickly, under his breath`，不要再寫 `in a … voice`，和 `voice` 疊在一起會重複。
- **`sound`**：環境音加一兩個具體的音效，寫出聲音的來源：「遠處的車聲，門軸的吱呀聲」。「緊張的氛圍音」沒有來源，生成工具只能自己編。只寫畫內聲（故事裡的人也聽得到的聲音）；配樂與旁白是畫外聲，不寫進影片提示詞。畫內聲、擬音、音橋的區別見 `shot-craft.md` 第十三節。
- 不想要工具自己加字幕或配樂，寫在 `audio_suffix`（「不要字幕，不要背景音樂」）。這是少數官方認可有效的否定寫法。

## 五、英文片段

- **寫名詞短語，不寫完整句子。** 開頭不大寫，結尾不加句號，腳本會處理。
  - `look`：`a woman in her early twenties, oval face, shoulder-length straight black hair with blunt bangs, dark brown almond eyes, slim build`
  - `outfit`：`an off-white chunky-knit turtleneck sweater, a dark grey ankle-length pleated skirt`（順序是顏色、材質、款式、物件）
- **`tag` 用 the 開頭的名詞短語**：`the young woman with shoulder-length black hair`。`motion` 和 `end` 裡每次都用完全相同的字串。
- **`pos`、`gaze`、`hands` 用現在分詞**：`sitting at the table in the right midground, upper body turned toward frame left`、`looking up at the man in the left foreground`。
- **`motion` 用現在式的子句**：`the young woman with shoulder-length black hair lowers her head and looks at the envelope; the curtain sways once in the breeze`。
- **畫面位置的說法**：frame left、frame right、the upper third of the frame、foreground、midground、background。
- **不要逐字直譯。**「神情平靜，略帶疲憊」是 `calm expression with a trace of tiredness`，不是 `expression calm, slightly tired feeling`。寫完自己唸一遍，不像英文就重寫。
- 給人看的欄位（`action`、`risk`、`continuity`、`post`、`desc`）仍然用使用者的語言。

## 六、提示詞太長的時候

工具未定時不縮。工具定了、`prompt_limits` 填了上限，腳本說哪一鏡超過了，照這個順序縮，前面的做完還不夠才往下：

1. `bg` 寫短，或改用機位的 `bg`，不要讓整段 `space` 進到近景裡。
2. 填 `outfit_top`，中景以內就不會帶到下半身的服裝。
3. 背影、前景虛焦的角色設 `partial: true`，腳本只寫短稱和服裝。
4. `frame` 刪掉修飾性的詞，只留位置。
5. `pos`、`gaze`、`hands` 各留一句最關鍵的。

`look` 與 `style_lock` 最後才動，而且要動就是改 `bible.json`、全片一起改。只在某一鏡把外貌寫短，那一鏡的角色就會走樣。

工具支援多張參考圖時，改用參考圖模式是縮得最多的做法：整段外貌與服裝都不進提示詞，見第七節。

## 七、參考圖模式

文字模式把角色的整段外貌寫進每一鏡，靠文字一字不差來維持一致；參考圖只是加強。現在多數圖像工具能一次掛好幾張參考圖、並在提示詞裡用編號指稱（即夢圖像、FLUX、可靈與即夢的全能參考），這時長相交給參考圖比交給文字穩：文字描述和參考圖有出入時，工具會在兩者之間搖擺，臉反而漂。

`project.ref_mode` 填 `參考圖`，腳本就這樣組合首幀：

- **角色**：「圖1中的黑髮及肩的年輕女子」＋走位（`pos`、`gaze`、`hands`、`face`）；近景以內、正面入鏡時再接「（臉部參照圖2）」，指向這個角色的頭像。`look`、服裝、`state`、`marks` 不進提示詞，它們已經在那張造型設定圖上。所以造型變體的設定圖一定要先定稿，受傷、換裝的樣子要畫在圖上。
- **局部入鏡**（`partial` 寫成片段）：片段照寫，後面接「（顏色與質感參照圖2）」。只借袖口、鞋子、毛色的顏色和質感，袖口才會對，工具也不會照整張設定圖畫出整個人。
- **背景**：「背景參照圖3：＋這一鏡的 `bg`」。有機位用機位背景圖，沒有就用場景定稿圖。`bg` 仍然要寫，它說的是這一鏡看得到哪一部分、清楚還是虛化。
- **道具與特效**：描述照寫，後面註明（圖4）。
- 光線、色彩、怎麼拍、風格鎖定句不變。

參考圖的順序由腳本排：角色的造型設定圖（照 `cast` 的順序；近景以內、正面入鏡的人，緊接著是他的頭像）→ 背景圖 → 道具圖（寫了狀態就是那個狀態的圖）→ 特效參考圖 → `refs` 額外寫的。每一鏡的生成資料會列出這個順序，使用者照順序上傳，提示詞裡的編號才對得上。

- **指稱語法**照工具：`ref_syntax` 填 `"@图片{n}"`、`"@Image{n}"` 或 `"image {n}"`，`{n}` 換成序號。查 `tool-capabilities.md`。
- **張數上限**填 `ref_max`。超過時腳本會警告；解法是把背影角色改成 `partial` 片段、少引用一件道具，或拆鏡。
- **短稱更重要了。** 提示詞裡只剩短稱和編號在指人，兩個角色的短稱要用不同種類的特徵（一個靠髮型、一個靠眼鏡）。
- **設定圖的姿勢會被照抄。** 設定圖用自然站姿，`pos` 寫具體的姿勢與朝向，工具才不會把設定圖的站姿直接搬進每一鏡。
- 影片提示詞（圖生影片）不受影響：首幀圖已經決定了長相，影片提示詞本來就只寫動作與運鏡。`video_mode` 是 `t2v` 時，參考圖模式改作用在影片提示詞，用的是影片工具的參考圖。

不確定工具能不能用編號指稱參考圖時，用文字模式。文字模式在任何工具上都能用，只是長、而且一致性靠文字。

## 八、真人寫實

`project.medium` 填 `真人寫實` 時（真人劇、多數的 AI 短劇、電影感短片），寫法和插畫有幾處不同。觀眾對真人的臉和身體最敏感，一點不自然就看得出是 AI。

**外貌（`look`、`detail`）寫成真人，不寫成美圖。**

| 不好 | 好 | 差在哪裡 |
|---|---|---|
| 完美無瑕的肌膚，精緻的五官 | 二十七八歲的女性，鵝蛋臉，左眉尾有一顆小痣，皮膚白而略乾，笑起來眼角有細紋 | 「完美」「精緻」會被畫成磨皮過度的塑膠臉 |
| 帥氣的霸總，八塊腹肌 | 三十出頭的男性，下顎線清楚，鬍渣剃得很乾淨，眉間有一道淺淺的川字紋，肩寬，身形偏瘦 | 寫看得見的特徵，加一兩個不完美的地方 |

- 年齡寫具體（「四十五歲左右」），年齡的痕跡也寫：法令紋、眼袋、白頭髮。沒有任何痕跡的臉，看起來年紀模糊、像假人。
- 膚質寫在角色的 `detail`：毛孔、細小的雀斑、嘴唇的紋路、手背的青筋。它進定妝照，臉在鏡頭裡才有真實的質感可以參照。
- 不用真人演員或名人的名字當描述：工具會擋，也有肖像權的問題。要「像某一類人」就寫那一類人的特徵。
- 服裝寫真實的布料與穿著痕跡（「洗到微微褪色的牛仔外套，袖口磨白」），不要寫「時尚的穿搭」。妝髮也是造型的一部分，寫在 `outfit` 或 `state`（「口紅暈開」「頭髮被雨打濕貼在額頭」）。

**鏡頭寫成攝影。** 真人寫實的工具最認得攝影的說法：

- 焦段填 `lens`（35mm、85mm），同一場戲的正反打用同一個焦段。
- 景深與散景寫在 `frame`：近景用淺景深，建立鏡頭用深焦。
- 光寫真實存在的光源：窗光、路燈、螢幕、霓虹，加上方向與軟硬，見第三節的光線與布光。沒有來源的「電影感燈光」只會得到過度打光、像棚拍的畫面。
- 質感寫在 `style_lock`：膠片或數位電影機、顆粒、高光怎麼過渡。不要寫「8K、超高清、大師作品、極致細節」這類詞，它們不描述畫面，只會讓畫面變得過度銳利、像廣告修圖。

**表演要小。** 真人的表情一誇張就假。`face` 寫細微的變化（「嘴角動了一下，沒有笑出來」），一個主表情配一個不完美的細節；大哭、大笑、驚叫留給高點，而且多用身體與反應鏡頭來演。`motion` 寫真人會有的小動作：換重心、摸一下鼻子、吞嚥。

**定妝照**：`medium` 是真人寫實時，腳本把角色設定圖寫成攝影棚的定妝照（正面、側面、背面全身照）、表情組圖寫成表情測試照，場景定稿圖寫成實景照片。它們就是這個角色的「選角」：定稿之後，整部片都照這張臉，所以第一張要挑到滿意為止。
