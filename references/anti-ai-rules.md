# 穩定性與去 AI 感規則

分兩部分。**第一部分**（一到五節）任何工具、任何形式都適用：動作的物理、活人感、真人寫實特有的 AI 感、一致性、節奏。**第二部分**（第六節）是工具定了之後，照那個工具做不好的地方換拍法；工具未定時不用它。最後是自查清單與後製建議。

# 第一部分：任何工具都適用

## 一、動作要符合物理

- 寫出起因與結果：「風吹起頭髮，她抬手按住」，而不是「頭髮飄動」。沒有起因的運動看起來像特效。
- 次要運動（頭髮、衣擺、水、煙）的方向和強度要與主動作一致。
- 有重量的動作（拿重物、坐下、跌倒）要有預備和緩衝：重心先往下，再起來。要讓觀眾感覺到重量，可以拆成兩三個短鏡頭。
- 速度與力道照戲寫。快的就寫快，並寫出力道落在哪裡（「門板撞上牆，震下一陣灰」）；安靜的戲寫自然速度、小幅度。不要每一鏡都寫「緩慢」：整片像慢動作，是最常見的 AI 感之一。
- 人物移動時腳要踩在地上、有重心轉換；人和鏡頭一起動時，寫清楚兩者的方向（「鏡頭跟著女子向右移」），工具才不會讓背景亂滑。

## 二、活人感

- 每鏡加一兩個微動作：眨眼、呼吸起伏、手指小動作、視線轉移、吞嚥。完全靜止的臉像蠟像。
- 表情不要完美：略帶疲憊、嘴角微僵、眼神游移，比標準的「微笑」「悲傷」更像人。各種情緒怎麼寫成看得見的表現，見 `prompt-writing.md` 的情緒對照表。
- 視線要有落點：`gaze` 寫看誰、看什麼。沒寫的眼睛常常是空的，看向不存在的地方。
- 背景有輕微的自然動態：樹影、窗簾、遠處路人、光影變化，幅度小。
- 對話戲要有反應鏡頭和停頓，不要每一鏡都在說話。

## 三、真人寫實的 AI 感

`medium` 是真人寫實時，觀眾對臉和身體最敏感。常見的破綻與寫法：

| 看起來很 AI | 原因 | 寫法 |
|---|---|---|
| 塑膠皮膚、磨皮過度 | 寫了「完美無瑕」「精緻」「8K」；沒寫膚質 | 膚質寫在角色的 `detail`（毛孔、細紋、雀斑）；刪掉「完美」類的詞；風格鎖定句寫膠片質感與輕微顆粒（不寫皮膚，它會進道具圖與空景） |
| 每個人都是同一張網紅臉 | 外貌只寫「漂亮」「帥氣」 | 每個角色寫一兩個不完美、但辨識度高的特徵（眉尾的痣、有點歪的鼻樑），年齡的痕跡照實寫 |
| 處處都亮、像棚拍 | 光沒有來源，只寫「電影感燈光」 | 寫畫面裡真的存在的光源與方向，讓暗部是暗的，見 `prompt-writing.md` 的光線與布光 |
| 眼神空洞 | 視線沒有落點；眼睛沒有反光 | `gaze` 寫看什麼；近景寫眼睛裡映著窗光或燈 |
| 衣服太新、沒有皺褶 | 服裝只寫款式 | 寫穿著的痕跡：褪色、袖口磨白、坐出來的皺褶 |
| 動作太順、像在飄 | 沒有重心與腳步 | 寫重心轉換、腳踩地、手碰到東西時的阻力 |
| 背景路人一模一樣 | 人群寫得太多、太清楚 | 背景的人少、虛化、各做各的事 |
| 表演太滿 | 每一鏡都是大表情 | 表演寫小，大情緒留給高點，多用身體與反應鏡頭 |

## 四、一致性

- 先生成並定稿資產圖（角色設定圖或定妝照、頭像、表情組圖、場景定稿圖、機位背景圖、道具圖與道具的狀態圖），之後每一鏡都掛它們當參考。近景以內的臉靠頭像，全身設定圖的臉太小。
- 工具能一次掛好幾張參考圖、並用編號指稱時，用參考圖模式（`ref_mode`）：長相交給設定圖，提示詞不再重複整段外貌，兩邊才不會互相拉扯。見 `prompt-writing.md` 第七節。
- 冷暖與主色寫在場景的 `palette`，不寫在風格鎖定句；否則夜戲和回憶的色調會和自己的光線打架。
- 同一個角色的其他造型，拿第一個造型的設定圖做圖像編輯，不要重新生成，臉才不會變。
- 同一個場景要換角度時，拿場景定稿圖做圖生圖，不要重新用文字生成。
- 尾幀從首幀圖編輯而來，不要重新生成。
- 只有「接續」的鏡頭才拿上一鏡的最後一幀當首幀；「切」的鏡頭各自生成首幀。
- 同一場戲沿用同一組光線和色調；短暫的光線變化用那一鏡的 `light`，時段真的換了才換場景編號。真人寫實的正反打也沿用同一個焦段。
- 反覆出現的道具登記在 `props`，用 `{P01}` 引用，不要每次重新描述。道具的狀態（拆開、空了）從道具圖改出來，不要重新生成，形狀和材質才不會變。
- 同一個機位的鏡頭登記在 `setups`，背景只寫一次，並先定稿那個機位的背景圖；同機位的後續首幀，拿前一張首幀圖做圖像編輯。
- 軸線：兩個人對話時，整場戲裡甲始終在畫面一側、乙在另一側，視線方向相對。要越過軸線時先插一個中性鏡頭（正面、空鏡或物件特寫）。視線匹配、運動方向、30 度規則見 `shot-craft.md` 第四節。

## 五、節奏

- 用鏡頭長短做節奏：鋪陳的鏡頭長一點，衝突和反應的鏡頭短一點。
- 遠、中、近交替，讓觀眾知道人在哪裡、在做什麼、心裡怎麼想。
- 空鏡和物件特寫可以用來換氣、表示時間流逝，也是最穩定、最不會出錯的鏡頭。漫劇裡這些鏡頭常常可以做成靜幀運鏡，連影片都不用跑。
- 慢動作（升格）和定格只留給一兩個要停住的瞬間。
- 漫劇：開頭三秒內要有衝突或懸念；每個旁白句子配一到兩個畫面；結尾停在懸念上。
- 短劇：開頭三秒進衝突；每一二十秒要有新資訊、反轉或爽點；爽點後一定給旁人的反應；結尾停在卡點的反應上。

# 第二部分：工具定了之後

## 六、替代拍法

**工具未定時不用這一節。** 照戲需要的拍法寫，在 `risk` 記一句這一鏡難在哪裡、做壞了的備案。工具定了之後，下面兩種情況才從這張表挑拍法：

- 這個工具確定做不好的：`tool_limits` 裡是 `false` 的項目（見 `tool-capabilities.md`）。
- 生成測試時做壞、同樣的錯出現兩次以上的鏡頭。

換拍法是為了達成同樣的戲劇效果，不是把戲拿掉：先照 `shot-craft.md` 想清楚這個節拍要讓觀眾看到什麼，再從下表挑一種做得穩的拍法。表裡的「物件特寫」在分鏡檔填 `type: 插入`、`size: 特寫`。

| 難拍的鏡頭 | 什麼時候換 | 替代拍法 |
|---|---|---|
| 打鬥、揮拳、武打 | `fast_motion` 是 `false`，或測試做壞 | 出手前一鏡，切到對方的反應或受擊後的結果；剪影；兵器或拳頭的物件特寫；用聲音帶過 |
| 奔跑、大幅走位 | `fast_motion` 是 `false`，或測試做壞 | 腳步特寫、背影遠景、跑過畫面的短鏡頭；起跑與抵達各一鏡，中間用剪接省略 |
| 多人肢體接觸（擁抱、握手、拉扯） | 測試做壞 | 接觸前一鏡，切到接觸後的近景；用過肩或背影遮住接觸點；拆成各自的反應鏡頭 |
| 手部特寫、拿取細小物件 | 測試做壞 | 改成中景讓手佔比變小；手半遮擋；直接拍物件特寫，手只從畫面邊緣入鏡（用 `partial` 寫成「一隻從畫面右緣伸入的手」）或不入鏡 |
| 轉身、快速轉頭 | 測試做壞 | 轉身前一鏡、轉身後一鏡，中間切掉 |
| 飲食、倒水、書寫 | 測試做壞 | 拍物件特寫或結果（放下的空杯、寫好的紙），過程用遮擋或省略 |
| 人群、大場面 | 測試做壞 | 遠景加虛化的背景人物；用局部（幾雙腳、幾個背影）代替全體 |
| 兩張以上的臉同時清楚入鏡 | 測試時臉或髮色互串 | 過肩鏡頭，前景的人只露肩背；或拆成交替的單人鏡頭 |
| 人物和鏡頭同時大幅移動 | 測試時背景扭曲、臉變形 | 人物有大動作時鏡頭固定；要運鏡時讓人物幾乎不動 |
| 說話的嘴型 | 聲音方案是後配口型，或工具的口型對不上 | 口型另外用對口型工具做，生成時鏡頭固定、嘴唇閉合；或讓說話的人背對鏡頭、拍聽的人 |
| 需要讀得懂的文字 | `text` 是 `false` | 畫面裡留空白，後製加字；寫字的物件（手機、信紙）在那一鏡保持靜止、朝向鏡頭、不被手擋住 |
| 變身 | 測試做壞 | 變身前一鏡給預兆，閃白、煙或光把人蓋住，變身後一鏡用原形的造型變體；想看到「變」的過程就拍牆上的影子。見 `creatures-and-effects.md` |
| 法術對打、能力相撞 | `fast_motion` 是 `false`，或測試做壞 | 出手前的預兆一鏡（光在掌心聚起來）→ 閃白或反應鏡頭 → 結果一鏡；相撞的那一下交給後製，或用聲音帶過 |
| 數量多的非人部位（九條尾巴、多隻手、三隻眼） | 測試時數量不對 | 用背面、局部、剪影或影子，不要每鏡完整入鏡；在 `risk` 註明生成後要數一下 |
| 特效裡的文字與數字、快速的爆發 | `text` 或 `fast_motion` 是 `false` | 特效的 `make` 填「後製」，畫面上留位置 |
| 甩鏡、環繞、滑動變焦 | `complex_camera` 是 `false` | 甩鏡改成轉場：前後兩鏡各自固定，剪接時接起來；環繞與滑動變焦改成緩慢推近 |

快的感覺交給剪接時，每一鏡的 `motion` 寫正常速度、小幅度，速度來自短鏡頭快切與聲音，見 `shot-craft.md` 第十節。

## 七、自查清單

腳本已經檢查的（不能執行腳本時要自己查）：

- [ ] 場景與角色編號都對得上設定檔
- [ ] 每個入鏡角色都寫了位置、視線、手部
- [ ] 每鏡都有 `motion`，有角色的鏡頭有 `end`
- [ ] `motion` 用短稱指人，沒有「同上」之類的指代
- [ ] 對白或旁白的長度塞得進這一鏡
- [ ] 沒有跳接：相鄰兩鏡不會主體、景別、角度、機位全都一樣卻切了一刀
- [ ] 鏡頭長短有變化
- [ ] 景別、鏡頭類型、角度、焦段、運鏡用的是用詞表裡的詞；帶方向的運鏡寫了方向
- [ ] 近景以內的鏡頭有 `bg`（自己填，或由機位提供）
- [ ] 場景出現後的頭三鏡內有遠景或全景
- [ ] 「對白」的說話者正面入鏡；沒入鏡的是「畫外音」
- [ ] 「接續」的鏡頭和上一鏡同場景、同角色、同機位，而且沒有填轉場
- [ ] 場景描述沒有用畫面左右
- [ ] 有 `episode_length` 時，整集長度在範圍內；分集表每一集都有鉤子、爽點、卡點
- [ ] 風格鎖定句沒有寫冷暖或主色（寫在場景的 `palette`）
- [ ] 有 `plan` 時每一鏡都填了 `beat`；每個節拍都有鏡頭；高點的節拍有全場最近的景別（插入特寫也算）和最長的一鏡
- [ ] 場景與機位的描述（含 `detail`）沒有寫到人（它們會進沒有人物的場景定稿圖與機位背景圖），也沒有用「頭頂」「腰部」這類身體部位說位置
- [ ] 這一集用到的角色、造型、場景、機位、道具與特效都有 `detail`，只寫做工、材質、磨損與陳設，沒有新的辨識特徵
- [ ] 一群人登記成一個角色時填了 `group`（人數）
- [ ] 道具描述沒有逗號，中文十五字、英文十個詞以內；英文沒有 with 片語
- [ ] 每個角色的短稱都不一樣；同一個角色沒有在一鏡裡出現兩次
- [ ] 片段裡沒有「後製」「字幕」「花字」這類替空白說明用途的字眼（負面詞除外）
- [ ] 同一個機位、取景沒有變近的鏡頭裡，登記過的道具沒有沒交代就不見
- [ ] 有台詞的角色都寫了聲線（`voice`），有旁白就寫了 `narrator_voice`
- [ ] 朝向用 `facing` 的用詞；背對鏡頭的人設了 `partial`；同一個機位裡同一個人沒有左右對調
- [ ] 兩人以上同框、看得到身體的鏡頭，每個人都有 `stature`，而且只寫絕對身高；風格鎖定句沒有寫頭身比
- [ ] 暖光的鏡頭沒有配上寫明「以冷色為主」的 `palette`；場景本身的光不暖、這一鏡才換成暖光時，`palette` 裡有那種暖色，或這一鏡覆寫了 `palette`
- [ ] 道具被收走、拿出來，寫在 `motion` 或 `end`，不只寫在 `continuity`
- [ ] `face` 不是只有一個情緒詞
- [ ] `sound` 只寫故事裡聽得到的聲音，配樂寫在 `music`
- [ ] 有分狀態的發光特效，各狀態的光分開寫（`light_states`）
- [ ] 兩個以上角色同場的戲寫了走位（`blocking`），而且沒有用畫面左右
- [ ] 靜幀運鏡只用推近、拉遠、搖、移；靜幀的鏡頭沒有填慢動作；說話的鏡頭沒有做成靜幀（後配口型或原生音訊時）
- [ ] 機位貼地時沒有配俯拍或頂拍

工具定了、填了對應欄位之後，腳本才檢查的：

- [ ] 成片秒數加上裁頭尾，不超過工具單段秒數（`clip_range`、`clip_lengths`）
- [ ] 組合後的提示詞沒有超過工具的長度上限（`prompt_limits`）
- [ ] 參考圖模式下，每一鏡的參考圖張數沒有超過工具上限（`ref_max`）
- [ ] 用 Midjourney 時填了 `image_suffix`，裡面的 `--ar` 和畫幅一致
- [ ] 工具沒有負面詞欄位時，沒有填負面詞（`tool_limits.negative`）
- [ ] 工具寫不好字時，沒有要求畫面出現可讀文字，片段裡也沒有「數字」「文字」（`tool_limits.text`）
- [ ] 工具做不好快速動作時，`motion` 沒有「快速、劇烈、瞬間」這類字眼（`tool_limits.fast_motion`）
- [ ] 工具做不穩複雜運鏡時，甩鏡、環繞、滑動變焦寫了備案（`tool_limits.complex_camera`）

腳本看不出來、要自己判斷的：

- [ ] 每場戲有場次設計（`plan`），鏡頭照著它安排：高點用了最近的景別、停留最久，特寫沒有濫用
- [ ] 動作戲：開打前交代了場地與雙方位置；攻守兩方固定在畫面兩側；每一擊都有一鏡交代結果或反應，而且看得出是誰做的（收勢的姿勢、被打的人看向他）；每個回合改變了局勢，而且越打越近、越短
- [ ] 揭示的順序是想過的：要懸念就讓觀眾先知道；角色看見東西時先給反應（近景或特寫），反應和揭示在同一個節拍；卡點停在反應上，不停在答案上
- [ ] 各機位的 `desc` 寫了門、窗、光源在畫面哪一邊；反打的機位左右相反，光從哪一邊進來也跟著換
- [ ] 漫劇的靜幀用在空鏡、物件特寫、旁白段落、要加字的畫面；角色在表演或說話的鏡頭仍是影片
- [ ] 短劇：前三秒進衝突，爽點之後有旁人的反應，最後一鏡停在卡點的反應上
- [ ] 真人寫實：外貌沒有「完美」「精緻」這類詞，有年齡痕跡與不完美的特徵；光有真實的來源；表演沒有每一鏡都很滿
- [ ] 慢動作與定格一場戲最多一兩鏡，用在真正要停住的瞬間
- [ ] 每一鏡真的只有一個主動作
- [ ] 景別和這一鏡要看到的東西對得上（要看到腳步就不能是中景）
- [ ] 相鄰鏡頭的左右位置與視線方向符合軸線；人物出畫與入畫的方向接得上
- [ ] 有運鏡的鏡頭說得出理由；整場戲不是每一鏡都在推近
- [ ] 需要畫面配合的轉場（動作剪輯、匹配剪輯、疊化）前後兩鏡已經配合好
- [ ] 9:16：臉和關鍵道具在畫面中間，沒有落在會被字幕和平台介面蓋住的邊緣
- [ ] 片段只寫看得見的東西，沒有「氣質」「氛圍」這類畫不出來的形容；同一樣東西前後用同一個詞

## 八、後製建議（交付時挑相關的說）

生成出來怎麼驗收、出了問題改哪裡，見 `generation-qa.md`。

- 每段的頭尾常常有一點變形或停頓，剪的時候裁掉；生成時要比成片多留一點長度（工具定了之後，腳本會在 CSV 算出建議生成秒數）。
- 同一鏡抽兩三次挑最好的，有風險的鏡頭多抽幾次。同樣的錯誤出現兩次以上就改提示詞或換拍法，不要一直抽。
- 全片統一調色，加輕微的顆粒，可以壓掉塑膠感，也讓不同批次生成的鏡頭看起來一致。真人寫實尤其要做。
- 聲音一定要做：環境音、腳步與衣物的音效、配樂、配音。聲音做好能明顯蓋過畫面的小瑕疵。每個角色的聲線先固定下來，寫在設定檔的 `voice`。
- 長段的文字（訊息、信件、介面、字幕）後製加，好改也好讀。
