# 穩定性與去 AI 感規則

## 一、高風險鏡頭與替代拍法

生成工具在下面這些情況最容易做壞。優先換拍法；一定要保留時，在 `risk` 寫明風險與備案，並建議多抽幾次。

換拍法是為了達成同樣的戲劇效果，不是把戲拿掉：先照 `shot-craft.md` 想清楚這個節拍要讓觀眾看到什麼，再從下表挑一種做得穩的拍法。表裡的「物件特寫」在分鏡檔填 `type: 插入`、`size: 特寫`。

| 高風險 | 替代拍法 |
|---|---|
| 打鬥、揮拳、武打 | 出手前一鏡，切到對方的反應或受擊後的結果；剪影；兵器或拳頭的物件特寫；用聲音帶過 |
| 奔跑、大幅走位 | 腳步特寫、背影遠景、跑過畫面的短鏡頭；起跑與抵達各一鏡，中間用剪接省略 |
| 多人肢體接觸（擁抱、握手、拉扯） | 接觸前一鏡，切到接觸後的近景；用過肩或背影遮住接觸點；拆成各自的反應鏡頭 |
| 手部特寫、拿取細小物件 | 改成中景讓手佔比變小；手半遮擋；直接拍物件特寫，手只從畫面邊緣入鏡（用 `partial` 寫成「一隻從畫面右緣伸入的手」）或不入鏡 |
| 轉身、快速轉頭 | 轉身前一鏡、轉身後一鏡，中間切掉 |
| 飲食、倒水、書寫 | 拍物件特寫或結果（放下的空杯、寫好的紙），過程用遮擋或省略 |
| 人群、大場面 | 遠景加虛化的背景人物；用局部（幾雙腳、幾個背影）代替全體 |
| 兩張以上的臉同時清楚入鏡 | 過肩鏡頭，前景的人只露肩背；或拆成交替的單人鏡頭 |
| 說話的嘴型 | 口型另外用對口型工具做，生成時鏡頭固定、嘴唇閉合；或讓說話的人背對鏡頭、拍聽的人 |
| 需要讀得懂的文字 | 畫面裡留空白，後製加字 |

## 二、動作要符合物理

- 寫出起因與結果：「風吹起頭髮，她抬手按住」，而不是「頭髮飄動」。沒有起因的運動看起來像特效。
- 次要運動（頭髮、衣擺、水、煙）的方向和強度要與主動作一致。
- 有重量的動作（拿重物、坐下、跌倒）要有預備和緩衝，可以拆成兩三個短鏡頭。
- 速度寫「自然」，幅度寫「小」。少用「快速、劇烈、瞬間」，也不要每鏡都寫「緩慢」；前者容易變形，後者會讓整片像慢動作。
- 人物有明顯動作時鏡頭固定；要運鏡時讓人物幾乎不動。兩邊一起動最容易出問題。

## 三、活人感

- 每鏡加一兩個微動作：眨眼、呼吸起伏、手指小動作、視線轉移、吞嚥。完全靜止的臉像蠟像。
- 表情不要完美：略帶疲憊、嘴角微僵、眼神游移，比標準的「微笑」「悲傷」更像人。
- 背景有輕微的自然動態：樹影、窗簾、遠處路人、光影變化，幅度小。
- 對話戲要有反應鏡頭和停頓，不要每一鏡都在說話。

## 四、一致性

- 先生成並定稿資產圖（角色設定圖、表情組圖、場景定稿圖、道具圖），之後每一鏡都掛它們當參考。
- 同一個角色的其他造型，拿第一個造型的設定圖做圖像編輯，不要重新生成，臉才不會變。
- 同一個場景要換角度時，拿場景定稿圖做圖生圖，不要重新用文字生成。
- 尾幀從首幀圖編輯而來，不要重新生成。
- 只有「接續」的鏡頭才拿上一鏡的最後一幀當首幀；「切」的鏡頭各自生成首幀。
- 同一場戲沿用同一組光線和色調；短暫的光線變化用那一鏡的 `light`，時段真的換了才換場景編號。
- 反覆出現的道具登記在 `props`，用 `{P01}` 引用，不要每次重新描述。
- 同一個機位的鏡頭登記在 `setups`，背景只寫一次；同機位的後續首幀，拿前一張首幀圖做圖像編輯。
- 軸線：兩個人對話時，整場戲裡甲始終在畫面一側、乙在另一側，視線方向相對。要越過軸線時先插一個中性鏡頭（正面、空鏡或物件特寫）。視線匹配、運動方向、30 度規則見 `shot-craft.md` 第四節。

## 五、節奏

- 用鏡頭長短做節奏：鋪陳的鏡頭長一點，衝突和反應的鏡頭短一點。
- 遠、中、近交替，讓觀眾知道人在哪裡、在做什麼、心裡怎麼想。
- 空鏡和物件特寫可以用來換氣、表示時間流逝，也是最穩定、最不會出錯的鏡頭。
- 漫劇：開頭三秒內要有衝突或懸念；每個旁白句子配一到兩個畫面；結尾停在懸念上。

## 六、自查清單

腳本已經檢查的（不能執行腳本時要自己查）：

- [ ] 場景與角色編號都對得上設定檔
- [ ] 每個入鏡角色都寫了位置、視線、手部
- [ ] 每鏡都有 `motion`，有角色的鏡頭有 `end`
- [ ] `motion` 用短稱指人，沒有「同上」之類的指代
- [ ] 對白或旁白的長度塞得進這一鏡
- [ ] 成片秒數加上裁頭尾，不超過工具單段秒數
- [ ] 沒有跳接：相鄰兩鏡不會主體、景別、角度、機位全都一樣卻切了一刀
- [ ] 鏡頭長短有變化
- [ ] 景別、鏡頭類型、角度、運鏡用的是用詞表裡的詞；帶方向的運鏡寫了方向
- [ ] 近景以內的鏡頭有 `bg`（自己填，或由機位提供）
- [ ] 場景出現後的頭三鏡內有遠景或全景
- [ ] 「對白」的說話者正面入鏡；沒入鏡的是「畫外音」
- [ ] 「接續」的鏡頭和上一鏡同場景、同角色、同機位，而且沒有填轉場
- [ ] 場景描述沒有用畫面左右
- [ ] 沒有要求畫面出現可讀文字
- [ ] 組合後的提示詞沒有超過工具的長度上限

腳本看不出來、要自己判斷的：

- [ ] 每場戲有場次設計（`plan`），鏡頭照著它安排：高點用了最近的景別、停留最久，特寫沒有濫用
- [ ] 每一鏡真的只有一個主動作
- [ ] 景別和這一鏡要看到的東西對得上（要看到腳步就不能是中景）
- [ ] 相鄰鏡頭的左右位置與視線方向符合軸線；人物出畫與入畫的方向接得上
- [ ] 有運鏡的鏡頭說得出理由；整場戲不是每一鏡都在推近
- [ ] 需要畫面配合的轉場（動作剪輯、匹配剪輯、疊化）前後兩鏡已經配合好
- [ ] 9:16：臉和關鍵道具在畫面中間，沒有落在會被字幕和平台介面蓋住的邊緣
- [ ] 片段只寫看得見的東西，沒有「氣質」「氛圍」這類畫不出來的形容；同一樣東西前後用同一個詞
- [ ] 服裝、傷痕、髒污、道具狀態前後一致；狀態改變時換了造型變體
- [ ] `end` 描述的結束狀態，和下一鏡的起始狀態接得上
- [ ] 高風險鏡頭已經換拍法，或在 `risk` 寫了備案
- [ ] 背影或局部入鏡的角色設了 `partial`；特寫裡看不到的光源已用 `light` 覆寫
- [ ] `motion` 的動詞不猛（撲、衝、甩、踹這類動作已拆成剪接）
- [ ] 有運鏡的鏡頭，`end` 寫的是運鏡之後的畫面
- [ ] 每一鏡的 `source` 連起來能覆蓋原文，改動都記在 `changes`
- [ ] 標了建議切點，分布大致平均，而且沒有切在一句對白或一個連續動作中間

## 七、後製建議（交付時挑相關的說）

- 每段裁掉頭尾各約 0.5 秒，生成工具常在這兩處變形。
- 同一鏡抽三到四次挑最好的，高風險鏡頭多抽幾次。
- 全片統一調色，加輕微的顆粒，可以壓掉塑膠感，也讓不同批次生成的鏡頭看起來一致。
- 聲音一定要做：環境音、腳步與衣物的音效、配樂、配音。聲音做好能明顯蓋過畫面的小瑕疵。每個角色的聲線先固定下來。
- 字幕、招牌、信件內容等文字一律後製加。
