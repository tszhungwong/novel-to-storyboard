# 拆鏡方法

`fields.md` 說每個欄位填什麼，這一份說怎麼決定要填什麼：一場戲該拆成哪些鏡頭、每一鏡為什麼用這個景別、在哪裡切、怎麼接。

生成工具能不能做好一個鏡頭是另一件事，見 `anti-ai-rules.md`。兩份有衝突時（這裡說該拍雙人鏡頭，那裡說兩張臉同框風險高），先照這一份決定「要讓觀眾看到什麼」，再用那一份的替代拍法達成同樣的效果。

## 一、先設計場次，再拆鏡頭

從文字到鏡頭有四層：章（一集）→ 場次 → 節拍 → 鏡頭。跳過中間兩層、直接把句子翻成鏡頭，結果會是原文一句對一鏡，每一鏡一樣重，看不出這場戲的重點在哪裡。

**場次**是同一個地點、同一段連續時間裡發生的一件事。換地點，或時間跳走了，就是新的一場。

拆鏡之前，每場戲先回答五個問題，寫進分鏡檔的 `plan`：

1. **目的**（`purpose`）：這場戲演完，觀眾多知道了什麼，或感覺變了什麼？一場戲至少要改變一件事：資訊、關係、處境或情緒。答不出來的戲，通常可以併進前後場，或縮成一兩個鏡頭帶過。
2. **視點**（`pov`）：觀眾跟著誰經歷這場戲？近景、反應鏡頭、主觀鏡頭優先給他。小說的敘事視角通常已經回答了這一題。
3. **節拍**（`beats`）：每當有人做了一件新的事、出現一個新資訊，或情緒轉了方向，就是一個新節拍。一個節拍通常拆成一到三個鏡頭（一個動作、一句對白、一個反應各一鏡）。
4. **高點**（`peak`）：哪個節拍最重要？整場戲的鏡頭安排都是為了讓它最有力：之前一步步靠近，高點用最近的景別、停留最久，之後放鬆。
5. **基調**（`mood`）：色調、光線的情緒、節奏快慢。同一場戲的鏡頭共用它。`mood` 是給人看的；要進提示詞的色彩寫在場景的 `palette`，光寫在 `light`。

```json
{
  "id": "1",
  "scene": "S01",
  "purpose": "林晚不敢拆信，陳嶼回來後她把決定交給他。觀眾知道這封信的份量，也知道她信任他",
  "pov": "C01",
  "beats": ["信放了三天，林晚不敢拆", "陳嶼進門，發現信還沒拆", "林晚說出她怕什麼", "她把信推給他"],
  "peak": "她把信推給他",
  "mood": "安靜、壓抑；窗邊的暖光一點一點變暗"
}
```

篇幅大、要先停下來確認時，這張場次表就是交給使用者看的場景清單。

拆鏡時每一鏡用 `beat` 指回它拍的節拍（`"1.3"`）。這不只是標記：寫的時候會逼你回答「這一鏡在拍哪個節拍」，答不出來的鏡頭多半可以刪；腳本也靠它檢查節拍有沒有漏拍、高點的鏡頭是不是最近、停最久。一個節拍通常一到三鏡；四個節拍以上卻每個都只有一鏡，就是原文一句對一鏡的徵兆。

## 二、從節拍到鏡頭

每個節拍問三件事，答案就是鏡頭：

- **觀眾這一刻要看到什麼才看得懂？** 決定拍誰、拍什麼。
- **這一刻誰的感受最重要？** 不一定是正在說話或正在動的人。
- **觀眾該離多近？** 決定景別。

景別是觀眾和人物之間的距離。越近越親密、越緊繃，但看到的環境越少；越遠越冷靜、越客觀。各景別的取景範圍與用途見 `fields.md` 的用詞表。選的時候：

- **景別跟著情緒走，不是為了變化而換。** 一場戲通常由遠到近：先讓觀眾知道在哪裡，再知道在做什麼，最後看到人心裡怎麼想。最近的景別留給高點。
- **特寫省著用。** 整場都是特寫，等於沒有特寫。
- **每換一鏡都要給新東西。** 觀眾看完這一鏡想知道的事（他在看什麼？她聽了什麼反應？），就是下一鏡的內容。
- **建立鏡頭**：場景出現後的頭三鏡內要有遠景或全景交代空間。不必是第一鏡，漫劇常先給鉤子再建立。人物在場景裡大幅換了位置，要再建立一次。
- **插入鏡頭與空鏡**：強調一件道具、讓觀眾喘口氣、表示時間過去了。它們也是生成工具最不會做壞的鏡頭。
- **主觀鏡頭**：讓觀眾直接用角色的眼睛看。前一鏡要先拍他「在看」，觀眾才知道這是誰的眼睛。
- **角度有意義**：仰拍讓人顯得有力，俯拍讓人顯得弱小。同一場戲裡不要無故改變角度；權力關係翻轉的那一刻再換，效果最大。

## 三、對話戲怎麼拍

兩個人說話，標準的拍法是這個順序：

1. **關係鏡頭**：全景或中全景，兩個人都在畫面裡，交代誰在哪裡、相隔多遠。
2. **過肩正反打**：越過甲的肩拍乙，再越過乙的肩拍甲，交替。兩邊的景別和角度成對（都是中景，或都是近景）。這時連續幾鏡景別相同是正常的。
3. **推近**：話越說越重時，從過肩換成單人近景（畫面裡不再有對方的肩膀，兩人的距離感被切斷），高點給特寫。兩邊同步推近；只推其中一邊，表示壓力在那個人身上。
4. **放鬆**：高點過後退回較寬的景別，或給一個空鏡、插入鏡頭收尾。

**不是誰說話就拍誰。** 一句話的重點常常在聽的人臉上。常見的切法是：一句話的開頭拍說話的人，讓觀眾知道是誰在說；後半句或下一句切到聽的人，說話聲繼續（`line` 用「畫外音」，`transition` 用「聲音延後」）。對生成工具來說這也是好事：反應鏡頭不需要對口型。

- **停頓**：重要的台詞前後，放一個沒有台詞的反應鏡頭，1.5 到 2.5 秒。話說完立刻接下一句，觀眾來不及感受。
- **三個人以上**：把他們分成兩邊，當成兩個人來處理，軸線畫在兩邊之間。有人換位置或有新的人加入時，重新給一個全景。
- **9:16**：畫面太窄，放不下並排的兩個人。關係鏡頭改用縱深（一前一後）或過肩，之後以交替的單人近景為主。

## 四、機位與連戲

**機位**是攝影機擺的位置。實際拍片時，一場戲不會每一鏡都換一個新位置：先擺好幾個機位，剪接時在它們之間來回切。用生成工具時照這個做法有兩個好處：

- 同一個機位的背景只描述一次（`setups[].bg`），不會每一鏡手寫一遍、越寫越不一樣。腳本會用它出一張機位背景圖（沒有人物的空景），先定稿，再當這個機位每一鏡的背景參考。場景定稿圖只有一個角度，反打看到的那面牆只能靠這張。
- 同機位的後續鏡頭，首幀可以拿前一次的首幀圖做圖像編輯（只改人物的姿勢和表情），背景、光線、人物位置都不會跑掉。腳本會在各鏡資料裡提醒哪一鏡可以這樣做。

一場雙人對話戲通常是這幾個機位：

```json
"setups": [
  {"id": "S01-A", "scene": "S01", "desc": "屋內靠沙發處，朝窗邊拍：桌子與窗戶的全貌，林晚側面", "bg": "窗邊的木頭方桌與整面窗戶，窗外是傍晚的天色"},
  {"id": "S01-B", "scene": "S01", "desc": "桌邊，朝玄關拍：陳嶼正面。軸線的沙發這一側，陳嶼看向畫面左", "bg": "玄關敞開的木門與門框，門外是昏暗的樓梯間"},
  {"id": "S01-C", "scene": "S01", "desc": "玄關，越過陳嶼的右肩朝窗邊拍：林晚正面。軸線的沙發這一側，林晚看向畫面右", "bg": "窗邊木桌與昏暗的窗戶"}
]
```

連戲要守的四件事：

- **軸線（180 度）**：兩個互動的人之間有一條假想的線，所有機位都放在線的同一側。這樣甲永遠在畫面一邊、乙在另一邊，兩人的視線相對。機位越到線的另一側，兩人左右對調，觀眾會以為他們換了位置。寫機位的 `desc` 時註明在軸線哪一側、人物看向畫面哪一邊。真的要越軸，先插一個中性鏡頭（正對軸線的正面或背面、空鏡、插入鏡頭），或讓人物自己走動、帶著軸線轉過去。
- **視線匹配**：甲看向畫面右，乙就要看向畫面左。高低也要對：站著的人看坐著的人視線朝下，坐著的人朝上。`gaze` 欄要寫到這個程度。
- **運動方向**：人物朝畫面右邊走出去，下一鏡就從畫面左邊進來，繼續朝右。追逐的雙方朝同一個方向，迎面相遇的兩人方向相反。
- **30 度規則**：連續兩鏡拍同一個主體時，景別至少差一級，或拍攝角度明顯不同。兩鏡太像，看起來像畫面跳了一下（跳接）。腳本會警告主體、景別、角度、機位全都相同的相鄰鏡頭。

狀態的連戲（服裝、傷痕、道具位置、光線）靠造型變體、`continuity` 與 `end`：每一鏡 `end` 寫的結束狀態，要接得上下一鏡的起始狀態。

## 五、在哪裡切，怎麼接

每一刀都要有理由。常見的五種：

| 理由 | 切法 |
|---|---|
| 視線 | 人物看向某處，切到他看到的東西 |
| 動作 | 在動作進行中切，下一鏡接著同一個動作 |
| 聲音 | 聽見聲音，切到聲音的來源；或下一鏡的聲音先進來 |
| 資訊 | 觀眾需要看清楚一樣東西，切到插入鏡頭 |
| 情緒 | 一句話或一件事落地，切到受影響的人的反應 |

沒有理由的切，觀眾會覺得碎。

轉場的種類和各自要配合的事見 `fields.md` 的轉場表。幾種常見情況：

- **動作剪輯**：生成工具很難讓動作剛好停在中途，所以實際做法是上一鏡拍動作的開頭（伸手），下一鏡拍動作的結果（手已經握住杯子），剪接時各裁掉一點讓兩段接上。這也是高風險動作的標準替代拍法。
- **短的時間跳躍**（幾分鐘到幾小時）：硬切，加上看得出時間過去的變化（光線暗了、杯子空了、人換了位置），或中間插一個空鏡。
- **長的時間跳躍**：疊化或黑場，並換一個場景編號（新的 `light` 與 `time`）。
- **回憶**：進去和出來各一個轉場（疊化或閃白）。回憶段落另開場景編號，在場景的 `light` 寫出不同的色調（「褪色的暖黃光，對比偏低」），角色用當時的造型變體；年齡差很多就另開角色編號。
- **平行剪輯**：兩件事同時發生時交替著切。每切回來一次，鏡頭更短、景別更近，張力就上去了。
- **蒙太奇**：把一段時間壓縮成三四個短鏡頭（各 1.5 到 2 秒），每鏡一個有代表性的畫面，鏡頭之間用疊化或硬切。

## 六、運鏡的理由

預設是固定。運鏡是在告訴觀眾注意力該往哪裡去，所以要有理由：

| 運鏡 | 觀眾的感受 | 適合的時機 |
|---|---|---|
| 推近 | 注意力收攏，進入人物的內心，事情變重要了 | 高點之前、人物下決定的那一刻 |
| 拉遠 | 看見周圍，人物顯得孤單，事情告一段落 | 揭露、一場戲的結尾 |
| 搖 | 跟著視線或動作，從一個主體帶到另一個 | 揭示旁邊的人或物 |
| 移 | 陪著人物走，展示空間的寬度 | 人物沿著某個方向移動 |
| 上升、下降 | 從細節到全貌，或從全貌進到細節 | 開場、結尾 |
| 跟拍 | 觀眾跟在人物身後一起進去 | 進入新的空間 |
| 環繞 | 人物處在被包圍或關鍵的時刻 | 很少用，而且生成風險高 |
| 手持 | 不安、身在現場 | 衝突、驚慌 |

一場戲裡有運鏡的鏡頭應該是少數。每一鏡都緩慢推近，等於沒有重點，也是常見的 AI 感來源。

## 七、構圖

寫在 `frame` 欄。景別、類型、角度有自己的欄位，這裡寫其餘的安排。

- **三分法**：主體放在畫面的三分線上，不要每一鏡都擺在正中央。正中央留給對稱、對峙、有儀式感的畫面。
- **視線空間**：人物看向哪一邊，那一邊多留一點空間。反過來（臉貼著畫面邊緣，背後空一大片）會有壓迫、被困住的感覺，要用就刻意用。
- **頭頂空間**：頭頂上方留一點點。特寫可以切掉頭頂，但畫面邊緣不要剛好切在下巴、脖子或關節上。
- **層次**：前景、中景、背景至少要有兩層，畫面才有深度，不會像貼圖。前景可以是虛焦的肩膀、門框、窗簾。
- **框中框**：用門框、窗框、鏡子把人物框起來，表示隔絕或被注視。
- **負空間**：大片留白，表示孤獨或渺小。
- **景深**：淺景深（背景虛化）把注意力集中在人身上；深焦讓環境和人一樣清楚，適合建立鏡頭。

**9:16**：畫面窄而高，一鏡一個主體，用前後縱深代替左右並排。平台的介面與字幕會蓋住畫面邊緣，大約是上緣一成、下緣兩成、右緣一成（各平台不同，這是概略值）。臉、關鍵道具和重要的動作要放在中間這一塊：人物的臉擺在畫面中段偏上，不要把重點放在最底下。

**16:9**：可以左右安排兩個人，注意軸線。畫面寬，單人近景的旁邊會空出來，用視線空間或前景填補。

## 八、小說怎麼變成畫面

| 原文是 | 做法 |
|---|---|
| 心理描寫（「她很難過」） | 變成看得見的東西：微表情、小動作、她怎麼對待手邊的物件、環境的細節。「她盯著杯子，手指停在杯緣，視線垂下」。真的需要才用內心獨白 |
| 概述（「三年過去了」「他每天都去」） | 蒙太奇；或一個看得出時間的空鏡加上旁白 |
| 背景交代（身世、前情） | 旁白配空鏡或插入鏡頭，或拆散了放在動作之間。不要整段旁白配一張不動的臉 |
| 第一人稱敘事 | 敘事的話當內心獨白或旁白，視點角色就是「我」。可以用主觀鏡頭，但不要整片都是 |
| 比喻與意象（「心像沉進水裡」） | 不要照字面拍。在場景裡找現成的東西對應（杯底下沉的茶葉），或只留下情緒，交給表情和光線 |
| 潛台詞（嘴上說的和心裡想的不一樣） | 台詞照舊，讓畫面說出真話：嘴上說沒事，手在絞衣角 |
| 很長的對話 | 分成幾個節拍，每個節拍換一次景別或機位，中間插反應鏡頭與插入鏡頭。要刪減時記入 `changes` |
| 環境描寫 | 建立鏡頭和空鏡；挑一兩個細節當插入鏡頭，不必樣樣都拍 |
| 群戲 | 先用全景交代所有人，之後只跟著視點角色和一兩個關鍵人物 |
| 原文沒寫、但畫面一定要決定的事（誰站哪裡、手上拿什麼） | 自己決定，並且前後一致。牽涉外貌和重要道具的，列入 `pending` |

不改劇情的原則不變：這些都是換一種方式呈現，不是增刪情節。真的增刪了要記在 `changes`。

## 九、節奏

- **鏡頭多長，看資訊量和情緒的份量。** 一眼就看懂的（插入鏡頭、簡單的反應）短；需要感受的（高點、沉默）長。
- **一場戲的節奏有形狀**：鋪陳時慢；接近高點時加快，鏡頭變短、景別變近；高點停住，給全場最長的一鏡；之後放鬆。
- **對比產生力量**：連續幾個短鏡頭之後的一個長鏡頭特別有份量，反過來也一樣。所有鏡頭一樣長，就沒有輕重。
- **動作戲**：1.5 到 2.5 秒的短鏡頭快切，但每一鏡裡的動作幅度仍然要小。速度是剪出來的。
- **漫劇**：前三秒給鉤子；旁白不會停，畫面要跟著句子換，一句配一到兩個畫面；短影音的觀眾流失得快，經驗上每二三十秒要有一個新資訊、轉折或情緒變化；結尾停在懸念上。
