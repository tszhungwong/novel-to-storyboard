# 欄位定義

兩個檔案：`bible.json`（設定，整個專案共用）和 `EPxx.json`（一集的分鏡）。完整範例在 `examples/`。輸入是大綱時，另有分集表 `series.json` 與分集劇本 `EPxx-script.md`，見本文的對應小節。

目錄：提示詞片段與語言 → `bible.json`（project、characters、scenes、props、effects）→ `series.json` → 分集劇本 → `EPxx.json`（plan、setups、shots、cast、motion 的寫法）→ 用詞（景別、人物朝向、鏡頭類型、角度、機位高度、焦段、運鏡、速度、生成方式、轉場、台詞類型）。

## 提示詞片段與語言

標了「片段」的欄位會被腳本原樣放進提示詞，請用提示詞語言寫，寫成沒有主詞也讀得通的名詞短語，結尾不加句號。腳本用逗號把片段接起來，所以寫成完整句子會接得很怪。

- 提示詞只出一種語言時，片段寫成字串：`"look": "二十歲出頭的女性，鵝蛋臉"`
- 中英都出時，寫成物件：`"look": {"zh": "二十歲出頭的女性，鵝蛋臉", "en": "a woman in her early twenties with an oval face"}`

沒標「片段」的欄位是給人看的，用使用者的語言寫。景別、鏡頭類型、角度、運鏡用最後一節「用詞」裡的標準用詞時，腳本會自動換成提示詞的寫法（中英都會）。

片段怎麼寫才好（外貌、服裝、光線、風格、動作各自的寫法與好壞對照）見 `prompt-writing.md`。

片段裡可以寫 `{P01}` 引用道具、`{F01}` 引用特效，腳本會換成設定檔裡的描述；有登記狀態的寫 `{F01:半開}`，換成那個狀態的描述。

## bible.json

### project

| 欄位 | 說明 |
|---|---|
| `title` | 專案名稱 |
| `format` | 形式：`漫劇`、`短劇`、`動畫`、`真人劇` 或 `影片`（MV、廣告、預告這類）。各自的節奏與預設見 `SKILL.md` 第二步。舊檔的 `正式動畫` 當成 `動畫` |
| `medium` | 媒材，可省略：`真人寫實`、`2D 動畫`、`3D 動畫` 或 `漫畫`。填 `真人寫實` 時，腳本把角色設定圖寫成攝影棚的定妝照、表情組圖寫成表情測試照、場景定稿圖寫成實景照片、道具圖寫成靜物攝影；其他值的資產圖是插畫式的設定圖 |
| `aspect` | 畫幅，例如 `9:16`、`16:9`、`2.39:1`、`1:1`。只顯示在設定表提醒使用者，不會進提示詞 |
| `image_tool`、`video_tool` | 工具名稱。留空表示工具未定，腳本不套用任何工具限制；填了之後腳本會提示補上 `tool_limits` 與單次秒數 |
| `prompt_langs` | `["zh"]`、`["en"]` 或 `["zh","en"]` |
| `video_mode` | `i2v`（圖生影片，預設）或 `t2v`（文字生影片）。`t2v` 時腳本會把外貌與場景也寫進影片提示詞 |
| `use_last_frame` | 工具支援首尾幀就填 `true`，腳本會輸出尾幀提示詞。工具還沒定時填 `true` |
| `tool_limits` | 工具定了才填，可省略。這個工具做不好的事，填 `false` 的項目腳本才會檢查：`text`（畫面裡的字）、`fast_motion`（快速、劇烈的動作）、`complex_camera`（甩鏡、環繞、滑動變焦）、`negative`（沒有負面詞欄位）。例如 `{"negative": false, "fast_motion": false}`。不填或填 `true` 表示不限制。怎麼判斷見 `tool-capabilities.md` |
| `ref_mode` | `文字`（預設）或 `參考圖`。`文字`：外貌與造型完整寫進每一鏡，參考圖只是加強。`參考圖`：角色寫成「圖1中的＋短稱」、背景與道具註明參照哪一張圖，整段外貌不再進提示詞。工具能一次掛好幾張參考圖、並在提示詞裡用編號指稱時才用，見 `prompt-writing.md` 第七節。作用在首幀圖像提示詞；`video_mode` 是 `t2v` 時作用在影片提示詞 |
| `ref_syntax` | 片段，只在 `參考圖` 模式有用。工具在提示詞裡怎麼稱呼第幾張參考圖，`{n}` 換成序號：`"@图片{n}"`、`"@Image{n}"`、`"image {n}"`。沒填就是「圖1」「image 1」 |
| `ref_max` | 只在 `參考圖` 模式有用。工具一次最多能掛幾張參考圖，腳本會檢查每一鏡有沒有超過 |
| `audio_plan` | `旁白`、`後配口型` 或 `原生音訊` |
| `clip_range` 或 `clip_lengths` | 工具單次可生成的秒數。連續範圍用 `"clip_range": [3, 30]`，固定幾種用 `"clip_lengths": [4, 6, 8]`。用來檢查鏡頭會不會太長，並算出建議生成秒數。工具還沒定就不要填 |
| `prompt_limits` | 工具的提示詞長度上限，可省略。例如 `{"image": {"zh": 300, "en": 600}, "video": {"zh": 500, "en": 1000}}`，中文算字數，英文算詞數。腳本會檢查每一鏡組合後有沒有超過 |
| `speech_rate` | 每秒幾個中文字，預設 4.5。使用者要快節奏解說可調到 5.5 |
| `episode_length` | 單集長度的範圍（秒），例如 `[60, 90]`。使用者或大綱指定了單集長度才填；只有一個目標秒數時，前後留一點空間，例如 `[55, 65]`。腳本用它檢查分集表的預估秒數、分集劇本的台詞長度與整集分鏡的長度。不填就是一章一集、不設上限 |
| `narrator_voice` | 旁白的聲線，例如 `沉穩的中年男聲，說書人的語氣`。給配音的人看，不進提示詞，整季要一致。有旁白卻沒寫，腳本會提示 |
| `music` | 配樂方向，例如 `鋼琴為主，少量弦樂，留白多`。給剪接的人看，顯示在設定表 |
| `narration` | 旁白的人稱與敘事者，例如 `沈小禾的第一人稱自述`、`第三人稱的說書人`。給人看，不進提示詞，整季要一致 |
| `style_lock` | 片段。畫風、線條、上色方式、飽和度與對比、質感。會加到每一張圖，所以不要提背景、人物、天氣、光線方向，也不要寫冷暖或主色（那歸場景的 `palette`）。寫了腳本會警告 |
| `negative_global` | 片段，可省略。通用負面詞，單獨列在設定表與每一鏡的「負面詞」欄，不會混進正向提示詞。工具未定時可以先寫一組；定了工具而它沒有負面詞欄位（`tool_limits.negative` 是 `false`）就清空，腳本會警告。Midjourney 的 `--no` 寫在 `image_suffix` |
| `speech_lang` | 片段，只在 `原生音訊` 有用。台詞的語言，例如 `{"zh": "普通話", "en": "Mandarin Chinese"}`。提示詞語言和台詞語言不同時要填，腳本會寫成「用普通話說」 |
| `audio_suffix` | 片段，只在 `原生音訊` 有用。接在每一鏡影片提示詞最後的短指令，例如 `不要字幕`。有些工具的文件建議這樣寫 |
| `image_suffix` | 可省略。接在每一鏡首幀、尾幀與機位背景圖提示詞最後的工具參數，原樣附加，不分語言。Midjourney 的畫幅、版本、負面詞都寫在提示詞裡，就填在這裡：`"--ar {ar} --no text, watermark"`，`{ar}` 會換成 `aspect`。寫死的 `--ar` 和 `aspect` 不一致時腳本會警告；不算進提示詞長度 |
| `asset_suffix` | 可省略。同上，接在角色設定圖、頭像、表情組圖、場景定稿圖、道具圖、特效參考圖的提示詞最後。寫成 `"--ar {ar} --v 8"`，`{ar}` 會換成每一張資產圖的建議畫幅（設定圖與組圖 16:9、頭像 3:2、道具與特效 1:1、場景定稿圖 16:9）；寫死一個畫幅時腳本會提示 |
| `video_suffix` | 片段，可省略。接在每一鏡影片提示詞的運鏡後面，任何聲音方案都有效。工具會自動把一段影片切成好幾個鏡頭時，在這裡寫 `單一連續鏡頭`（`single continuous shot`），見 `tool-capabilities.md` 的可靈一列 |

### characters[]

| 欄位 | 說明 |
|---|---|
| `id` | `C01`、`C02`… |
| `name` | 角色名，顯示用，不會進提示詞 |
| `kind` | 可省略，預設 `人`。非人角色填 `半人`、`動物`、`器物` 或 `異獸`，寫法與差別見 `creatures-and-effects.md`。`動物`、`器物`、`異獸` 的服裝可以空，鏡頭裡要寫的走位欄位也比較少 |
| `tag` | 片段。短稱，十個字左右，看得出是誰，角色之間不會混淆。`motion` 和 `end` 裡用它指人。兩個角色的短稱一樣時腳本會警告。長得一樣的兩個手下，要各自動作就登記成兩個角色、短稱分得出來（「左臉有疤的黑衣人」「矮壯的黑衣人」）；只當一群人出現時登記成一個角色，`tag` 和 `look` 寫成複數（「兩個蒙面黑衣人」），並填 `group`，否則提示詞會把兩個人寫成一個 |
| `group` | 可省略。一個編號代表一群人時，填人數（`2`）。設定圖改成「一群人並排的正面全身，加其中一人的側面與背面」，不出頭像與表情組圖。短稱看起來是一群人（「兩個…」）卻沒填時腳本會提示 |
| `look` | 片段。不會變的外貌：年齡、臉型、髮型髮色、眼睛、體型。非人角色的順序不同，見 `creatures-and-effects.md` |
| `stature` | 片段，可省略但建議填。只寫絕對身高：「身高約一百八十公分」。腳本把它放進角色設定圖，以及兩人以上同框、看得到身體（中景以外）的鏡頭，同框時每個人的身高並排，高矮自然看得出來。寫成「比某某高一個頭」會在設定圖和沒有那個人的鏡頭裡點名他，腳本會警告；同框的人沒寫時腳本會提示。頭身比寫在 `look` |
| `marks` | 片段。辨識特徵（痣、疤、飾品），可空。角色有好幾個形態時，它會加在每一個形態上，所以寫每個形態都有的記號 |
| `detail` | 片段，可省略但建議填。只進這個角色的設定圖、頭像與表情組圖、不進鏡頭的細節：皮膚、髮絲、手這類近看才看得到的質感。不寫新的辨識特徵（那歸 `look` 與 `marks`），否則設定圖畫了、鏡頭的文字沒有，兩邊對不起來。有自己 `look` 的形態不套用，寫在那個形態的 `detail`。寫法見 `prompt-writing.md` 的 `detail` 一節 |
| `variants[]` | 造型變體，至少一個，見下表 |
| `expressions` | 片段，可省略。表情組圖要畫哪幾種表情，預設是「平靜、微笑、難過、生氣」。依角色在戲裡實際用到的表情改。`動物`、`器物`、`異獸` 沒寫就不出表情組圖 |
| `minor` | 填 `true` 表示配角或龍套，只出設定圖與頭像，不出表情組圖 |
| `voice` | 片段。聲線：性別年齡、音色、語速，例如「二十多歲的女聲，音色偏低，說話輕而慢」；英文寫成名詞短語 `a low, gravelly male voice`。原生音訊時腳本把它寫進這個角色的每一句台詞，聲音才不會一鏡一個樣；其他方案給配音的人看。有台詞卻沒寫，腳本會提示 |
| `voice_ref` | 可省略。工具裡選定的音色名稱，或聲音樣本的檔名。給人看，顯示在設定表與各鏡的聲線欄，每次生成或配音都選同一個 |
| `mouthless` | 填 `true` 表示沒有嘴（燈籠、茶壺、紙人）。它說話時 `line.type` 用「畫外音」，`motion` 寫一個看得見的說話信號 |

年齡差很多的同一個人（回憶中的童年）外貌不同，另開一個角色編號，並在 `name` 註明。同一個角色的人形與原形不用另開編號，開兩個造型變體，各寫自己的 `look` 與 `tag`。

**variants[]**

| 欄位 | 說明 |
|---|---|
| `id` | `C01-a`、`C01-b`… |
| `label` | 顯示用，例如「居家」「受傷後」 |
| `outfit` | 片段。完整服裝。`動物`、`器物`、`異獸`，或有自己 `look` 的形態，可以空 |
| `outfit_top` | 片段，可省略但建議填。上半身的服裝。中景以內（腰部以上）看不到下半身，腳本會改用這一段；否則提示詞裡的褲子鞋子會讓生成工具把鏡頭拉遠 |
| `state` | 片段，可空。狀態，例如「左臉頰有一道擦傷」「身後露出一條銀白色的狐尾」 |
| `sheet` | 片段，可省略。設定圖的畫法，預設是「正面、四分之三側面、側面、背面全身四視圖，自然站姿，表情平靜」（多數鏡頭是四分之三側面，所以設定圖一定要有這個角度）；`異獸` 預設會加一個人類剪影當比例尺。臥床或坐輪椅的角色改成合適的，例如「正面與側面半身視圖，靠坐在床上」 |
| `look` | 片段，可省略。這個形態自己的外貌，取代角色的 `look`。只用在長得完全不一樣的形態（人形與原形） |
| `tag` | 片段，可省略。這個形態自己的短稱。有自己 `look` 的形態一定要寫，否則影片提示詞會用另一個形態的樣子指它 |
| `voice` | 片段，可省略。這個形態自己的聲線，取代角色的 `voice`（原形的聲音和人形不同時） |
| `detail` | 片段，可省略但建議填。只進這個造型設定圖的服裝做工：布料、縫線、鈕扣、口袋、磨損與皺褶的位置、鞋。第二個以後的造型接在「造型改成：」後面。和角色的 `detail` 一樣，不寫新的辨識特徵 |

第二個以後的造型，腳本產出的設定圖提示詞是「拿第一個造型的設定圖來改」，這樣臉才不會變。所以把最基本的造型排第一個。有自己 `look` 的形態例外：腳本會出一張完整的設定圖。

人與半人另外有一張**頭像**：正面與四分之三側面的頭部特寫，穿第一個造型的上衣。全身設定圖裡臉只佔很小一塊，撐不起近景與特寫；所以近景以內、正面入鏡的角色，腳本會在參考圖清單裡把頭像排在這個角色的設定圖後面（參考圖模式下寫成「圖1中的…（臉部參照圖2）」）。群體角色與長得完全不一樣的形態（原形）不出頭像。

### scenes[]

| 欄位 | 說明 |
|---|---|
| `id` | `S01`、`S02`… |
| `name` | 地點名，顯示用 |
| `space` | 片段。這是什麼地方（類型、時代與地域、大小、新舊），不會動的結構、門窗、大型家具，以及它們的空間關係。不寫畫面左右，不寫會移動或會變狀態的東西 |
| `light` | 片段。光源、方向、明暗與光本身的顏色。不要重複時間，也不要寫飽和度（那歸風格鎖定句） |
| `time` | 片段。時間與天氣 |
| `palette` | 片段，可省略但建議填。這個場景整體的色彩：主色、暗部偏什麼色、點綴色（「暗部偏灰藍」「燈籠的暗紅與潮濕石板的青黑為主」）。只寫 `light` 沒說到的，十個字左右就夠。會接在每一鏡的光線後面，也會進場景定稿圖與機位背景圖 |
| `detail` | 片段，可省略但建議填。只進場景定稿圖的陳設與材質：牆面、地面、木料的紋理與磨損，固定在那裡的小東西（招牌、管線、雜物）。不寫人，不寫會移動或會變狀態的東西。不進鏡頭，也不進機位背景圖：一個機位只看得到一部分，各機位看得到的陳設寫在機位的 `detail` |

同一地點換了時段、而且之後很多鏡都是新光線，才另開場景編號（S01 傍晚、S02 深夜），`space` 的文字保持一模一樣，`light`、`time`、`palette` 各自重寫。一場戲裡短暫的光線變化用每一鏡的 `light`（和 `palette`）覆寫。

所有場景的 `palette` 排在一起，就是這一季的色彩腳本：回憶褪色、高潮的夜戲最冷、結局回到暖色，這類設計在這裡一眼看得出來。設定表的場景表會列出這一欄。

### props[]

反覆出現、需要每次長得一樣的道具。只出現一次的不用登記。

| 欄位 | 說明 |
|---|---|
| `id` | `P01`、`P02`… |
| `name` | 道具名，顯示用 |
| `desc` | 片段。十五字以內的外觀描述，寫成名詞短語（「一把磨得發亮的舊銅鑰匙」）。只寫不會變的外觀，狀態（拆了沒、亮不亮）寫在鏡頭裡 |
| `states` | 可省略。會反覆出現、需要每次寫得一樣的狀態：`{"拆開": "一個封口翻起的白色信封"}`。每個狀態寫成完整的名詞短語，用 `{P01:拆開}` 引用。腳本會替每個狀態出一張由道具圖改出來的狀態圖（「P01 道具圖・拆開」），鏡頭寫了這個狀態時，參考圖指向那一張 |
| `detail` | 片段，可省略但建議填。只進道具圖的細節：大小、各部位的材質與做工、磨損的位置。它不代入句子，可以有逗號、可以長；`desc` 只留兩三個最能辨認的特徵，其餘寫在這裡 |

`desc` 和 `states` 會被代入句子中間，所以不能有逗號，中文十五字、英文十個詞以內。有逗號腳本會警告，太長會提示。

鏡頭裡任何片段都可以寫 `{P01}`，例如 `"hands": "右手握著{P01}"`。腳本也會為每件道具產出一張道具圖的提示詞。

### effects[]

法術、印記、妖氣、鬼火這類特效。寫法、分類和生成與後製的分工見 `creatures-and-effects.md`。腳本會替每個特效（有狀態的話每個狀態）產出一張純黑背景的特效參考圖。

| 欄位 | 說明 |
|---|---|
| `id` | `F01`、`F02`… |
| `name` | 特效名，顯示用 |
| `desc` | 片段。外觀，寫成名詞短語：形狀 → 顏色 → 光 → 質感與粒子 → 大小與範圍 |
| `states` | 可省略。會隨劇情變化的特效，每個階段寫成完整的名詞短語：`{"花苞": "…", "全開": "…"}` |
| `detail` | 片段，可省略但建議填。只進特效參考圖、不進鏡頭的細節：粒子的大小與疏密、邊緣是銳利還是柔散、內部的紋理與層次。每個狀態的參考圖都會接上它 |
| `motion` | 片段，可省略。怎麼動：方向、速度、範圍怎麼變。會接在影片提示詞的 `motion` 後面 |
| `light` | 片段，可省略。會發光的特效怎麼照亮周圍。會接在首幀提示詞的光線後面 |
| `light_states`、`motion_states` | 可省略。各狀態自己的光與動態：`{"花苞": "印記在掌心映出一點微弱的淡金色光", "淡痕": ""}`。沒列的狀態用 `light`、`motion`；空字串表示這個狀態不發光、不動。有分狀態、`light` 卻只有一段時腳本會提示 |
| `make` | `生成`（預設）、`後製` 或 `生成加後製`。`後製` 的特效不進提示詞，只寫在備註裡。要精確控制的文字、數字與介面通常填 `後製`；選定的工具做不好快速的爆發時，爆發也改成 `後製` |

## 分集劇本（EPxx-script.md）

Markdown 格式，一集一個檔案：場標寫成 `## 第 1 場　地點　時段　內外`，畫面以 `△` 開頭，台詞寫成 `角色名（語氣）：台詞`，後製文字以 `【字】` 開頭。完整格式與寫法見 `outline-to-episodes.md` 第四節。執行 `build_storyboard.mjs bible.json EP01-script.md` 會算台詞長度、列出太長的句子與不在設定檔裡的說話者。

## EPxx.json

| 欄位 | 說明 |
|---|---|
| `episode` | `EP01`。會用在輸出檔名 |
| `source_title` | 這一集對應的原文範圍 |
| `changes[]` | 對原文的刪減、合併、新增、調動順序，每項一句話 |
| `plan[]` | 場次設計：每場戲的目的、視點、節拍、高點。拆鏡前先寫，見下表 |
| `setups[]` | 機位：一場戲裡反覆使用的拍攝位置。可省略，對話戲建議用，見下表 |
| `shots[]` | 鏡頭，依播放順序 |

### plan[]

「場景」是地點（`S01`），「場次」是一場戲：同一個地點、同一段連續時間裡發生的一件事。一個場景可以有好幾場戲，`plan` 一場寫一筆。怎麼分析見 `shot-craft.md` 第一節。這些欄位都是給人看的，不進提示詞。

| 欄位 | 說明 |
|---|---|
| `id` | 場次編號，`1`、`2`… |
| `scene` | 場景編號 |
| `purpose` | 這場戲的目的：演完之後，觀眾多知道了什麼、感覺變了什麼。寫不出來的戲通常可以併掉 |
| `pov` | 視點角色的編號：觀眾跟著誰經歷這場戲。近景和反應鏡頭優先給他 |
| `beats[]` | 節拍，每個一句話，依序。行動、資訊或情緒每變一次算一個節拍 |
| `peak` | 高點落在哪個節拍：寫節拍的序號（`4`），或和 `beats` 裡的文字一字不差。最近的景別、最長的停留留給它 |
| `blocking` | 走位：每個人在空間裡的起點、移動路線與終點，軸線在誰和誰之間、機位在哪一側。用門、窗、桌子這些固定的東西當參照，不用畫面左右。兩個以上角色同場時要寫，沒寫腳本會提示；寫法見 `shot-craft.md` 第一節 |
| `mood` | 可省略。這場戲的影像基調：色調、光線的情緒、節奏快慢 |

每一鏡用 `beat` 指回它拍的節拍（見 `shots[]`）。腳本據此檢查：

- 每個節拍至少有一鏡；沒有的是漏拍，或這個節拍其實不需要。
- 高點的節拍裡，景別最近的鏡頭不比其他節拍的人物鏡頭遠（高點這一邊連物件的插入特寫也算），最長的一鏡不比其他節拍短。兩樣都不符合是警告，一樣不符合是提示；刻意用遠景表現孤立、或用很短的鏡頭製造衝擊時，交付時說明理由。
- 四個節拍以上卻每個都只有一鏡：多半是原文一句對一鏡，提示。
- 鏡頭順序和節拍順序倒過來：平行剪輯或閃回以外，多半是排錯，提示。漫劇把後面的畫面提前當開頭鉤子時，那一鏡照實填它原本的節拍（例如 `"1.4"`），整集第一鏡的這種倒退腳本不算。

分鏡表的場次設計會在每個節拍後面列出拍它的鏡頭，高點標 ★；導演表與 CSV 有「節拍」欄。

### setups[]

同一個機位拍出來的鏡頭，背景和光線應該一模一樣。把它登記成機位，`bg` 只寫一次，鏡頭用 `setup` 引用；一場對話戲通常兩到四個機位就夠。用法見 `shot-craft.md` 第四節。

| 欄位 | 說明 |
|---|---|
| `id` | `S01-A`、`S01-B`…（場景編號加字母） |
| `scene` | 場景編號 |
| `desc` | 給人看的一句話：鏡頭在哪裡、朝哪裡拍、拍到誰的正面，門、窗、光源在畫面哪一邊。軸線守不守得住就看這一句；反打的機位左右相反，光的方向也跟著換邊 |
| `bg` | 片段。從這個機位實際看得到的背景。鏡頭沒寫 `bg` 時用它 |
| `light` | 片段，可省略。從這個機位看到的光線和場景的 `light` 不一樣時才填（例如逆光機位）。場景的 `light` 寫了方向（「越往巷底越暗」）時，朝反方向拍的機位看到的剛好相反，一定要填，否則機位背景圖的 `bg` 和光線會互相矛盾。只寫空間裡的光；人臉上、身上的光寫在各鏡的 `light`，否則會跑進沒有人的機位背景圖，腳本會警告 |
| `detail` | 片段，可省略但建議填。只進機位背景圖、不進鏡頭的細節：從這個位置看得到的陳設、材質與磨損。不寫人 |

腳本會替每個機位產出一張**機位背景圖**的提示詞：這個機位的 `bg` 與 `detail`、光線、場景的 `palette`，加上「純背景空景，取景比鏡頭略寬」（這個機位的鏡頭都同一個角度時，也寫上角度）。它列在分鏡表的「機位背景圖」一節與 `<集數>-assets.csv`，先生成並定稿，再當這個機位所有鏡頭的背景參考圖。場景定稿圖只有一個角度，反打的機位看到的牆不在那張圖裡，所以有機位的鏡頭以機位背景圖為準：文字模式下腳本會把它加進參考圖清單，取代 `refs` 裡同一個場景的場景定稿圖。所以 `bg` 要寫成拿掉人之後也成立的背景。

### shots[]

| 欄位 | 必填 | 說明 |
|---|---|---|
| `id` | 是 | `EP01-001`。插入鏡頭用 `EP01-004a` |
| `scene` | 是 | 場景編號 |
| `beat` | 建議 | 這一鏡拍的是哪一場的哪個節拍，寫成字串 `"1.3"`（第 1 場的第 3 個節拍）。有 `plan` 時每一鏡都填，腳本才能檢查高點與漏拍，見上方 `plan[]` |
| `source` | 是 | 原文對應：十五字以內的一小句，或段落號 |
| `duration` | 是 | 成片秒數（裁完頭尾之後用在片子裡的長度） |
| `setup` | 否 | 機位編號。填了就沿用那個機位的 `bg`（和 `light`） |
| `size` | 是 | 景別：取景範圍有多大，見下方用詞 |
| `type` | 否 | 鏡頭類型：過肩、主觀、雙人、空鏡、插入等，見下方用詞。不填就是單人鏡頭 |
| `angle` | 否 | 角度：平視、俯拍、仰拍等，見下方用詞。不填就不寫進提示詞，生成工具通常給平視 |
| `height` | 否 | 機位高度：地面、低機位、眼睛高度、高機位，見下方用詞。和角度分開填；高度對這一鏡重要時才填 |
| `lens` | 否 | 焦段：廣角、標準、長焦等，或直接寫 `35mm`，見下方用詞。真人寫實最有用；不填就由工具決定 |
| `camera` | 是 | 運鏡，見下方用詞。帶方向的運鏡一定要寫方向 |
| `speed` | 否 | 速度：升格（慢動作）、降格、縮時、變速、定格，見下方用詞。不填就是正常速度 |
| `render` | 否 | 生成方式：`影片`（預設）、`靜幀運鏡`、`靜幀`，見下方用詞。靜幀只出首幀圖，不跑影片 |
| `link` | 是 | `切` 或 `接續`。這是首幀從哪裡來：「切」各自生成首幀，「接續」沿用上一鏡的最後一幀 |
| `transition` | 否 | 轉場：從上一鏡進到這一鏡的剪接方式，見下方用詞。不填就是硬切。給剪接的人看，不進提示詞 |
| `action` | 是 | 給人看的一句話：這一鏡發生什麼。可以用角色名 |
| `line` | 否 | `{"type": …, "who": 角色編號或「旁白」, "text": "…", "tone": "…"}`；沒有就填 `null`。`type` 見下方「台詞類型」。`tone` 是片段，可省略：這句話的語氣（「低沉、遲疑」；英文寫成說法 `hesitantly, almost a whisper`。音色寫在角色的 `voice`），原生音訊方案下會進影片提示詞，其他方案給配音的人看。一句話要跨兩鏡時，拆成兩段分別填在兩鏡 |
| `sound` | 否 | 環境音與音效，只寫故事裡聽得到的聲音。聲音方案是 `原生音訊` 時它會進影片提示詞，要當成片段用提示詞語言寫。寫到配樂腳本會提示 |
| `music` | 否 | 配樂提示，給剪接的人看：配樂在這一鏡進、轉、停，或重拍落在這裡（「弦樂在這一鏡開頭輕輕進來」）。不進提示詞；分鏡表會列成「配樂提示」表，附上開始時間 |
| `cast[]` | 是 | 畫面中的角色與走位；純空鏡或沒有任何人體入鏡的物件特寫填 `[]` |
| `props` | 否 | 片段。不在手上、但畫面中要交代的道具與它的狀態 |
| `fx[]` | 否 | 這一鏡的特效：`[{"id": "F01", "state": "花苞", "pos": "左手掌心正中"}]`。`state` 是設定檔登記的狀態名稱；`pos` 是片段，寫在畫面哪裡、附著在什麼上面；`motion`、`light` 可省略，不填就用設定檔的（有分狀態的用那個狀態的），寫 `false` 表示這一鏡不加。後製的特效不進提示詞，只寫進備註 |
| `bg` | 否 | 片段。這一鏡實際看得到的背景。近景以內都要有（自己填，或由機位提供）；都沒有時腳本用整段 `space`，只適合全景以上 |
| `light` | 否 | 片段。這一鏡的光線，填了就取代機位與場景的光線。用在光線短暫改變，或特寫裡看不到場景光源的時候 |
| `palette` | 否 | 片段。這一鏡的色彩，填了就取代場景的 `palette`。用在閃電、警燈掃過這類短暫改變整個畫面顏色的時候 |
| `frame` | 否 | 片段。景別、類型、角度以外的構圖：主體放在畫面哪裡、前景有什麼、景深、留白。替後製留白時只寫看得見的空白，不寫空白是給什麼的；片段裡出現「後製」「數字」「文字」腳本會警告 |
| `end` | 建議 | 片段。結束時的畫面和首幀差在哪裡。要讓沒看過這一鏡的人也讀得懂，用短稱指人。有運鏡時，寫運鏡之後看到的樣子 |
| `motion` | 是 | 片段。怎麼動，用短稱指人。寫法見下。`render` 是靜幀時不用填 |
| `refs[]` | 否 | 額外要掛的參考圖，例如 `"C01 表情組圖"`、`"EP01-004 的首幀圖"`。角色的造型設定圖（近景以內再加頭像）、背景圖（有機位用機位背景圖，否則用場景定稿圖）、片段裡引用的道具圖（寫了狀態就用那個狀態的圖）、特效參考圖都由腳本列出，這裡寫了也不會重複；`refs` 排在它們後面。`參考圖` 模式要照這個順序上傳。「接續」的鏡頭沿用上一鏡的最後一幀，不自動列 |
| `negative` | 否 | 片段。這一鏡特有的負面詞，會接在通用負面詞後面。能寫成正面描述的先寫成正面；工具沒有負面詞欄位時不要填 |
| `risk` | 否 | 這一鏡的風險與備案 |
| `continuity` | 否 | 連戲備註：道具狀態、軸線、和前後鏡怎麼接。它不進提示詞：道具被收走、拿出來這類變化寫在這裡不會發生，要拍一鏡或寫進 `motion`、`end`；這一鏡和前一鏡都沒寫時腳本會提示 |
| `post` | 否 | 剪接時要加的東西：後製的字（手機訊息、信件內容）、花字、集中線、速度線、震屏、調色上的變化。給剪接的人看，不進提示詞；腳本會連同靜幀的推拉、變速、定格與後製特效列在備註與 CSV 的「後製」欄 |
| `cut` | 否 | 這一鏡之後適合切開時，寫一句理由，例如 `"懸念：她看見手機訊息"`。腳本會在精簡表標 ✂、算出累計時間，並另外列成「建議切點」表。只用在沒有指定單集長度的漫劇與短劇 |

### cast[]

| 欄位 | 說明 |
|---|---|
| `char` | 造型變體編號，例如 `C01-a` |
| `facing` | 朝向，見下方用詞：正面、半側朝左、半側朝右、側面朝左、側面朝右、背面。左右指臉朝畫面哪一邊。腳本會換成提示詞的寫法，放在 `pos` 前面；同一個機位裡同一個人左右對調會提示 |
| `pos` | 片段。在畫面的哪裡、什麼姿勢；沒填 `facing` 時也寫朝哪個方向。這裡用畫面座標 |
| `gaze` | 片段。看誰、看哪裡 |
| `hands` | 片段。兩隻手各在哪裡、拿著什麼；不在畫面內也要寫「手不在畫面內」 |
| `face` | 片段。表情，可空。寫看得見的眉、眼、嘴與呼吸，不要只寫一個情緒詞（只寫「難過」腳本會提示）；常見情緒的寫法見 `prompt-writing.md` 的情緒對照表 |
| `partial` | 角色沒有完整入鏡時用。填 `true`：背影或前景虛焦，腳本改用短稱加服裝，不寫臉部細節與狀態。填一段片段：只入鏡身體的一部分，腳本直接用這段文字，例如 `"partial": "一隻從畫面右緣伸入的手，袖口是米白色毛衣"` |

`pos`、`gaze`、`hands` 三項都要寫。沒寫的地方生成工具會自己猜，這正是這份分鏡要避免的事。非人角色例外：`器物` 只要寫 `pos`；`動物` 和 `異獸` 要寫 `pos` 與 `gaze`，前爪有動作才寫 `hands`。唯一的例外是 `partial` 寫成片段的時候（只入鏡一隻手、一雙腳）：那段文字已經說明看得到什麼，只要再用 `pos` 交代它在畫面哪裡；不要為了填滿欄位寫「臉不在畫面內」，否定句反而容易把臉叫出來。

### motion 的寫法

一句到兩句，依序是：

1. 主動作，以及它的起因或結果（「風吹起頭髮，黑髮及肩的年輕女子抬手按住」，而不是「頭髮飄動」）。
2. 一兩個微動作：眨眼、呼吸起伏、吞嚥、手指的小動作。
3. 有原因的次要運動：窗簾、衣擺、煙、影子，方向和強度要與主動作一致。
4. 不動的部分也可以點出來（「其餘保持靜止」），多人鏡頭尤其有用。

不要寫外貌、服裝、場景，那些已經在首幀圖裡。不要寫運鏡，腳本會從 `camera` 加上去。

## 用詞

一個鏡頭「怎麼拍」拆成幾個欄位，各管一件事：`size` 管取多大、`type` 管拍誰和從哪個關係拍、`angle` 管往上看還是往下看、`height` 管攝影機離地多高、`lens` 管焦段、`camera` 管鏡頭怎麼動、`speed` 管播放的快慢、`render` 管要不要跑影片。下面是腳本認得的標準用詞：它會換成提示詞的寫法，並據此做檢查。景別、類型、角度、高度、焦段、運鏡用了用詞表以外的寫法，腳本原樣放進提示詞；要出英文提示詞時請寫成 `{"zh": "…", "en": "…"}`。速度與生成方式只收用詞表裡的詞。

什麼時候用哪一種，見 `shot-craft.md`。

### 景別（`size`）

| 景別 | 取景範圍 | 英文提示詞 | 主要用途 |
|---|---|---|---|
| 大遠景 | 環境為主，人物很小或沒有 | extreme wide shot | 交代地點；表現渺小、孤立 |
| 遠景 | 人物全身入鏡，但只佔畫面一小部分 | wide shot | 建立鏡頭；人和環境的關係 |
| 全景 | 人物從頭到腳剛好入鏡 | full shot | 肢體動作、走位、人物之間的位置 |
| 中全景 | 膝蓋以上 | medium full shot | 站姿與手上的動作；兩三個人同框 |
| 中景 | 腰部以上 | medium shot | 對話的基本景別；看得到手勢 |
| 近景 | 胸部以上 | medium close-up | 表情與情緒；對話戲用得最多 |
| 特寫 | 肩部以上，臉佔畫面大部分 | close-up | 情緒高點、關鍵反應 |
| 大特寫 | 臉或物件的局部（眼睛、嘴角、指尖、鑰匙孔） | extreme close-up | 極度強調；用得少才有力 |

- 「中景」「近景」這些詞各地的定義不一樣，生成工具也各自解讀，所以以這張表的取景範圍為準。畫面裡有完整入鏡的人物時，腳本會把範圍一起寫進提示詞（「中景，腰部以上入鏡」、`medium shot, framed from the waist up`）。
- 鏡頭裡要看到的東西決定景別，不是反過來：要看到踏步就不能用中景，要看到手上的動作至少要中景。
- 拍物件時照它佔畫面的比例類推：整件入鏡、周圍還有環境是近景，佔滿畫面是特寫，只拍局部是大特寫。
- 舊寫法「中近景」「中特寫」等同近景，「中遠景」等同中全景，腳本照收。

### 人物朝向（`cast[].facing`）

| 朝向 | 中文提示詞 | 英文提示詞 |
|---|---|---|
| 正面 | 正面朝向鏡頭 | facing the camera |
| 半側朝左、半側朝右 | 半側面朝畫面左（右） | three-quarter view, facing frame left (right) |
| 側面朝左、側面朝右 | 正側面朝畫面左（右） | in profile, facing frame left (right) |
| 背面 | 背對鏡頭 | with their back to the camera |

- 左右指臉朝向畫面的哪一邊。過肩正反打時，兩個人的方向相反：甲半側朝右，乙就半側朝左。
- 背面要同時設 `partial: true`，否則提示詞會寫一整段看不到的臉，腳本會提示。
- 同一個機位裡同一個人上一鏡朝左、這一鏡朝右，腳本會提示；真的轉身了，在前一鏡的 `end` 寫出來。

### 鏡頭類型（`type`）

| 類型 | 意思 | 英文提示詞 | 怎麼填 |
|---|---|---|---|
| 單人 | 一個人，預設值 | （不寫） | 不用填 |
| 雙人 | 兩個人都清楚入鏡 | two-shot | 9:16 畫面窄，並排的雙人很擠，改用一前一後的縱深或過肩 |
| 群像 | 三人以上同框 | group shot | 只有主要人物寫完整，其餘用 `partial` 或寫在 `bg`。中全景以上的寬鏡頭裡，`partial` 的人也會寫進身高 |
| 過肩 | 越過前景人物的肩膀，拍對面的人 | over-the-shoulder shot | 前景的人設 `partial: true`；`size` 指的是對面那個人的取景範圍 |
| 主觀 | 角色眼睛看到的畫面 | first-person POV shot | `cast` 不放這雙眼睛的主人，只放他看到的人或物；他的手入鏡時用 `partial` 片段 |
| 背後 | 從人物背後拍 | shot from behind | 人物設 `partial: true` |
| 空鏡 | 沒有人的場景 | scenery only, unoccupied | `cast` 填 `[]` |
| 插入 | 物件或身體局部的細節 | detail shot | 配特寫或大特寫；手腳入鏡時用 `partial` 片段 |

「建立鏡頭」「反應鏡頭」是鏡頭的功能，不是類型：建立鏡頭通常填遠景或全景（可以是空鏡），反應鏡頭就是聽的人的單人近景。

舊檔把過肩、主觀、背影、空鏡、物件特寫寫在 `size` 裡，腳本照舊處理並提示；這樣寫的鏡頭沒有景別，建議補上。

### 角度（`angle`）

| 角度 | 英文提示詞 | 給人的感覺 |
|---|---|---|
| 平視 | eye-level shot | 中性；不填時生成工具通常也給平視 |
| 微俯、俯拍 | slightly high angle、high-angle shot | 人物顯得弱小、受壓；也用來看清桌面上的東西 |
| 頂拍 | top-down overhead shot | 從正上方垂直往下：桌面、躺著的人、圖案化的構圖 |
| 微仰、仰拍 | slightly low angle、low-angle shot | 人物顯得有力、有威脅 |
| 傾斜 | Dutch angle | 不安、失衡；少用 |

同一場戲裡角度不要無故改變。俯仰是有意義的，換角度就是在告訴觀眾人物的處境變了。

### 機位高度（`height`）

| 高度 | 英文提示詞 | 用途 |
|---|---|---|
| 地面 | ground-level camera | 腳步、積水、地上的東西；搭配平視或仰拍 |
| 低機位 | low camera height, about one metre off the ground | 約腰部高度：孩子或寵物的視角；人物稍微顯得高大 |
| 眼睛高度 | camera about 1.6 metres off the ground | 中性；不填時生成工具通常也給這個高度 |
| 高機位 | high camera position, about three metres off the ground | 高過頭頂：看清人群、桌面、人物之間的距離 |

- 角度是往上看或往下看，高度是攝影機離地多高，兩者可以任意搭配：低機位平視是貼著桌面看過去，低機位仰拍是英雄式的仰角。
- 「地面」配「俯拍」或「頂拍」是矛盾的，腳本會警告。
- 機位背景圖會寫上高度：這個機位的鏡頭都同一個高度時才寫。提示詞用離地的公尺數，不用「腰部」「頭頂」，免得沒有人的背景圖被身體部位叫出人來。

### 焦段（`lens`）

| 焦段 | 提示詞 | 英文提示詞 | 效果 |
|---|---|---|---|
| 超廣角 | 超廣角鏡頭，約 16mm | ultra-wide 16mm lens | 空間被誇張地拉開，邊緣變形；壓迫、荒謬、狹小的空間 |
| 廣角 | 廣角鏡頭，約 24mm | wide-angle 24mm lens | 收得進整個環境，近大遠小；建立鏡頭、室內 |
| 小廣角 | 35mm 鏡頭 | 35mm lens | 接近人眼看到的空間感；跟拍、紀實、中景 |
| 標準 | 標準鏡頭，約 50mm | standard 50mm lens | 自然、不誇張；對話的中景與近景 |
| 中長焦 | 中長焦鏡頭，約 85mm | 85mm lens | 臉的比例好看，背景柔和虛化；人物近景與特寫 |
| 長焦 | 長焦鏡頭，約 135mm | 135mm telephoto lens | 前後景被壓在一起，背景大片虛化；偷看、人群裡的一個人、追逐 |
| 微距 | 微距鏡頭 | macro lens | 很小的東西拍到佔滿畫面：水珠、眼睛、針腳 |
| 魚眼 | 魚眼鏡頭 | fisheye lens | 畫面成球形；醉、夢、監視器 |

- 也可以直接寫 `35mm`、`100mm` 這類焦距，腳本原樣放進提示詞。
- 焦段和景別是兩件事：同樣是近景，廣角要貼得很近、背景收得多，長焦站得遠、背景虛化。真人寫實裡，同一場戲的正反打用同一個焦段，臉的比例才不會一鏡一個樣。
- 淺景深、前景虛焦這類效果寫在 `frame`，見 `prompt-writing.md` 第四節。

### 運鏡（`camera`）

| 用詞 | 攝影機怎麼動 | 英文提示詞 |
|---|---|---|
| 固定 | 不動 | static camera |
| 推近、拉遠 | 整台攝影機往前、往後 | push-in、pull-out |
| 左搖、右搖 | 位置不動，鏡頭水平轉向 | pan left、pan right |
| 上搖、下搖 | 位置不動，鏡頭垂直轉向 | tilt up、tilt down |
| 左移、右移 | 整台攝影機橫向平移 | truck left、truck right |
| 上升、下降 | 整台攝影機垂直升降 | pedestal up、pedestal down |
| 跟拍 | 跟著移動中的主體走 | follow shot |
| 左環繞、右環繞 | 繞著主體轉 | arc shot to the left、to the right |
| 變焦推近、變焦拉遠 | 攝影機不動，只是鏡頭變焦 | zoom in、zoom out |
| 手持 | 輕微不規則的晃動 | handheld sway |
| 移焦到後景、移焦到前景 | 攝影機不動，對焦從前景轉到後景，或反過來 | rack focus from the foreground to the background（反之亦然） |
| 左甩、右甩 | 極快的水平搖，中間糊成一片 | whip pan left、whip pan right |
| 滑動變焦 | 攝影機前後移動、同時反向變焦：主體大小不變，背景前後拉伸 | dolly zoom |
| 搖臂上升、搖臂下降 | 攝影機掛在長臂上升降，高度和俯仰一起變 | crane up、crane down |
| 航拍前進、航拍上升 | 空拍機向前飛，或垂直升高 | aerial drone shot flying forward、rising straight up |

- 前面可以加「緩慢」或「輕微」：`緩慢推近`、`輕微左搖`。運鏡的幅度跟著戲走：安靜的戲小，衝突與追逐可以大。
- **帶方向的運鏡一定要寫方向。**「橫移」「環繞」「移焦」「甩鏡」「搖臂」「航拍」沒寫方向，腳本會警告，因為生成工具只能猜。
- 搖和移不一樣：搖是站著轉頭，背景只是從畫面一邊滑到另一邊；移是整個人走過去，前後景會錯開，有空間感。推近和變焦推近的差別也一樣。上升、下降是整台攝影機垂直移動，鏡頭方向不變；搖臂是邊升降邊改變俯仰。
- 一鏡只用一種運鏡。人物有明顯動作時鏡頭固定，要運鏡時讓人物幾乎不動；兩邊同時動最容易變形。
- 運鏡要有理由（推近是強調、拉遠是揭示、搖是跟隨視線、移焦是轉移注意力），見 `shot-craft.md` 第六節。沒有理由就用固定。
- 甩鏡、環繞、滑動變焦是比較難生成的運鏡。選定的工具做不穩時（`tool_limits.complex_camera` 是 `false`），這一鏡沒寫 `risk` 腳本會提示；甩鏡多半改成轉場：前後兩鏡各自固定，`transition` 填「甩鏡」，剪接時接起來。
- 移焦要說清楚從什麼移到什麼時，寫成完整片段：`{"zh": "焦點從前景的信封移到後方女子的臉", "en": "rack focus from the envelope in the foreground to the woman's face behind it"}`。
- 俯拍、仰拍是角度不是運鏡，填在 `angle`。

英文用詞對照的是 Google 影片提示詞指南列的 pan、tilt、truck、pedestal、zoom、arc shot，以及可靈 4.0 指南用的 push-in、pull-out（2026-11-25 查證）。rack focus、whip pan、dolly zoom、crane、aerial drone shot 是通用的攝影術語，各工具是否都認得沒有逐一查證。

### 速度（`speed`）

| 用詞 | 意思 | 怎麼做 |
|---|---|---|
| 升格 | 慢動作 | 影片提示詞加「慢動作」（slow motion） |
| 降格 | 快動作 | 影片提示詞加「快動作」（fast motion） |
| 縮時 | 縮時攝影：很長的時間壓成幾秒 | 影片提示詞加「縮時攝影」（time-lapse） |
| 變速 | 同一鏡裡從正常變慢再恢復 | 不進提示詞；照正常速度生成，剪接時做，列在後製備註 |
| 定格 | 停在最後一幀 | 不進提示詞；剪接時做，停的時間算在 `duration` 裡，列在後製備註 |

什麼時候用見 `shot-craft.md` 第六節。慢動作一場戲最多一兩鏡；原生音訊方案下，慢動作的鏡頭不要放「對白」，腳本會提示。

### 生成方式（`render`）

| 方式 | 產出 | 腳本怎麼處理 |
|---|---|---|
| 影片 | 首幀、尾幀、影片 | 預設值 |
| 靜幀運鏡 | 只有首幀圖，剪接時在圖上推拉或搖移 | 不出影片提示詞與尾幀；`camera` 變成給剪接的指示，只能是固定、推近、拉遠、搖、移、變焦或手持；`motion`、`end` 可以不填 |
| 靜幀 | 只有首幀圖，畫面停住 | 同上，`camera` 填固定 |

- 靜幀不受工具單次秒數限制，也不做影片提示詞的長度檢查。
- 靜幀的人嘴不會動。聲音方案是後配口型或原生音訊時，「對白」的鏡頭不要用靜幀，腳本會提示。
- 分鏡表開頭會列出影片和靜幀各幾鏡；CSV 有「生成方式」欄。什麼時候用見 `shot-craft.md` 第十二節。

### 轉場（`transition`）

從上一鏡進到這一鏡的剪接方式。不填就是硬切，絕大多數鏡頭都是硬切。轉場是剪接時做的，但有幾種需要兩鏡的畫面事先配合，所以要在拆鏡時決定。

| 轉場 | 意思 | 用在哪裡 | 拆鏡時要配合的事 |
|---|---|---|---|
| 動作剪輯 | 在動作進行中切，下一鏡接著同一個動作 | 讓剪接點不被察覺；換景別時最順 | 上一鏡的 `end` 停在動作中途，這一鏡從動作的後半開始 |
| 視線剪輯 | 上一鏡的人看向某處，這一鏡是他看到的東西 | 引出主觀鏡頭或插入鏡頭 | 上一鏡的 `gaze` 方向要對得上這一鏡的位置 |
| 匹配剪輯 | 兩鏡的形狀或構圖相似（圓月接圓碗） | 跨時間、跨地點的連結 | 兩鏡用 `frame` 把主體放在畫面同一個位置、同樣大小 |
| 疊化 | 兩個畫面交疊著換 | 時間流逝、進出回憶 | 兩鏡構圖單純，主體不要重疊在同一處 |
| 淡入、淡出 | 從黑畫面浮現、漸漸變黑 | 一集或一大段的開頭與結尾 | 無 |
| 黑場 | 中間隔一小段全黑 | 大段時間跳躍、昏迷、熄燈 | 無 |
| 閃白 | 一瞬間全白 | 衝擊、閃回 | 無 |
| 聲音先入 | 這一鏡的聲音在上一鏡結束前就先出現（J-cut） | 帶出下一場；製造期待 | 在 `sound` 註明 |
| 聲音延後 | 上一鏡的說話聲延續到這一鏡（L-cut） | 對話戲切到聽的人時最常用 | 這一鏡的 `line` 用「畫外音」 |
| 甩鏡 | 上一鏡結尾和這一鏡開頭各帶一段糊掉的快搖，接在一起 | 急轉到另一個地點或另一個人；製造衝勁 | 兩鏡各自固定或輕微搖，方向一致；糊掉的部分剪接時做 |
| 跳接 | 同一主體、同景別直接切 | 刻意的時間壓縮或焦躁感 | 只有刻意時才用；填了腳本就不警告跳接 |

「接續」的鏡頭沒有剪接點，不填轉場。

### 台詞類型（`line.type`）

| 類型 | 意思 |
|---|---|
| 對白 | 角色在這場戲裡說話，而且這一鏡拍得到他（正面入鏡） |
| 畫外音 | 角色在這場戲的現場說話，但這一鏡沒拍到他說：拍的是聽的人、物件，或他只有背影。英文劇本記作 O.S. |
| 旁白 | 敘事者的聲音，不屬於這場戲的現場。英文劇本記作 V.O. |
| 內心獨白 | 角色心裡的話，沒有說出口。也是 V.O. 的一種 |

- 中文口語習慣把內心獨白叫「OS」，和劇本格式的 O.S.（畫外音）意思剛好不同，所以這裡用中文、不用縮寫。舊檔的 `VO`、`OS` 腳本照收。
- 聲音方案是「旁白」時，角色的台詞仍然照上表填「對白」或「畫外音」（`who` 填角色編號），由配音蓋在畫面上；角色不開口，表情寫「嘴唇自然閉合」。
- 聲音方案是「原生音訊」時，只有「對白」會寫進影片提示詞。「畫外音」在剪接時把說話者那一鏡的聲音延伸過來，或另外配音；讓生成工具替沒入鏡的人配聲音，聲線每次都不一樣。
