# 欄位定義

兩個檔案：`bible.json`（設定，整個專案共用）和 `EPxx.json`（一集的分鏡）。完整範例在 `examples/`。

## 提示詞片段與語言

標了「片段」的欄位會被腳本原樣放進提示詞，請用提示詞語言寫，寫成沒有主詞也讀得通的名詞短語，結尾不加句號。腳本用逗號把片段接起來，所以寫成完整句子會接得很怪。

- 提示詞只出一種語言時，片段寫成字串：`"look": "二十歲出頭的女性，鵝蛋臉"`
- 中英都出時，寫成物件：`"look": {"zh": "二十歲出頭的女性，鵝蛋臉", "en": "a woman in her early twenties with an oval face"}`

沒標「片段」的欄位是給人看的，用使用者的語言寫。鏡別和運鏡用下面的標準用詞時，腳本會自動換成英文。

片段裡可以寫 `{P01}` 引用道具，腳本會換成 `props` 裡那件道具的描述。

## bible.json

### project

| 欄位 | 說明 |
|---|---|
| `title` | 專案名稱 |
| `format` | `漫劇` 或 `正式動畫` |
| `aspect` | `9:16` 或 `16:9`。只顯示在設定表提醒使用者，不會進提示詞 |
| `image_tool`、`video_tool` | 工具名稱，顯示用 |
| `prompt_langs` | `["zh"]`、`["en"]` 或 `["zh","en"]` |
| `video_mode` | `i2v`（圖生影片，預設）或 `t2v`（文字生影片）。`t2v` 時腳本會把外貌與場景也寫進影片提示詞 |
| `use_last_frame` | 工具支援首尾幀就填 `true`，腳本會輸出尾幀提示詞。工具還沒定時填 `true` |
| `audio_plan` | `旁白`、`後配口型` 或 `原生音訊` |
| `clip_range` 或 `clip_lengths` | 工具單次可生成的秒數。連續範圍用 `"clip_range": [3, 30]`，固定幾種用 `"clip_lengths": [4, 6, 8]`。用來檢查鏡頭會不會太長，並算出建議生成秒數。工具還沒定就不要填 |
| `prompt_limits` | 工具的提示詞長度上限，可省略。例如 `{"image": {"zh": 300, "en": 600}, "video": {"zh": 500, "en": 1000}}`，中文算字數，英文算詞數。腳本會檢查每一鏡組合後有沒有超過 |
| `speech_rate` | 每秒幾個中文字，預設 4.5。使用者要快節奏解說可調到 5.5 || `style_lock` | 片段。畫風、線條、色彩與質感。會加到每一張圖，所以不要提背景、人物、天氣或光線方向 |
| `negative_global` | 片段。通用負面詞。預設填空字串；只有工具確定有獨立的負面詞欄位才寫。它是給影片工具用的 |
| `speech_lang` | 片段，只在 `原生音訊` 有用。台詞的語言，例如 `{"zh": "普通話", "en": "Mandarin Chinese"}`。提示詞語言和台詞語言不同時要填，腳本會寫成「用普通話說」 |
| `audio_suffix` | 片段，只在 `原生音訊` 有用。接在每一鏡影片提示詞最後的短指令，例如 `不要字幕`。有些工具的文件建議這樣寫 |

### characters[]

| 欄位 | 說明 |
|---|---|
| `id` | `C01`、`C02`… |
| `name` | 角色名，顯示用，不會進提示詞 |
| `tag` | 片段。短稱，十個字左右，看得出是誰，角色之間不會混淆。`motion` 和 `end` 裡用它指人 |
| `look` | 片段。不會變的外貌：年齡、臉型、髮型髮色、眼睛、體型 |
| `marks` | 片段。辨識特徵（痣、疤、飾品），可空 |
| `variants[]` | 造型變體，至少一個，見下表 |
| `expressions` | 片段，可省略。表情組圖要畫哪幾種表情，預設是「平靜、微笑、難過、生氣」。依角色在戲裡實際用到的表情改 |
| `minor` | 填 `true` 表示配角或龍套，只出設定圖，不出表情組圖 |

年齡差很多的同一個人（回憶中的童年）外貌不同，另開一個角色編號，並在 `name` 註明。

**variants[]**

| 欄位 | 說明 |
|---|---|
| `id` | `C01-a`、`C01-b`… |
| `label` | 顯示用，例如「居家」「受傷後」 |
| `outfit` | 片段。完整服裝 |
| `outfit_top` | 片段，可省略。上半身的服裝。中近景以內看不到下半身，腳本會改用這一段，提示詞比較短也不會出現褲子鞋子 |
| `state` | 片段，可空。狀態，例如「左臉頰有一道擦傷」 |
| `sheet` | 片段，可省略。設定圖的畫法，預設是「正面、側面、背面全身三視圖，自然站姿，表情平靜」。臥床或坐輪椅的角色改成合適的，例如「正面與側面半身視圖，靠坐在床上」 |

第二個以後的造型，腳本產出的設定圖提示詞是「拿第一個造型的設定圖來改」，這樣臉才不會變。所以把最基本的造型排第一個。

### scenes[]

| 欄位 | 說明 |
|---|---|
| `id` | `S01`、`S02`… |
| `name` | 地點名，顯示用 |
| `space` | 片段。不會動的結構、門窗、大型家具，以及它們的空間關係。不寫畫面左右，不寫會移動或會變狀態的東西 |
| `light` | 片段。光源、方向、明暗。不要重複時間，也不要寫飽和度（那歸風格鎖定句） |
| `time` | 片段。時間與天氣 |

同一地點換了時段、而且之後很多鏡都是新光線，才另開場景編號（S01 傍晚、S02 深夜），`space` 的文字保持一模一樣。一場戲裡短暫的光線變化用每一鏡的 `light` 覆寫。

### props[]

反覆出現、需要每次長得一樣的道具。只出現一次的不用登記。

| 欄位 | 說明 |
|---|---|
| `id` | `P01`、`P02`… |
| `name` | 道具名，顯示用 |
| `desc` | 片段。十五字以內的外觀描述，寫成名詞短語（「一把磨得發亮的舊銅鑰匙」）。只寫不會變的外觀，狀態（拆了沒、亮不亮）寫在鏡頭裡 |

鏡頭裡任何片段都可以寫 `{P01}`，例如 `"hands": "右手握著{P01}"`。腳本也會為每件道具產出一張道具圖的提示詞。

### 其他

| 欄位 | 說明 |
|---|---|
| `pending[]` | 待確認設定，每項一句話：哪個設定、為什麼是暫定、暫定值是什麼 |
| `log[]` | 每做完一集加一行收尾狀態，下一集接戲用 |

## EPxx.json

| 欄位 | 說明 |
|---|---|
| `episode` | `EP01`。會用在輸出檔名 |
| `source_title` | 這一集對應的原文範圍 |
| `changes[]` | 對原文的刪減、合併、新增、調動順序，每項一句話 |
| `shots[]` | 鏡頭，依播放順序 |

### shots[]

| 欄位 | 必填 | 說明 |
|---|---|---|
| `id` | 是 | `EP01-001`。插入鏡頭用 `EP01-004a` |
| `scene` | 是 | 場景編號 |
| `source` | 是 | 原文對應：十五字以內的一小句，或段落號 |
| `duration` | 是 | 成片秒數（裁完頭尾之後用在片子裡的長度） |
| `size` | 是 | 鏡別，見下方用詞 |
| `camera` | 是 | 運鏡，見下方用詞 |
| `link` | 是 | `切` 或 `接續` |
| `action` | 是 | 給人看的一句話：這一鏡發生什麼。可以用角色名 |
| `line` | 否 | `{"type": "VO" / "OS" / "對白", "who": 角色編號或「旁白」, "text": "…"}`；沒有就填 `null`。`VO` 是旁白或畫外音，`OS` 是內心獨白，`對白` 是角色在畫面裡開口說。一句話要跨兩鏡時，拆成兩段分別填在兩鏡 |
| `sound` | 否 | 環境音與音效。聲音方案是 `原生音訊` 時它會進影片提示詞，要當成片段用提示詞語言寫 |
| `cast[]` | 是 | 畫面中的角色與走位；純空鏡或沒有任何人體入鏡的物件特寫填 `[]` |
| `props` | 否 | 片段。不在手上、但畫面中要交代的道具與它的狀態 |
| `bg` | 否 | 片段。這一鏡實際看得到的背景。中近景以內都要填；不填時用整段 `space`，適合全景 |
| `light` | 否 | 片段。這一鏡的光線，填了就取代場景的 `light` 與 `time`。用在光線短暫改變，或特寫裡看不到場景光源的時候 |
| `frame` | 否 | 片段。鏡別以外的構圖：俯仰角度、誰佔畫面哪一塊、景深 |
| `end` | 建議 | 片段。結束時的畫面和首幀差在哪裡。要讓沒看過這一鏡的人也讀得懂，用短稱指人。有運鏡時，寫運鏡之後看到的樣子 |
| `motion` | 是 | 片段。怎麼動，用短稱指人。寫法見下 |
| `refs[]` | 否 | 這一鏡要掛的參考圖，例如 `"C01-a 設定圖"`、`"S01 場景定稿圖"`、`"P01 道具圖"` |
| `negative` | 否 | 片段。這一鏡特有的負面詞，會接在通用負面詞後面。工具沒有負面詞欄位時不要填 |
| `risk` | 否 | 這一鏡的風險與備案 |
| `continuity` | 否 | 連戲備註：道具狀態、軸線、需要後製加的字 |
| `cut` | 否 | 這一鏡之後適合切開時，寫一句理由，例如 `"懸念：她看見手機訊息"`。腳本會在精簡表標 ✂、算出累計時間，並另外列成「建議切點」表 |

### cast[]

| 欄位 | 說明 |
|---|---|
| `char` | 造型變體編號，例如 `C01-a` |
| `pos` | 片段。在畫面的哪裡、朝哪個方向、什麼姿勢。這裡用畫面座標 |
| `gaze` | 片段。看誰、看哪裡 |
| `hands` | 片段。兩隻手各在哪裡、拿著什麼；不在畫面內也要寫「手不在畫面內」 |
| `face` | 片段。表情，可空。不要完美對稱的標準表情，寫具體一點（「嘴角微僵」「眼神游移」） |
| `partial` | 角色沒有完整入鏡時用。填 `true`：背影或前景虛焦，腳本改用短稱加服裝，不寫臉部細節與狀態。填一段片段：只入鏡身體的一部分，腳本直接用這段文字，例如 `"partial": "一隻從畫面右緣伸入的手，袖口是米白色毛衣"` |

`pos`、`gaze`、`hands` 三項都要寫。沒寫的地方生成工具會自己猜，這正是這份分鏡要避免的事。

### motion 的寫法

一句到兩句，依序是：

1. 主動作，以及它的起因或結果（「風吹起頭髮，黑髮及肩的年輕女子抬手按住」，而不是「頭髮飄動」）。
2. 一兩個微動作：眨眼、呼吸起伏、吞嚥、手指的小動作。
3. 有原因的次要運動：窗簾、衣擺、煙、影子，方向和強度要與主動作一致。
4. 不動的部分也可以點出來（「其餘保持靜止」），多人鏡頭尤其有用。

不要寫外貌、服裝、場景，那些已經在首幀圖裡。不要寫運鏡，腳本會從 `camera` 加上去。

## 用詞

**鏡別（`size`）**：大遠景、遠景、全景、中景、中近景、近景、特寫、大特寫、過肩、主觀、背影、空鏡、物件特寫

**運鏡（`camera`）**：固定、緩慢推近、緩慢拉遠、輕微橫移、輕微跟拍、輕微手持、輕微上搖、輕微下搖

運鏡幅度一律小。一鏡只用一種運鏡，而且人物有明顯動作時鏡頭最好固定，兩邊同時動最容易變形。俯拍、仰拍是角度不是運鏡，寫在 `frame`。
