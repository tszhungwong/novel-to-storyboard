# 生成後的驗收與除錯

分鏡寫好只是一半。這一份說生成出來之後怎麼判斷能不能用、不能用時改哪裡。使用者問「這一鏡一直生成不好怎麼辦」、貼了生成結果要你看，或交付時要提醒製作流程時讀。

腳本會在每一鏡的生成資料寫「驗收重點」（CSV 也有這一欄），列的是這一鏡特別容易出錯的地方：雙人鏡頭的髮色互串、手、軸線、同機位的背景、運鏡方向、嘴型。下面第一節的通用項目每一鏡都要看，腳本不會逐鏡重複。

## 一、驗收順序與標準

照製作順序驗，前一關沒過就不要往下做。資產圖不穩，後面每一鏡都會跟著錯。

### 1. 資產圖（定稿之前）

- 設定圖的正面、側面、背面是同一個人：髮型、瀏海、髮色、體型、服裝的顏色與款式一致。
- 和 `bible.json` 的描述對得上：寫了齊瀏海就要有齊瀏海，寫了痣就要有痣。對不上的不要將就，重抽或改描述，否則之後每一鏡都會在「設定檔」和「參考圖」之間搖擺。
- 手指數正確、沒有多餘的肢體；三視圖裡沒有長出第二個人。
- 畫面上沒有亂碼文字、浮水印、色票以外的雜物。
- 表情組圖的每一格都是同一張臉。
- 場景定稿圖與機位背景圖沒有人。同一個場景的幾張機位背景圖，牆面材質、家具、光線的方向和顏色要一致；有出入時以場景定稿圖為準，把其他幾張改到一致。
- 定稿之後在 `assets.csv`（機位背景圖在 `<集數>-assets.csv`）記下採用的檔名與 seed。

### 2. 首幀

- 臉、髮型和設定圖一致，辨識特徵（痣、眼鏡、疤）都在。
- 服裝是這一鏡指定的造型變體（受傷、換裝之後的那一套）。
- 人數正確；誰在畫面左、誰在畫面右和分鏡一致（對照機位的 `desc`，這是軸線）。
- 景別對：寫中景就不能出全身。
- 視線方向和分鏡一致，尤其是視線剪輯的前一鏡（看向畫面右下，下一鏡的東西就要在那裡）。
- 光線的方向、顏色和同一場戲的其他鏡頭一致；同機位的鏡頭背景一致。
- 9:16 的臉和關鍵道具在中間那一塊，不在會被字幕和平台介面蓋住的邊緣。
- 沒有需要讀的字，或者字留給後製。

### 3. 尾幀

- 只改了 `end` 寫的地方，其餘和首幀一模一樣：臉、服裝、背景、光線都沒有變。
- 變化幅度合理：首尾差太多，影片工具會在中間硬補，常常出現變形或「變臉」。

### 4. 影片

驗收的是「成片要用的那幾秒」，不是整段。頭尾各要裁掉約 0.5 秒，那裡變形沒關係。

- 主動作做完了，而且只做了這一個。
- 臉在動作中途沒有變成另一個人；手指沒有融化、增減；拿著的東西沒有穿過手或憑空消失。
- 次要運動（頭髮、衣擺、煙、窗簾）的方向一致，有原因。
- 運鏡照寫的方向；人物沒有跟著大幅移動。
- 沒有被工具自己切成好幾個鏡頭。
- 速度自然：沒有像慢動作，也沒有突然加速。
- 聲音：
  - 後配口型、旁白方案：嘴唇閉合，角色沒有自己在說話。
  - 原生音訊：台詞一字不差、說話的是對的人、嘴型對得上、聲線和這個角色前面的鏡頭一致，沒有自己加字幕或配樂。

### 抽卡與記錄

- 每一鏡先抽兩三次，挑最好的。高風險鏡頭（`risk` 有寫的）多抽幾次。
- **同樣的錯誤出現兩次以上，就不要再抽，改提示詞。** 一直抽是在賭運氣，問題的原因還在。
- 改了五六次還是不行，就換拍法：照 `anti-ai-rules.md` 的替代表，用剪接、遮擋、反應鏡頭或物件特寫達成同樣的效果。保留原拍法本身就是 `risk` 裡寫的備案該上場的時候。
- `<集數>-shots.csv` 的「模型、seed、抽卡次數、採用版本、驗收結果」照實填。之後要重做某一鏡、或同一個錯誤在別集又出現，這些紀錄是唯一的線索。

## 二、症狀、原因與改法

先找症狀，照順序試改法，前面的有效就不用往下。

### 圖像（資產圖、首幀、尾幀）

| 症狀 | 常見原因 | 改法 |
|---|---|---|
| 臉和設定圖不像，或每一鏡的臉都不一樣 | 沒掛設定圖；文字外貌和參考圖互相拉扯；臉在畫面裡太小 | 掛上這個造型的設定圖；工具支援多張參考圖時改用參考圖模式（`ref_mode`）；景別推近一級；同機位的鏡頭拿前一張首幀做圖像編輯 |
| 兩個人的髮色、服裝互相串色 | 兩個人都完整描述，工具把特徵混在一起 | 其中一人改成背影或前景虛焦（`partial`）；每個人的 `pos` 都以畫面位置開頭；把兩人的服裝顏色拉開；還是不行就分開生成再合成 |
| 多出一個人，或人數不對 | `bg`、`props`、`frame` 裡出現了人；場景描述太大，工具用路人填滿 | 檢查這些片段有沒有人；近景以內寫 `bg`，不要讓整段 `space` 進來；空鏡用 `type: 空鏡` |
| 手指多、少、融在一起 | 手佔畫面的比例不上不下；拿細小的東西 | `hands` 把兩隻手的位置寫清楚；換景別讓手變大或變小；改成物件特寫，手只從畫面邊緣入鏡；只壞了手就用局部重繪修那一塊，不要整張重抽 |
| 景別不對（寫中景卻出全身） | 服裝寫到褲子和鞋子，工具為了畫出來把鏡頭拉遠 | 填 `outfit_top`；在 `frame` 寫畫面下緣切在哪裡（「畫面下緣在腰部」） |
| 同機位的背景每一鏡都不一樣 | 每一鏡都從文字重新生成背景 | 先生成並定稿機位背景圖，每一鏡都掛它；同機位的後續鏡頭拿前一張首幀做圖像編輯 |
| 反打鏡頭的背景和場景對不起來 | 場景定稿圖只有一個角度，反打看到的牆沒有參考 | 用那個機位的機位背景圖；機位背景圖本身對不起來時，先拿場景定稿圖做圖生圖、轉到那個方向 |
| 光線方向在相鄰鏡頭之間跳來跳去 | 每一鏡的 `light` 各寫各的；特寫裡寫了看不到的光源 | 同一場戲沿用場景或機位的光線；特寫只寫畫面上看得到的光（「一束冷白的光從上方斜照在臉上」） |
| 色調在相鄰鏡頭之間跳 | 風格鎖定句寫了冷暖，和夜戲的光線打架；沒有寫 `palette` | 冷暖與主色從風格鎖定句移到場景的 `palette`；同一場戲的鏡頭共用它 |
| 畫面出現亂碼文字 | 提示詞裡有招牌、信、螢幕、書本這類會帶出字的東西 | 寫成「空白的招牌」「沒有字的信紙」這種正面寫法；需要的字一律後製；已經出現就局部重繪擦掉 |
| 風格一鏡一個樣 | 風格鎖定句被改過或沒加；不同批次用了不同模型 | 不要改風格鎖定句；工具支援時掛風格參考圖；同一集用同一個模型版本 |
| 塑膠感、太乾淨、像 3D 渲染 | 質感詞不夠；寫了「高清、精緻、完美」這類詞 | 風格鎖定句加質感（顆粒、紙紋、筆觸）；刪掉「完美」類的詞；後製統一加顆粒與調色 |
| 參考圖模式下，人物的動作或位置不照寫 | 參考圖的姿勢太強，工具照抄設定圖的站姿 | 設定圖用自然站姿；`pos` 寫具體的姿勢與朝向；掛的圖太多時拿掉不必要的那一張 |
| 尾幀和首幀差太多，連背景都變了 | `end` 改的東西太多，或寫成了一個新畫面 | `end` 只寫一兩處差別；確定是拿首幀圖做圖像編輯，不是重新生成 |

### 影片

| 症狀 | 常見原因 | 改法 |
|---|---|---|
| 動作沒做，或只做了一半 | `motion` 塞了太多拍；動詞太抽象（「表現出猶豫」） | 只留一個主動作，用具體的動詞（「手指在杯緣停住」）；生成秒數加長一級；用尾幀把結束的畫面定下來 |
| 動作做太多，人一直亂動 | 沒寫哪些地方不動；生成秒數遠長於動作需要的時間 | 加「其餘保持靜止」；生成秒數貼近需要的長度，多的部分剪掉 |
| 臉在動作中途變形或變成別人 | 大幅轉頭、轉身；鏡頭和人物同時在動 | 拆成轉身前、轉身後兩鏡；人物有動作時鏡頭固定；幅度寫小 |
| 整段像慢動作 | 每一鏡都寫「緩慢」；動作只要一秒卻生成了五秒 | 刪掉「緩慢」，寫「自然速度、幅度小」；生成秒數貼近需要 |
| 突然加速、抽搐 | 寫了「快速、劇烈、瞬間」 | 單鏡內寫自然速度，速度用短鏡頭和剪接做 |
| 一段裡被切成好幾個鏡頭 | 工具的多鏡頭功能預設開啟 | 關掉多鏡頭；在 `video_suffix` 寫「單一連續鏡頭」 |
| 運鏡沒照做，或方向相反 | 運鏡沒寫方向；人物也在大動；首尾幀的構圖和運鏡矛盾 | 用用詞表的詞並寫方向（「左移」）；運鏡時讓人物幾乎不動；尾幀的構圖照運鏡之後的樣子 |
| 東西憑空出現、消失、穿過手 | 拿取、放下、手和物件接觸 | 換成動作剪輯：上一鏡拍伸手，下一鏡拍已經握住；或拍結果（放下的空杯） |
| 背景在影片裡扭曲、流動 | 運鏡太大；背景有大量細節或規律的圖案（磚牆、書架） | 運鏡改小或固定；`bg` 改成虛化的背景；有規律圖案的鏡頭少用運鏡 |
| 後配口型方案，角色卻在動嘴 | 提示詞或台詞讓工具以為要說話 | 表情寫「嘴唇自然閉合」；`motion` 不寫說話；原生音訊的工具，生成時關掉聲音 |
| 原生音訊：台詞念錯或用錯語言 | 台詞太長；提示詞和台詞語言不同卻沒註明 | 一鏡只說一句短話；填 `speech_lang` |
| 原生音訊：說話的是錯的人 | 畫面裡有兩個人，工具不知道是誰說 | 說話的人正面入鏡、聽的人背影或不入鏡；「畫外音」不要交給工具生成，剪接時鋪 |
| 原生音訊：聲線每一鏡都不一樣 | 工具沒有聲音參考 | 支援聲音參考就每個角色固定一個；不支援就改用後配口型，配音統一做 |
| 自己加了字幕或配樂 | 工具預設 | 在 `audio_suffix` 寫「不要字幕，不要背景音樂」 |

## 三、改提示詞的原則

- **一次只改一個地方。** 同時改三處，成功了也不知道是哪一處有效，下次遇到同樣的問題還是要猜。
- **改分鏡檔或設定檔，再重跑腳本，不要只改組合好的提示詞。** 直接改 CSV 或 Markdown 裡的提示詞，下次重跑就被蓋掉了；手改的那一鏡也會和其他鏡頭的用詞不一致。
- **看錯誤出現在哪裡，決定改哪一層。**
  - 只有一鏡出錯：改那一鏡的欄位（`motion`、`hands`、`bg`、`frame`）。
  - 同一個角色每一鏡都錯（臉、服裝）：改 `bible.json` 的 `look` 或造型變體，全片一起重跑；已經生成的鏡頭要評估哪些得重做。
  - 同一種鏡頭都錯（所有過肩鏡頭、所有運鏡鏡頭）：通常是拍法的問題，換拍法比改字有效。
- **改了什麼、為什麼改，記在 CSV 的備註。** 分鏡檔裡對應的那一鏡，`risk` 或 `continuity` 也補一句，下一集遇到同樣的鏡頭可以直接照做。
- **能局部修就不要整張重抽。** 手、文字、一小塊背景用局部重繪；整張重抽會把已經對的地方一起賭掉。

## 四、交付時提醒什麼

交付分鏡時，在製作順序之後加一兩句，挑和這一集有關的：

- 先定稿資產圖與機位背景圖，再出首幀；資產圖沒過驗收就不要往下做。
- 首幀全部出完後，先用 `EPxx-animatic.csv` 把首幀圖排上剪輯軟體的時間線（每張停多久、怎麼模擬動作都寫在裡面），匯入 `EPxx.srt` 當臨時字幕、配上臨時配音，粗剪一版看節奏、軸線和長度，再開始生成影片。影片是最貴的一步，問題在這裡抓最便宜。
- 每一鏡看「驗收重點」那一欄；同樣的錯出現兩次就改提示詞，不要一直抽。
