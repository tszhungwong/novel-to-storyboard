# 拆鏡方法

`fields.md` 說每個欄位填什麼，這一份說怎麼決定要填什麼：一場戲該拆成哪些鏡頭、每一鏡為什麼用這個景別、在哪裡切、怎麼接。

生成工具能不能做好一個鏡頭是另一件事，見 `anti-ai-rules.md`。先照這一份決定「要讓觀眾看到什麼」；工具定了、某個拍法它做不好，再用那一份第二部分的替代拍法達成同樣的效果。

這一份的方法對漫劇、短劇、動畫、真人劇都一樣，形式之間的差別在第九節（節奏）、第十二節（漫劇）與第十四節（短劇）。

目錄：一、先設計場次，再拆鏡頭（含走位）｜二、從節拍到鏡頭｜三、對話戲怎麼拍｜四、機位與連戲｜五、在哪裡切，怎麼接｜六、運鏡的理由（含速度、機位高度）｜七、構圖｜八、小說怎麼變成畫面｜九、節奏｜十、動作戲怎麼拍｜十一、資訊控制與揭示｜十二、漫劇的表現手法｜十三、聲音｜十四、短劇的表現手法

## 一、先設計場次，再拆鏡頭

從文字到鏡頭有四層：章（一集）→ 場次 → 節拍 → 鏡頭。跳過中間兩層、直接把句子翻成鏡頭，結果會是原文一句對一鏡，每一鏡一樣重，看不出這場戲的重點在哪裡。

**場次**是同一個地點、同一段連續時間裡發生的一件事。換地點，或時間跳走了，就是新的一場。

拆鏡之前，每場戲先回答這幾個問題，寫進分鏡檔的 `plan`：

1. **目的**（`purpose`）：這場戲演完，觀眾多知道了什麼，或感覺變了什麼？一場戲至少要改變一件事：資訊、關係、處境或情緒。答不出來的戲，通常可以併進前後場，或縮成一兩個鏡頭帶過。
2. **視點**（`pov`）：觀眾跟著誰經歷這場戲？近景、反應鏡頭、主觀鏡頭優先給他。小說的敘事視角通常已經回答了這一題。
3. **節拍**（`beats`）：每當有人做了一件新的事、出現一個新資訊，或情緒轉了方向，就是一個新節拍。一個節拍通常拆成一到三個鏡頭（一個動作、一句對白、一個反應各一鏡）。
4. **高點**（`peak`）：哪個節拍最重要？整場戲的鏡頭安排都是為了讓它最有力：之前一步步靠近，高點用最近的景別、停留最久，之後放鬆。
5. **走位**（`blocking`）：每個人在空間裡從哪裡開始、往哪裡移動、停在哪裡，軸線在誰和誰之間。兩個以上角色同場時要寫。
6. **基調**（`mood`）：色調、光線的情緒、節奏快慢。同一場戲的鏡頭共用它。`mood` 是給人看的；要進提示詞的色彩寫在場景的 `palette`，光寫在 `light`。

```json
{
  "id": "1",
  "scene": "S01",
  "purpose": "林晚不敢拆信，陳嶼回來後她把決定交給他。觀眾知道這封信的份量，也知道她信任他",
  "pov": "C01",
  "beats": ["信放了三天，林晚不敢拆", "陳嶼進門，發現信還沒拆", "林晚說出她怕什麼", "她把信推給他"],
  "peak": "她把信推給他",
  "blocking": "林晚整場坐在窗邊方桌靠窗的一側；陳嶼從玄關推門進來，停在門內一步，沒有再往前。軸線在兩人之間，機位都在沙發這一側",
  "mood": "安靜、壓抑；窗邊的暖光一點一點變暗"
}
```

篇幅大、要先停下來確認時，這張場次表就是交給使用者看的場景清單。

**走位怎麼寫。** 實際拍片會先畫一張俯視平面圖，標出家具、人物的站位與移動路線、軸線和機位。`blocking` 用文字寫同一件事：

- 用空間裡固定的東西當參照（門、窗、桌子、櫃台），不用畫面左右。畫面左右會隨機位改變，那是每一鏡 `pos` 的事。
- 寫每個人的起點、移動路線與終點。人走動時軸線會跟著轉，要寫出移動之後軸線在哪裡。
- 寫軸線在誰和誰之間、機位放在哪一側。機位的 `desc`、每一鏡的 `pos` 與 `gaze` 都從這裡推出來。

相鄰兩鏡人物左右對調、視線對不上，多半是少了這一步：每一鏡各自想像人站在哪裡。

拆鏡時每一鏡用 `beat` 指回它拍的節拍（`"1.3"`）。這不只是標記：寫的時候會逼你回答「這一鏡在拍哪個節拍」，答不出來的鏡頭多半可以刪；腳本也靠它檢查節拍有沒有漏拍、高點的鏡頭是不是最近、停最久。一個節拍通常一到三鏡；四個節拍以上卻每個都只有一鏡，就是原文一句對一鏡的徵兆。

## 二、從節拍到鏡頭

每個節拍問三件事，答案就是鏡頭：

- **觀眾這一刻要看到什麼才看得懂？** 決定拍誰、拍什麼。
- **這一刻誰的感受最重要？** 不一定是正在說話或正在動的人。
- **觀眾該離多近？** 決定景別。

景別是觀眾和人物之間的距離。越近越親密、越緊繃，但看到的環境越少；越遠越冷靜、越客觀。各景別的取景範圍與用途見 `fields.md` 的用詞表。選的時候：

- **景別跟著情緒走，不是為了變化而換。** 一場戲通常由遠到近：先讓觀眾知道在哪裡，再知道在做什麼，最後看到人心裡怎麼想。最近的景別留給高點。
- **特寫省著用。** 整場都是特寫，等於沒有特寫。
- **每換一鏡都要給新東西。** 觀眾看完這一鏡想知道的事（他在看什麼？她聽了什麼反應？），就是下一鏡的內容。
- **建立鏡頭**：場景出現後的頭三鏡內要有遠景或全景交代空間。不必是第一鏡，漫劇常先給鉤子再建立。人物在場景裡大幅換了位置，要再建立一次。
- **插入鏡頭與空鏡**：強調一件道具、讓觀眾喘口氣、表示時間過去了。它們也是生成工具最不會做壞的鏡頭。
- **主觀鏡頭**：讓觀眾直接用角色的眼睛看。前一鏡要先拍他「在看」，觀眾才知道這是誰的眼睛。
- **角度有意義**：仰拍讓人顯得有力，俯拍讓人顯得弱小。同一場戲裡不要無故改變角度；權力關係翻轉的那一刻再換，效果最大。
- **焦段**（真人寫實與 3D 動畫最有用）：同樣是近景，廣角要貼得很近，人和環境一起入鏡，有臨場感；長焦站得遠，背景虛化，人被從環境裡隔出來，像在偷看。一場戲的正反打用同一個焦段。用詞見 `fields.md`。

## 三、對話戲怎麼拍

兩個人說話，標準的拍法是這個順序：

1. **關係鏡頭**：全景或中全景，兩個人都在畫面裡，交代誰在哪裡、相隔多遠。
2. **過肩正反打**：越過甲的肩拍乙，再越過乙的肩拍甲，交替。兩邊的景別和角度成對（都是中景，或都是近景）。這時連續幾鏡景別相同是正常的。
3. **推近**：話越說越重時，從過肩換成單人近景（畫面裡不再有對方的肩膀，兩人的距離感被切斷），高點給特寫。兩邊同步推近；只推其中一邊，表示壓力在那個人身上。
4. **放鬆**：高點過後退回較寬的景別，或給一個空鏡、插入鏡頭收尾。

**不是誰說話就拍誰。** 一句話的重點常常在聽的人臉上。常見的切法是：一句話的開頭拍說話的人，讓觀眾知道是誰在說；後半句或下一句切到聽的人，說話聲繼續（`line` 用「畫外音」，`transition` 用「聲音延後」）。對生成工具來說這也是好事：反應鏡頭不需要對口型。

- **停頓**：重要的台詞前後，放一個沒有台詞的反應鏡頭，1.5 到 2.5 秒。話說完立刻接下一句，觀眾來不及感受。
- **三個人以上**：把他們分成兩邊，當成兩個人來處理，軸線畫在兩邊之間。有人換位置或有新的人加入時，重新給一個全景。
- **9:16**：畫面太窄，放不下並排的兩個人。關係鏡頭改用縱深（一前一後）或過肩，之後以交替的單人近景為主。

## 四、機位與連戲

**機位**是攝影機擺的位置。實際拍片時，一場戲不會每一鏡都換一個新位置：先擺好幾個機位，剪接時在它們之間來回切。用生成工具時照這個做法有兩個好處：

- 同一個機位的背景只描述一次（`setups[].bg`），不會每一鏡手寫一遍、越寫越不一樣。腳本會用它出一張機位背景圖（沒有人物的空景），先定稿，再當這個機位每一鏡的背景參考。場景定稿圖只有一個角度，反打看到的那面牆只能靠這張。
- 同機位的後續鏡頭，首幀可以拿前一次的首幀圖做圖像編輯（只改人物的姿勢和表情），背景、光線、人物位置都不會跑掉。腳本會在各鏡資料裡提醒哪一鏡可以這樣做。

一場雙人對話戲通常是這幾個機位：

```json
"setups": [
  {"id": "S01-A", "scene": "S01", "desc": "屋內靠沙發處，朝窗邊拍：桌子與窗戶的全貌，林晚側面", "bg": "窗邊的木頭方桌與整面窗戶，窗外是傍晚的天色"},
  {"id": "S01-B", "scene": "S01", "desc": "桌邊，朝玄關拍：陳嶼正面。軸線的沙發這一側，陳嶼看向畫面左", "bg": "玄關敞開的木門與門框，門外是昏暗的樓梯間"},
  {"id": "S01-C", "scene": "S01", "desc": "玄關，越過陳嶼的右肩朝窗邊拍：林晚正面。軸線的沙發這一側，林晚看向畫面右", "bg": "窗邊木桌與昏暗的窗戶"}
]
```

連戲要守的四件事：

- **軸線（180 度）**：兩個互動的人之間有一條假想的線，所有機位都放在線的同一側。這樣甲永遠在畫面一邊、乙在另一邊，兩人的視線相對。機位越到線的另一側，兩人左右對調，觀眾會以為他們換了位置。寫機位的 `desc` 時註明在軸線哪一側、人物看向畫面哪一邊，門、窗、光源在畫面哪一邊也一起寫。反打的機位左右相反：正打時門在畫面左，反打時就在右，從門照進來的光、窗外掃過的車燈也跟著換邊。真的要越軸，先插一個中性鏡頭（正對軸線的正面或背面、空鏡、插入鏡頭），或讓人物自己走動、帶著軸線轉過去。
- **視線匹配**：甲看向畫面右，乙就要看向畫面左。高低也要對：站著的人看坐著的人視線朝下，坐著的人朝上。`gaze` 欄要寫到這個程度。
- **運動方向**：人物朝畫面右邊走出去，下一鏡就從畫面左邊進來，繼續朝右。追逐的雙方朝同一個方向，迎面相遇的兩人方向相反。
- **30 度規則**：連續兩鏡拍同一個主體時，景別至少差一級，或拍攝角度明顯不同。兩鏡太像，看起來像畫面跳了一下（跳接）。腳本會警告主體、景別、角度、機位全都相同的相鄰鏡頭。

狀態的連戲（服裝、傷痕、道具位置、光線）靠造型變體、`continuity` 與 `end`：每一鏡 `end` 寫的結束狀態，要接得上下一鏡的起始狀態。道具最容易漏：前一鏡放在櫃檯上的手機，同一個機位的下一鏡還要在那裡；被收起來、被拿走、被舉高，要有一鏡拍到，或寫在那一鏡的 `end`；憑空出現在手上也一樣。同機位的首幀是從前一張改出來的，沒交代就消失的道具，生成時常常又被畫回來。同一個機位、取景沒有變近的鏡頭裡，登記過的道具不見了又沒交代，腳本會提示；換機位之間的連戲要自己查。

## 五、在哪裡切，怎麼接

每一刀都要有理由。常見的五種：

| 理由 | 切法 |
|---|---|
| 視線 | 人物看向某處，切到他看到的東西 |
| 動作 | 在動作進行中切，下一鏡接著同一個動作 |
| 聲音 | 聽見聲音，切到聲音的來源；或下一鏡的聲音先進來 |
| 資訊 | 觀眾需要看清楚一樣東西，切到插入鏡頭 |
| 情緒 | 一句話或一件事落地，切到受影響的人的反應 |

沒有理由的切，觀眾會覺得碎。

轉場的種類和各自要配合的事見 `fields.md` 的轉場表。幾種常見情況：

- **動作剪輯**：生成工具很難讓動作剛好停在中途，所以實際做法是上一鏡拍動作的開頭（伸手），下一鏡拍動作的結果（手已經握住杯子），剪接時各裁掉一點讓兩段接上。這也是高風險動作的標準替代拍法。
- **短的時間跳躍**（幾分鐘到幾小時）：硬切，加上看得出時間過去的變化（光線暗了、杯子空了、人換了位置），或中間插一個空鏡。
- **長的時間跳躍**：疊化或黑場，並換一個場景編號（新的 `light` 與 `time`）。
- **回憶**：進去和出來各一個轉場（疊化或閃白）。回憶段落另開場景編號，在場景的 `light` 寫出不同的色調（「褪色的暖黃光，對比偏低」），角色用當時的造型變體；年齡差很多就另開角色編號。
- **平行剪輯**（也叫交叉剪輯，cross-cutting）：兩件事同時發生時交替著切。每切回來一次，鏡頭更短、景別更近，張力就上去了。
- **蒙太奇**：把一段時間壓縮成三四個短鏡頭（各 1.5 到 2 秒），每鏡一個有代表性的畫面，鏡頭之間用疊化或硬切。

幾個剪接的業界名稱，和這份文件的用詞對照：

- **J-cut** 就是「聲音先入」：下一鏡的聲音先進來，剪接軟體上的聲軌和畫面軌排成 J 字形。**L-cut** 就是「聲音延後」，對話戲最常用。
- **插入鏡頭**（insert）拍的是這場戲裡的東西：桌上的信、她握緊的手。**切出鏡頭**（cutaway）拍的是當下不在主要動作裡的東西：窗外的雨、牆上的鐘、另一個房間的人。兩者都能換氣、蓋住剪接點；分鏡檔裡前者填 `type: 插入`，後者多半是 `空鏡`。
- **主鏡頭**（master shot）：用一個較寬的景別把整場戲從頭拍到尾，其他鏡頭再從裡面切出去。生成工具一段多半拍不完一整場戲，而且一段越長誤差越大，但概念還在：關係鏡頭的那個機位就是主機位，人物換了位置、觀眾可能迷路時切回它。

## 六、運鏡的理由

預設是固定。運鏡是在告訴觀眾注意力該往哪裡去，所以要有理由：

| 運鏡 | 觀眾的感受 | 適合的時機 |
|---|---|---|
| 推近 | 注意力收攏，進入人物的內心，事情變重要了 | 高點之前、人物下決定的那一刻 |
| 拉遠 | 看見周圍，人物顯得孤單，事情告一段落 | 揭露、一場戲的結尾 |
| 搖 | 跟著視線或動作，從一個主體帶到另一個 | 揭示旁邊的人或物 |
| 移 | 陪著人物走，展示空間的寬度 | 人物沿著某個方向移動 |
| 上升、下降 | 從細節到全貌，或從全貌進到細節 | 開場、結尾 |
| 跟拍 | 觀眾跟在人物身後一起進去 | 進入新的空間 |
| 環繞 | 人物處在被包圍或關鍵的時刻 | 很少用；工具做不穩時改成緩慢推近 |
| 手持 | 不安、身在現場 | 衝突、驚慌 |
| 移焦 | 畫面不動，注意力從一樣東西轉到另一樣 | 揭示：前景的信 → 後面的人；從說話的人轉到聽的人 |
| 甩鏡 | 急促、跳躍，像猛然轉頭 | 兩地之間的急轉；工具做不穩時改成轉場，在剪接時做 |
| 滑動變焦 | 主體大小不變、背景突然逼近或拉遠，暈眩、震驚 | 角色意識到可怕事情的那一刻；一部片用一次就夠 |
| 搖臂 | 高度和角度一起變，從人物升到全貌，有抽離感或史詩感 | 開場、結尾 |
| 航拍 | 從空中看地形與路線 | 大場面的建立鏡頭、旅程 |

一場戲裡有運鏡的鏡頭應該是少數。每一鏡都緩慢推近，等於沒有重點，也是常見的 AI 感來源。

### 速度

單鏡內的動作速度寫在 `motion`，照戲的力道寫：安靜的戲自然、幅度小，衝突的戲該快就快。整個鏡頭要變慢或變快時，填 `speed`：

| 用詞 | 意思 | 什麼時候用 | 怎麼做 |
|---|---|---|---|
| 升格 | 慢動作。拍攝時每秒格數升高，播放時就變慢 | 高點的一擊、東西落地、時間像停住的一刻 | 影片提示詞加「慢動作」 |
| 降格 | 快動作 | 喜劇、匆忙、時間壓縮 | 影片提示詞加「快動作」 |
| 縮時 | 很長的時間壓成幾秒：雲飛過、天色由亮轉暗、人潮流動 | 時間流逝、換場 | 影片提示詞加「縮時攝影」；畫面裡不要有要看清楚的人物動作 |
| 變速 | 同一鏡裡從正常變慢，再恢復 | 動作戲的關鍵一下 | 照正常速度生成，剪接時做 |
| 定格 | 畫面停在最後一幀 | 漫劇的卡點、人物出場配名字 | 剪接時做，停的時間算在 `duration` 裡 |

- 慢動作要省著用，一場戲最多一兩鏡。整片都慢，就沒有哪一刻是慢的；這和每一鏡都寫「緩慢」是同一個問題。
- 升格鏡頭的真實時間很短：成片 3 秒的慢動作，實際只有一秒左右的動作。`motion` 只寫一個很短的動作（落下、濺起、轉頭的一半）。
- 生成工具對「慢動作」的解讀不一定穩。做不出來時，照正常速度生成，剪接時補幀放慢；這樣要多生成一點長度。

### 機位高度

`angle` 管鏡頭往上看還是往下看，`height` 管攝影機離地多高，兩件事分開填。

| 高度 | 用途 |
|---|---|
| 地面 | 腳步、積水、地上的東西、從地面看人走過來；搭配平視或仰拍 |
| 低機位 | 約腰部高度：孩子或寵物的視角；讓人物稍微顯得高大，但不像仰拍那麼誇張 |
| 眼睛高度 | 中性，大多數鏡頭都是；不填時生成工具通常也給這個高度 |
| 高機位 | 高過頭頂：看清人群、桌面、人物之間的距離 |

低機位平視（貼著桌面看過去）和低機位仰拍（英雄式的仰角）效果不同；高機位平視（從二樓看對面的窗）和高機位俯拍也不同。只填角度時，生成工具會自己猜高度，所以高度對這一鏡重要時才填。

## 七、構圖

寫在 `frame` 欄。景別、類型、角度有自己的欄位，這裡寫其餘的安排。

- **三分法**：主體放在畫面的三分線上，不要每一鏡都擺在正中央。正中央留給對稱、對峙、有儀式感的畫面。
- **視線空間**：人物看向哪一邊，那一邊多留一點空間。反過來（臉貼著畫面邊緣，背後空一大片）會有壓迫、被困住的感覺，要用就刻意用。
- **頭頂空間**：頭頂上方留一點點。特寫可以切掉頭頂，但畫面邊緣不要剛好切在下巴、脖子或關節上。
- **層次**：前景、中景、背景至少要有兩層，畫面才有深度，不會像貼圖。前景可以是虛焦的肩膀、門框、窗簾。
- **框中框**：用門框、窗框、鏡子把人物框起來，表示隔絕或被注視。
- **負空間**：大片留白，表示孤獨或渺小。
- **景深**：淺景深（背景虛化）把注意力集中在人身上；深焦讓環境和人一樣清楚，適合建立鏡頭。

**9:16**：畫面窄而高，一鏡一個主體，用前後縱深代替左右並排。平台的介面與字幕會蓋住畫面邊緣，大約是上緣一成、下緣兩成、右緣一成（各平台不同，這是概略值）。臉、關鍵道具和重要的動作要放在中間這一塊：人物的臉擺在畫面中段偏上，不要把重點放在最底下。

**16:9**：可以左右安排兩個人，注意軸線。畫面寬，單人近景的旁邊會空出來，用視線空間或前景填補。

## 八、小說怎麼變成畫面

| 原文是 | 做法 |
|---|---|
| 心理描寫（「她很難過」） | 變成看得見的東西：微表情、小動作、她怎麼對待手邊的物件、環境的細節。「她盯著杯子，手指停在杯緣，視線垂下」。真的需要才用內心獨白 |
| 概述（「三年過去了」「他每天都去」） | 蒙太奇；或一個看得出時間的空鏡加上旁白 |
| 背景交代（身世、前情） | 旁白配空鏡或插入鏡頭，或拆散了放在動作之間。不要整段旁白配一張不動的臉 |
| 第一人稱敘事 | 敘事的話當內心獨白或旁白，視點角色就是「我」。可以用主觀鏡頭，但不要整片都是 |
| 比喻與意象（「心像沉進水裡」） | 不要照字面拍。在場景裡找現成的東西對應（杯底下沉的茶葉），或只留下情緒，交給表情和光線 |
| 潛台詞（嘴上說的和心裡想的不一樣） | 台詞照舊，讓畫面說出真話：嘴上說沒事，手在絞衣角 |
| 很長的對話 | 分成幾個節拍，每個節拍換一次景別或機位，中間插反應鏡頭與插入鏡頭。要刪減時記入 `changes` |
| 環境描寫 | 建立鏡頭和空鏡；挑一兩個細節當插入鏡頭，不必樣樣都拍 |
| 群戲 | 先用全景交代所有人，之後只跟著視點角色和一兩個關鍵人物 |
| 原文沒寫、但畫面一定要決定的事（誰站哪裡、手上拿什麼） | 自己決定，並且前後一致。牽涉外貌和重要道具的，列入 `pending` |

不改劇情的原則不變：這些都是換一種方式呈現，不是增刪情節。真的增刪了要記在 `changes`。

## 九、節奏

- **鏡頭多長，看資訊量和情緒的份量。** 一眼就看懂的（插入鏡頭、簡單的反應）短；需要感受的（高點、沉默）長。
- **一場戲的節奏有形狀**：鋪陳時慢；接近高點時加快，鏡頭變短、景別變近；高點停住，給全場最長的一鏡；之後放鬆。
- **對比產生力量**：連續幾個短鏡頭之後的一個長鏡頭特別有份量，反過來也一樣。所有鏡頭一樣長，就沒有輕重。
- **動作戲**：1.5 到 2.5 秒的短鏡頭快切。速度感大半是剪出來的，見第十節。
- **漫劇**：前三秒給鉤子；旁白不會停，畫面要跟著句子換，一句配一到兩個畫面；短影音的觀眾流失得快，經驗上每二三十秒要有一個新資訊、轉折或情緒變化；結尾停在懸念上。漫劇特有的手法見第十二節。
- **短劇**：比漫劇更快。前三秒進衝突，每一二十秒一個新資訊、反轉或爽點，對白一句一鏡；但高點與卡點要停住。見第十四節。
- **真人劇、動畫**：容許沉默與長一點的鏡頭，節奏的形狀照上面的原則，不必每幾秒就有一個鉤子。

## 十、動作戲怎麼拍

動作戲的難處是：觀眾要看得懂誰打誰、打中沒有、誰佔上風。實拍的動作片也是這樣拆的：把一場打鬥拆成很多個看得懂的小結果，速度與力道大半交給剪接和聲音。這樣拆，碰到做不好快速動作的工具時，要換的鏡頭也最少。

1. **先交代場地與雙方的位置。** 開打前一個遠景或全景：在哪裡、誰在哪一邊、中間有什麼（柱子、桌子、攤車）。之後的鏡頭都靠這個地理，寫進 `plan` 的 `blocking`。
2. **攻守兩方固定在畫面兩側。** 甲始終從畫面左邊打向右邊，乙從右往左。兩人之間的線就是軸線，和對話戲一樣不要越過，越了觀眾就分不清誰是誰。
3. **每一擊拆成預備、出手、結果。** 預備（抬手、重心下沉、眼神）→ 出手（短，一秒左右）→ 結果（被擊中的反應、兵器脫手、東西碎掉）。觀眾看得懂的是結果，不是過程。出手那一下照實寫；選定的工具做不好快速的動作時，改成只拍局部、剪影，或交給一聲音效、一個閃白。結果要看得出是誰做的：出手的人收勢的姿勢（劍停在揮完的位置）、被打的人抬頭看他、旁邊的人轉頭看他，至少一樣入鏡。只有聲音、閃白和一個沒有人的物件特寫，觀眾知道刀飛了，卻不知道是誰打飛的。
4. **力量看反應與環境。** 被打的人退了幾步、桌子被撞歪、灰塵和碎片落下、旁觀的人縮了一下。打得多重，是從這些東西看出來的。
5. **一個回合一個節拍。** 每一回合都要改變局勢：誰佔上風、誰受傷、武器在誰手上。沒有改變的回合可以刪。回合之間給一鏡喘息：對峙、喘氣、重新站好。
6. **越打越近、越打越短。** 第一回合用中全景，看得到全身和距離；之後一回合比一回合近，鏡頭也比上一回合短，張力自然上升。決勝的那一下可以用升格或定格讓它停住。
7. **每一鏡仍然只有一個動作。** 快的感覺主要來自短鏡頭快切與聲音；單鏡裡的動作照它真實的速度寫，不必刻意放慢，也不必把三招塞進同一鏡。

追逐戲也一樣：先交代路線；雙方朝同一個方向跑（運動方向見第四節）；交替拍追的人和被追的人，兩人的距離一鏡比一鏡近；起跑與抵達各一鏡，中間用腳步、背影和障礙物的短鏡頭省略。

## 十一、資訊控制與揭示

每一鏡都在決定觀眾知道什麼、什麼時候知道。同一件事先讓誰看到，效果完全不一樣。

**懸念與驚嚇。** 桌子底下有一顆炸彈。先拍炸彈，再拍兩個人若無其事地聊天，觀眾會一直緊張，這是懸念；不拍炸彈、讓它突然爆炸，觀眾只會嚇一下，這是驚嚇。懸念撐得住一整場戲，驚嚇只有一瞬間。想讓觀眾緊張，就讓他們比角色知道得多。

**觀眾和角色，誰知道得多：**

- 觀眾知道得比角色多：懸念、反諷。先讓觀眾看到危險或真相，再看角色走進去。
- 一樣多：跟著視點角色一起發現，代入感最強，推理和恐怖常用。
- 觀眾知道得比角色少：好奇、誤會。角色看見了什麼，觀眾還沒看到，等著揭曉。

**揭示的拍法：**

- **先拍反應，再拍東西。** 角色看見了，臉先變（近景或特寫；過肩的中景看不清臉色的變化，不算反應鏡），觀眾想知道他看見什麼，下一鏡才給。反過來先給東西、再給反應，適合讓觀眾和角色一起吃驚。不論哪個順序，反應和揭示都屬於同一個節拍（`beat` 填同一個），反應緊接在看見之後；反應拖到下一句台詞的鏡頭裡，揭示的那一刻就沒有落點。
- **拉遠揭示**：從一個細節拉遠，才看到它在什麼地方、旁邊還有誰。
- **搖鏡揭示**：跟著視線搖過去，看到原本在畫面外的人或物。
- **移焦揭示**：前景清楚、背景模糊，焦點一轉，背景裡的人才出現。
- **前景移開**：擋在前面的人走開、門打開、煙散去，後面的東西才露出來。
- **入畫**：畫面裡原本只有甲，乙從邊緣走進來。

一鏡只揭一件事。最穩、在任何工具上都做得出來的揭示是「反應一鏡、東西一鏡」，靠剪接；大幅的搖鏡揭示和轉身揭示，選定的工具做不穩時改成這一種。

**漫劇與短劇的鉤子與卡點**幾乎都靠這些手法：

- 鉤子：把後面的結果或最奇怪的一個畫面提前，讓觀眾知道得比角色多；或用一個看不懂的特寫勾起好奇。提前的鉤子是多出來的一鏡，它揭示的東西（手機上的訊息）在原本的節拍裡也要再交代一次，使用者刪掉鉤子時劇情才完整。
- 卡點：停在反應上，不停在答案上。角色看見了、臉色變了，他看見的東西留到下一集；或停在揭示的前一刻：門正要打開、手機正要翻過來。

## 十二、漫劇的表現手法

漫劇不只是「9:16 加旁白」。它從動態漫畫來，有自己的一套手法，其中很多比影片便宜，也更穩定。

**生成方式（`render`）：**

| 方式 | 是什麼 | 適合 |
|---|---|---|
| 影片 | 照常生成影片，預設值 | 需要動作、表演、對口型的鏡頭 |
| 靜幀運鏡 | 只出一張首幀圖，剪接時在圖上推近、拉遠或搖移 | 建立鏡頭、空鏡、物件特寫、旁白段落、回憶、要後製加字的畫面 |
| 靜幀 | 只出一張圖，畫面停住 | 定格的反應、配花字或集中線的衝擊畫面、很短的閃回 |

- 靜幀不跑影片，不會變形、不用抽卡，成本只有一張圖。旁白多的漫劇，空鏡和物件特寫大多可以用靜幀運鏡。
- 有人物的靜幀看起來就是停住的人。旁白在推進、畫面只是配合時可以；角色在表演、在說話，或是高點的動作，用影片。
- 靜幀運鏡只能做一張圖上做得到的動作：推近、拉遠、搖、移、變焦，也可以加輕微的晃動（手持）。環繞、跟拍、升降、移焦都做不出來。推近的鏡頭首幀要取寬一點，推完才不會裁掉臉。
- 要後製加字的畫面特別適合靜幀：物件一定不動，字貼上去最乾淨。

**後製的效果，寫在 `post`：**

- **定格**：停在一個表情或動作上，配人物名字的花字，或當卡點。影片鏡頭用 `speed: 定格`；整鏡都不動就用靜幀。
- **集中線、速度線**：漫畫的衝擊感。集中線是從四周往中心的放射線，用在震驚、發現；速度線用在衝刺、出手。
- **花字**：大而有設計感的字，擬聲詞（「砰」）、情緒符號（「？！」）、人物介紹。它和字幕不同，是畫面的一部分。
- **震屏、閃白、變色濾鏡**：衝擊、回憶、危險。
- **分格**：一個畫面分成兩三格，同時給兩個人的反應，或同一個動作的不同角度。

這些都在剪接時做，但生成時要替它們留位置：花字的地方留空白，集中線的中心對準臉，分格的每一格各自生成。用多了會像廉價的特效模板，一集挑幾個關鍵處就好。

## 十三、聲音

聲音不在畫面裡，卻會決定剪接點。拆鏡時想到的寫在 `sound`：

- **畫內聲與畫外聲**：畫內聲（diegetic）是故事世界裡的聲音，角色也聽得到：對白、腳步、雨、收音機裡的歌。畫外聲（non-diegetic）只有觀眾聽得到：配樂、旁白、強調用的音效。收音機裡的歌（畫內）漸漸變成整段的配樂（畫外），本身就是一種轉場。
- **擬音**（Foley）：後製錄的動作聲，例如腳步、衣服摩擦、杯子放下、刀出鞘。生成的影片幾乎都要補擬音，畫面才有重量；動作戲的力道有一半來自它。
- **環境音**（ambience）：每個場景墊一層底：雨聲、街聲、冷氣聲。換場時環境音一換，觀眾就知道換了地方。寫在場景的 `ambient_sound`，每一鏡的 `sound` 只寫這一鏡特有的音效；畫面上一直在動的東西（雨絲、燭火、人群）寫在場景的 `ambient`。
- **音橋**（sound bridge）：用聲音把兩鏡或兩場接起來，J-cut 和 L-cut 都是。上一場響起的電話鈴延續到下一場有人接起，兩場就連在一起。
- **靜默**：高點前把聲音抽掉，往往比加大音量更有力。在 `sound` 寫「所有聲音停住，只剩呼吸聲」。
- **配樂**：寫在 `music`，不寫在 `sound`（配樂是畫外聲，寫進 `sound`，原生音訊會把它當成現場的聲音生成）。只在配樂有變化的鏡頭寫：在哪裡進、在哪裡轉、在哪裡停。漫劇的剪接常常跟著配樂的拍子走，把重拍或突然的停頓對在高點與卡點上；「音樂停在信封推過去的那一刻」比一整段配樂從頭鋪到尾更有力。分鏡表會把它們列成「配樂提示」表，附上每一鏡開始的時間。
- **聲線**：有台詞的角色在設定檔寫 `voice`，旁白寫 `project.narrator_voice`。配音的人照它選聲音，原生音訊時腳本把它寫進每一句台詞；不寫，同一個角色每一集、甚至每一鏡的聲音都不一樣。

## 十四、短劇的表現手法

短劇（豎屏微短劇）和漫劇一樣靠鉤子與卡點留住觀眾，但它是演出來的：對白多、衝突直接、反應比日常大一級。多半是真人寫實，也有動畫風的。一集通常一到兩分鐘，大綱或使用者給了長度就照它。

**節奏**

- 前三秒進衝突：從爭吵、打臉、意外的中途切入，前因用一兩句台詞補。
- 每一二十秒一個新資訊、反轉或爽點。拍不出推進的鏡頭，刪掉。
- 單鏡短，對白一句一鏡，正反打切得快；高點與卡點反過來要停住，比其他鏡頭長。

**鏡頭**

- 近景與特寫為主，9:16 一鏡一張臉。需要交代兩人關係時，用一前一後的縱深或過肩。
- 爽點拆成壓、揚、看、收（`outline-to-episodes` 技能第三節）。「看」是旁人的反應：反派的臉垮掉、圍觀的人愣住、手上的杯子停在半空。這一段給足鏡頭與停頓，爽感有一半在這裡。
- 一句狠話、一個揭露，配一個快速推近到特寫，或一個定格。整集用兩三次就好，每句都推就沒有重點了。
- 重要角色第一次出場，定格加上名字與身分的字卡（`speed: 定格`，字卡寫在 `post`）。
- 打臉、反轉的那一刻，常常配一聲重音效，或讓配樂突然停住（`sound`、`music`）。

**字與介面**：聊天訊息、轉帳金額、身分字卡、彈幕式的吐槽字，短劇用得很多。這些都是要精確、要能改的字，寫在 `post` 後製加；拍手機畫面的那一鏡，手機要穩、螢幕朝向鏡頭。

**卡點**：停在反應上，答案留到下一集。付費或留存的卡點要比平常更強（危機或揭露），放在哪一集由大綱或使用者決定，不要自己挑。

**真人短劇的表演**：反應大一級，不等於每一鏡都大。主角的情緒多半壓著演，旁人的反應才放大；寫法見 `prompt-writing.md` 第八節。
